# 魔兽管家桌面界面复核 · 2026-11-24

**建议先评审公会与个人导航原型。** 运营此前找不到战报，当前团队导航也确实没有这一项。入口对齐后，再打磨公会与个人的页面字体。另有两处可独立决定的小改动，分别影响首次到站的游客和经常找家具的玩家。

## 现场与依据

| 场景 | 本轮核对范围 |
| --- | --- |
| 正式站，未登录的 Chrome | 从首页分别点开更新日志、团队管理和家宅分享。在家宅图鉴展开高级筛选、选中「矮人」、收起并查看命中数。 |
| 公会和个人导航评审稿 | 用示例会长读战报、从活动进入草稿，再切成普通团员核对入口。进入个人档案的「我的角色」，打开账号菜单并按 Esc 返回。 |
| 正式站公会成员视角 | 入口位置由运营提供的登录态截图及当前应用导航核对。表单字体取自正式页样式；本轮线上使用游客会话，登录态编辑、保存与发布未作线上验收。 |

桌面以 1366 × 768、1920 × 1080 两档检验图鉴排版。沿用站内深铁底色、暗铁金边图标和系统中文字体；新资料中关于分组导航、当前项提示和文字可读性的建议，用于选择检查点。移动端沿用项目既定范围。[项目 UI 规范](../../docs/魔兽管家UI设计规范v2.md) · [现有交互原型](../guild-personal-navigation/index.html)

## 三项评审意见

| 建议次序 | 已测量的现象或运营反馈 | 建议改法 | 范围与把握 |
| --- | --- | --- | --- |
| 1 | 运营找不到战报。当前团队导航列有仪表盘、成员、考勤、装备等八个页面键；公开主页在仪表盘，编辑按钮在考勤活动详情。登录态顶栏同时出现邮箱、用户中心和身份菜单。 | 沿用原型的顶栏「公会」「个人档案」和一个头像菜单。进入公会即看已发布战报，侧栏常驻「公会战报」。管理者从战报列表选活动写草稿，仪表盘保留最近战报摘要。 | 既有候选 REQ-211。入口分散已确认；正式账号与权限仍需在实施时验证。 |
| 2 | 正式站首页把「更新日志」列在「登录并加入公会后可用」之下，游客点顶栏却能阅读。旁边的「数据中心」又只向产品超管开放。三个公开卡片中，仅前两个标了「免登录」，游客实测也能打开家宅分享。 | 首页权限说明与实际入口对齐。锁定区只列入会后可用的团务，把更新日志和数据中心移出；给家宅分享补上与同排一致的「免登录」标记。 | 候选待审核，仅涉及首页展示。前两处由访客实测与现有权限规则支持；候选不涉及修改权限。 |
| 3 | 图鉴默认展示分类和来源。「更多筛选」一次展开九组，在 1366 档把首张家具卡从页面顶部 406 px 推到 1140 px；在 1920 档由 390 px 推到 1028 px。选中「矮人」并收起，已有摘要和「命中 78 件」正确显示。 | 保留搜索、分类、来源及已有选中摘要。展开「更多筛选」时先显示九个维度的名称，点击某一维度只展开它的选项；切换维度保留前一组选择。 | 候选待审核，仅涉及图鉴筛选布局。几何结果已测量；节省多少操作尚无玩家测试数据。 |

### 公会与个人的视觉落点

原型里团员能从同一个公会入口读到两条示例战报；切到会长才看到「从活动写战报」。个人档案下的角色列表有独立选中态。账号菜单适合放邮箱、通知和退出，版本放更新日志；正式接线时仍须保留现有公会切换和问题反馈入口。[现有顶栏对照](../guild-personal-navigation/before-account.png) · [公会预览](../guild-personal-navigation/guild.png) · [个人预览](../guild-personal-navigation/personal.png)

字体可先从公会介绍这一处试。正式页输入框的计算样式为 12 px 等宽体，原型同一处为 15 px 系统无衬线、24.75 px 行高。建议把战旗、日期印章和书卷感标题留给战报与档案页头，团长实际输入长段寄语和介绍时使用清晰的中文正文字体。此处为视觉建议，字号尚待运营选定。

### 复核时看什么

1. **找战报。** 从家宅页出发，点一次「公会」即能读到已发布列表。团员能读，会长能从同一处选活动写战报；返回后仍能找到原活动。
2. **看权限。** 未登录时，三个公开内容入口的标记一致。邀请一位普通团员检查首页承诺开放的项目都能找到。
3. **找家具。** 在 1366 × 768 下同时选择种族和颜色，核对两个选项与命中数。收起后能看到两项摘要与首排家具；选择一种常用维度时能同时看到结果。
