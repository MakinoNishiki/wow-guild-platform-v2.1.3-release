# REQ-177 整站美术方向 · 暮色公会厅

## 设计语言

- 范围：首页与共享导航、家宅图鉴、成员管理。治理来源为 DESIGN.md 和 UI 工作方法，桌面优先。
- 审计：此前家宅双页稿把暖色渐变页头放在冷灰筛选和卡片之上，用户确认画风断裂。新稿统一导航、背景、面板、正文和金色交互态，首页独用原创城堡剪影承担主题氛围。
- 色板：墨石 #121719、面板 #1b2222、边界 #3c4540、羊皮纸正文 #f4ead7、旧金 #e9bf77、状态绿 #93c7a5。标题用衬线，控件与表格用系统中文无衬线。
- 布局：首页展示品牌和入口，家宅用筛选与网格，成员用紧凑表格。三个页面共享顶部导航和操作样式。

## 验收与边界

打开 index.html，切换三页。Chrome 1440×1000 验证导航、浏览器后退、8 张房型原生预览解码、升级奖励筛选、详情与 Esc、成员名单搜索。零页面脚本错误。房型使用仓库既有图与已上线解锁数据的样本；成员为演示名单，当前没有编辑或保存链路。截图为 home.png、housing.png、members.png。

先确认这套整站基调，再确定正式改版范围和任务书。方向稿独立于产品代码；此前掉落页试改继续暂缓发布。职业测试、人物图鉴、社交扩展暂缓，#65 套装数据现状复核保留在后续队列。

## 运营反馈与下一版验收重点

- 布局优先于换色。保留三页稿的整洁度和空间利用率，参考 ForeverChanges 的信息组织。每页先明确主任务，再布置辅助入口；筛选、结果数量和结果区应在同一阅读路径。成员工作区的搜索、批量操作和表格归属清楚。
- 点击反馈拆成按下、执行中、结果三类。副本／首领和图鉴筛选立即显示选中态，同时更新标题、数量或结果。成员保存等异步动作应立即显示处理中，确认成功后更新对应行，失败时保留输入并就地提示。可同步完成的操作直接更新结果。
- 下一版演示图鉴筛选与详情回退、成员编辑保存的成功／失败状态。方向稿使用演示数据，正式验收需在隔离环境走真实保存主链路。

## 操作反馈样板已完成

同一预览增加家宅条件摘要、结果计数、详情退出时焦点回原卡片，以及成员编辑的模拟保存。Chrome 1440×1000 真浏览器验证：「升级奖励」选中后显示 4 项，打开首张详情再按 Esc，原按钮恢复焦点；成员管理点「编辑」，修改角色名并模拟失败，点「保存修改」进入保存中，失败后表格原值和表单输入保留；再次保存成功后对应行更新，表格旁显示回执。页面脚本错误 0。截图为 housing-feedback.png、member-save-error.png、member-save-success.png。

成员保存只更新样板会话内的演示名单，未接数据库。布局仍使用原三页方向稿的导航、页面间距和配色。

## 正式迁移红线 · 职业色与图标

职业色、职业图标、专精图标、职责图标及图标缺失回退沿用现有产品映射和渲染入口。页面主题色仅用于通用控件、选中态和焦点，避免覆盖职业文字、图标与品质语义。正式任务书须将这些项列为回归门禁。

验收时用同一批实际数据对比改版前后成员列表、考勤名单、智能导入预览，以及涉及专精展示的现有入口。核对职业颜色值、图标资源及文字标签，覆盖普通、选中、悬停和缺图回退状态。发现差异先修复再送验。演示名单只用于布局和反馈验证。
