# REQ-207 作品互动与举报处理

## 开工审计
- 表面：`#/house/community/:id` 的 `HousingBuilds.work()`、用户中心通知 `loadNotifications()`。
- 已测量：作品详情复用 `.hb-work`、`.btn.btn-sm`；现有通知表必须关联公会，无法承载全站作品回执。后者属于功能缺口，不当作视觉缺陷。
- 设计依据：DESIGN.md、UI 设计规范 v2，暗色表面、金色选中、已有按钮和输入框，桌面优先为已知取舍。
- 无证据支持需要重做现有图文卡片。本次在详情末尾增加互动与留言；后台使用独立弹窗，用户中心聚合回执。

## 已确认范围与规格
- 作品点赞、作品收藏、纯文字留言；作品/留言举报及原因、说明。
- 只有平台管理员处理举报：驳回、隐藏留言、下架作品，支持纠正已处理结果。公会角色不授予该权限。
- 新举报、处理结果写入站内回执；通知在用户中心统一查看。失败保留输入，重试不重复留言/举报。
- 互动条使用已有按钮，`aria-pressed` 标示点赞和收藏；文本计数说明数量。留言 1000 字，举报说明 1000 字，管理员说明 500 字；不解析 HTML、不自动执行或预览外链。
- 举报表单折叠在目标下方，提交按钮显示忙碌；关闭后返回目标。管理后台显示原文快照和处理历史。
- 状态覆盖：加载、未登录、空留言、选中、忙碌、错误与重试、长文本、撤回、被下架、键盘焦点。无装饰性动画。
- 写入通过 cloudCrud，专属服务端 API 鉴权、服务端基础词库与频率限制；SQL55 独立表和 RPC，管理员下架限制贯通旧版/新版保存、截图、蓝图复制。

## 验证
隔离 PostgreSQL + PostgREST + 实际 server.js，浏览器双账号与平台管理员操作；具体结果由修改报告记录。此文不代表实测通过。
