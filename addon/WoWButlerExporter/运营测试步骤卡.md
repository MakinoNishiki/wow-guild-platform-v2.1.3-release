# 运营测试步骤卡 · WoWButler Data Exporter（任务书 #26 WP1 验收）

> 目的：验证插件在真实游戏内可用。预计 15 分钟。每步做完在「结果」栏打 ✅/❌，❌ 请截图并反馈顾问侧。

| # | 步骤 | 预期 | 结果 |
|---|---|---|---|
| 1 | 把 `WoWButlerExporter` 文件夹复制到 `_retail_\Interface\AddOns\` | 文件夹内含 .toc / .lua / README | ☐ |

## 主链路实测

| # | 步骤 | 预期 | 结果 |

| 4 | 输入 `/wjdc all`，等待进度滚完 | 聊天框逐副本提示「团本：xxx（N 个 BOSS，M 件掉落）」「大秘境：…」，最后提示「已导出，请 /reload」；团本段会先提示「四难度档采集已启用」、大秘境段提示「大秘境难度档采集已启用」（1.0.12 起），并逐 BOSS 提示「档重扫完成（N/M 件带档）」，**总时长约为单档 4 倍（15–20 分钟量级）属预期**；导出开始/结束有「导出 run …」标记+时间戳（1.0.12 起）；若出现红字「N 件物品解析失败记 failed」，/reload 后重跑一次再判定；若出现红字「档采集通道不可用」，属自动回退单档，文件照常可用但请截图反馈 | ☐ |
| 5 | 输入 `/reload` | 界面重载，无报错弹窗 | ☐ |

| 8 | **抽查 BOSS ②**：换一个大秘境副本 BOSS 同上核对 | 件数一致，名称一致 | ☐ |
| 9 | **数据质量抽查**：文件中任选 3 件装备，核对 `ilvl` 与游戏内手册显示装等一致（应为当前赛季真实装等量级，不是 44 之类小数字）；文件内不应出现 `type = ""` 的空类型行 | ilvl 一致、无空 type 行；若 BOSS 条目带 `failed` 列表，聊天框应有对应红字报告（两者必须同时出现，缺一即 ❌） | ☐ |
| 10 | 输入 `/wjdc me` → `/reload` → 重新打开导出文件 | 文件只含 `meta` 和 `me`，角色名/服务器/职业/专精/等级/装等/公会名与本人角色面板一致（装等允许 ±1 的四舍五入差） | ☐ |
| 11 | 把第 6 步（/wjdc all）与第 10 步（/wjdc me）两次文件分别发给顾问侧 | 注意：`/wjdc me` 会覆盖文件，**请先备份 all 产物再跑 me**，或跑完 me 再跑一次 all | ☐ |

## 判定

- 全部 ✅ → WP1 游戏内验收通过，管道进入 WP2 实文件端到端（WP3 彩排）。
- 任何 ❌ → 截图 + 导出文件（若已生成）发顾问侧，注明步骤编号。

## 注意事项

- 测试期间**不要**用记事本编辑导出文件。
- 大秘境内、战斗中跑命令不影响结果，但建议在主城空闲时跑，避免卡顿。
- 插件不联网、不读账号数据，只读游戏自带副本手册，可放心常驻。

## 附：报障取证 + 1.0.12 验收跑（V1-V9 签字判据）

> 用途：某件装备游戏内 tooltip 有「毒咒」绿字标签行/「装备：…」特效行，但导出文件里 `effect`/`venomcurse` 为空时，跑本取证把 tooltip 原始行完整倒出，供顾问侧对照定位漏读形态。
> 1.0.11 定论：平面双通道（SetItemByID / 裸链接）对 EJ 预览态装备天生缺特效/毒咒行，导出已改挂难度上下文通道（史诗档链接）；**悬停直读（probe hover）为同类取证标准件**。
> 1.0.12：两跑实测定损修复包——**首次真机跑即验收跑，聊天框现场全留（完整截图）**，按 V1-V9 逐条判定。
> 1.0.13：断链零留存——每实例收尾即落表，中断跑出的文件 `meta` 带 `partial = true`（中断产物仍可发顾问侧，已扫副本数据不丢）。
> 1.0.14：链死（C stack overflow）与跨难度错位根治——连跑稳定性与档值带档率为本轮重点观察项；任何中断后需 /reload 再跑。
> 1.0.16：真机核毕三修（E1 过滤器污染/E2 毒咒残差/E3 单件主属性）——跑后**先截图聊天全文再 /reload**；「毒咒疑似行」黄字出现请一并截图。
> 1.0.17：1.0.16 翻车打回修 v2（F1-F5）——过滤器清零改官方重置接口（1.0.16 自动清空实际未生效且误把槽位钉成「头部」，本版根治）、枚举等待列表重建完成再扫、0 件掉落不再静默跳过（重试 3 次仍 0 会红字）、同 BOSS 重复掉落去重；任一副本 0 件时本跑不覆写上次计数基线。
> 1.0.18：1.0.17 双跑打回三修（BUG-094/095/096）——钉难度前校验副本是否支持该档（首选档无效自动改钉，快照行出现「改钉」注记属正常）、完整性质量门（缺副本或任一 0 件红字逐一点名+不覆写计数基线，判空跳过副本记入导出文件 `skipped_instances`）、BOSS 选中读回校验（未生效重试 3 次，仍失败记 `selectFail` 空占位）、单 BOSS 超 40 件判异常红字、毒咒支持「史诗↵毒咒」两行形态；**每段结束新增黄字「重建钩子统计（G1 查证）」请一并截图**。
> 冒烟模式（1.0.17 起）：`/wjdc smoke` 只扫至暗之夜第 1 BOSS + 毒牙祭坛第 1 BOSS（约 3 分钟），黄字全要素与全量同链——**全量 A/B 前先跑冒烟：冒烟绿再连跑 A/B，冒烟红直接截图打回，不烧全量**。
