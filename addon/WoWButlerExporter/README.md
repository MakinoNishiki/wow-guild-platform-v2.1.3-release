# 魔兽管家数据导出器（WoWButler Data Exporter）

> 游戏内插件，一键把「当前资料片」的副本手册数据导出成文件，发给顾问侧转换录入。
> 零外部依赖、不联网、不碰账号数据，只读游戏自带的副本手册和角色信息。

## 一、安装（一次即可）

1. 关闭游戏（或退回角色选择界面）。
2. 把 **`WoWButlerExporter` 整个文件夹** 复制到：
   `World of Warcraft\_retail_\Interface\AddOns\` 下面
   复制完路径应该是 `...\_retail_\Interface\AddOns\WoWButlerExporter\WoWButlerExporter.toc`
3. 启动游戏 → 登录界面左下角「插件」按钮 → 勾选「魔兽管家数据导出器」→ 若提示过期，勾选「加载过期插件」（12.x 正式服接口号已按 120000 填好，正常不会提示）。
4. 进入游戏，聊天框输入 `/wjdc` 能看到用法提示即安装成功。

## 二、使用（每条命令导完都要 /reload）

| 命令 | 导出内容 |
|---|---|
| `/wjdc all` | 全量：团本掉落 + 大秘境掉落 |
| `/wjdc raid` | 仅团本掉落 |
| `/wjdc mplus` | 仅大秘境掉落 |
| `/wjdc me` | 仅本人角色档案（角色名/服务器/区域/阵营/种族/职业/专精/等级/装等/公会名） |
| `/wjdc probe [序号\|物品ID\|hover]` | 诊断（不出文件）：团本序号=打印副本手册接口原始返回；物品ID=打印数值采集链核验（1.0.6 起）；`hover`=悬停链接直读（1.0.11 起，鼠标悬停装备不动再输入，取实物链接全行 dump，取证标准件），仅在顾问侧要求时使用 |

> **1.0.11 说明（S2 录库前修复包）**：
> ①**冷缓存自动等待**：物品数据未加载完不再直接解析（旧版曾致部分装备主属性缺损/类型错位），
> 插件自动排队等数据就绪，无需 /reload 重跑补齐；仍有个别记 `failed` 的会红字单列，照原流程反馈。
> ②**特效/毒咒改走难度档链接**：团本装备特效文本按四难度档链接读取、导出存**史诗档**文本；
> 毒咒标签按史诗档判定（平面 tooltip 通道对预览态装备天生缺这些行，已实锤）。
> ③属性数值 API 通道换用 `C_Item.GetItemStats`（12.1 起旧全局函数已移除）。
> 导出字段格式零改动，转换器照常可用。

> **1.0.12 说明（两跑实测定损修复包）**：
> ①**同一会话可连跑多次**：上一版在同一会话第二次导出可能出现团本 0 件/大米件数漂移
> （难度档状态未复位所致），已根治，连跑两次结果应一致；
> ②**逐件隔离**：单件采集失败只跳过单件，不再出现「整 BOSS 回退」「后续 BOSS 不再切档」的连坐；
> ③**大秘境也按难度档采集**：普通/英雄/史诗/时空漫游逐档探测（因副本而异，没有的档自动跳过），
> 饰品特效按史诗档读取，导出大秘境掉落新增 `primary_tiers`/`secondary_tiers` 字段；
> ④**伪实例过滤**：「史诗钥石地下城」不再混入导出；
> ⑤**导出日志更可查**：开始/结束带 run 标记+时间戳，每实例打印难度档快照，
> 与上次导出件数不一致时黄字对比提示。
> 导出字段格式零改动（仅大米段新增 tiers 字段），转换器照常可用。

> **1.0.13 说明（断链零留存）**：
> 旧版「全部跑完才一次性写结果」，中途崩溃/链死会让整跑数据全丢（/reload 后文件还是上一次旧数据）。
> 现改为**每跑完一个副本立即落表**：即使中断，已扫完的副本数据都在，`/reload` 写盘不丢；
> 中断跑出的文件 `meta` 里带 `partial = true` 标记，发给顾问侧时请注明是中断产物。

> **1.0.14 说明（稳定性根治）**：
> ①修复暖缓存连跑时可能报「C stack overflow」中断的隐患（导出链改为逐帧推进，现场表现为更稳、略慢属预期）；
> ②修复跨难度掉落列表错位导致的档值漏采（切档后等一帧再扫+按物品 ID 对齐，带档率跨跑波动消除）；
> ③回调报错文案改实话：报「导出链中断」即为真中断，按提示 /reload 后重跑即可，已扫数据不丢。

> **1.0.15 说明（断链哨兵）**：
> 导出超过 5 分钟毫无进展时，聊天框红字主动提醒「导出链已超过 300 秒无进展，判定链中断」——
> 看到它按提示 /reload 后重跑即可，已扫数据不丢；正常导出不会触发。

> **1.0.16 说明（真机核毕三修）**：
> ①过滤器自动清空在本版实际未生效且误把槽位过滤器钉成「头部」（已随 1.0.17 根治，请直接使用 1.0.17）；
> ②毒咒标签采集加固（全难度档扫描+疑似行自动取证，聊天框出现「毒咒疑似行」黄字请截图反馈）；
> ③修复个别装备主属性漏采（行首隐藏码所致）。

> **1.0.17 说明（翻车打回修 v2，当前版本）**：
> ①**过滤器处理根治**：改用官方重置接口清空手册职业/专精/槽位过滤器，导完自动还原——
> 1.0.16 的自动清空实际未生效（且误把槽位钉成「头部」致大量掉落漏采），本版起真正无需手动操作；
> ②枚举等待掉落列表重建完成再扫（修复同会话连跑时第二次导出大量漏件）；
> ③某 BOSS 掉落枚举为 0 时不再静默跳过——自动重试 3 次，仍为 0 会红字提示（看到请截图反馈）；
> ④同一 BOSS 重复掉落自动去重；任一副本本次 0 件时，本跑不覆写上次计数基线（红字提示）；
> ⑤**新增冒烟模式 `/wjdc smoke`**：只扫至暗之夜第 1 BOSS + 毒牙祭坛第 1 BOSS，约 3 分钟出数——
> 全量连跑 A/B 前先跑冒烟：冒烟绿（无红字、掉落/档值/特效齐全）再烧全量，冒烟红直接截图打回不烧全量。

> **套装效果说明（1.0.4 起）**：`/wjdc tier` 已移除——游戏内套装效果提取在 12.x 实证不可靠，
> 套装数据改走顾问侧文章/OCR 管道录入，本插件不再导出。

> **属性数值说明（1.0.6 起）**：掉落导出新增主/副属性**数值**字段 `primary_values` / `secondary_values`
> （如 `["secondary_values"] = { ["爆击"] = 300, ["急速"] = 100 }`，任务书 #28 WP1 星标数据链）。
> 采集优先走游戏接口 GetItemStats，不可用时自动回退 tooltip 解析，无需任何额外操作；
> 原有字段（名称/部位/类型/装等/属性名/特效）格式不变，旧版导出文件转换器照常可用。
> （1.0.5 为数值字段首版，因一处 Lua 多返回值隐患在真机必炸，请直接使用 1.0.6。）

> **四难度档说明（1.0.7 起，任务书 #29 WP1）**：**团本**掉落按 随机团队/普通/英雄/史诗 四档
> 逐件切档重扫，新增 `primary_tiers` / `secondary_tiers` 字段，形如
> `["secondary_tiers"] = { ["lfr"] = { ["爆击"] = 280 }, ["normal"] = { ["爆击"] = 300 }, ["heroic"] = { ["爆击"] = 320 }, ["mythic"] = { ["爆击"] = 340 } }`
> （只记存在的档——某装备无随机档则无 `lfr` 键；无静态属性的品类天然空档）。
> **采集时长约为旧版 4 倍（全量 15–20 分钟量级）属预期**，聊天框逐 BOSS 提示「四档重扫完成」。
> 大秘境无四难度（钥石层数缩放），不产 tiers，`primary_values`/`secondary_values` 仍是其唯一数值口径。
> 若切档通道不可用（聊天框红字提示「四档采集通道不可用」），插件自动回退旧版单档采集，
> 导出文件照常可用（tiers 不出现），请把红字截图反馈顾问侧。

操作流程：

1. 聊天框输入命令，例如 `/wjdc all`。
2. 聊天框会滚动显示进度（每个副本一行）。看到红色「N 件物品未缓存记 failed」提示时**不要慌**，先 `/reload` 再重跑一次同一命令；仍失败请截图整段聊天记录反馈顾问侧（失败的物品已记录在文件 `failed` 字段里，不会静默跳过）。
3. 看到「已导出，请 /reload 或退出游戏写入文件」后，输入 `/reload`（或直接退出游戏）。
   **不做这一步文件不会写盘。**

## 三、导出文件在哪

```
World of Warcraft\_retail_\WTF\Account\<你的账号名>\SavedVariables\WoWButlerExporter.lua
```

- 账号名不确定时，直接到 `WTF\Account\` 下逐个文件夹找 `SavedVariables\WoWButlerExporter.lua`。
- 每次导出会**整体覆盖**该文件，发文件前确认刚跑的是想要的命令。
- 把这个 `.lua` 文件原样发给顾问侧即可（微信/飞书/邮件都行），**不要用记事本改它**。

## 四、常见问题

| 现象 | 原因与处理 |
|---|---|
| 红色提示「不支持副本手册接口（EJ）」 | 装错客户端了——本插件只支持 12.x 正式服（`_retail_`），不能装怀旧服。确认安装路径含 `_retail_`。 |
| 聊天框红字「N 件物品解析失败记 failed」 | 物品数据重试后仍未就绪或解析报错。`/reload` 后重跑同一命令即可补齐；仍失败截图反馈顾问侧。 |
| 掉落里个别装备缺属性/特效 | 同上，缓存问题。`/reload` 后重跑同一命令即可补齐。 |
| 找不到导出文件 | 确认已执行 `/reload` 或退出过游戏；确认找的是 `<账号名>` 下的 `SavedVariables`（不是角色名下的）。 |
| `/wjdc` 无反应 | 插件未启用：登录界面「插件」里勾选并确认已加载。 |
