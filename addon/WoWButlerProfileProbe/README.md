# 个人档案国服验证 0.1.0（REQ-093 调研切片）

独立测试插件，只采集当前角色的允许读取数据，保留最近两次快照。
不上传网站，不调用战网账号接口，不读取密码、令牌或游戏进程内存；不改动拾取插件。

1. 启动国服正式服，启用「魔兽管家-个人档案验证」，进入角色所在世界并脱战。
2. 输入 `/wbprofile`，等待约 10 秒出现「采集完成」。
3. 输入 `/reload`，正常重载后由代理读取本插件的 SavedVariables 文件。

保存文件位于该游戏账号的 `WTF/Account/<账号>/SavedVariables/WoWButlerProfileProbe.lua`。
文件含个人角色与收藏信息，仅用于本地核查，不应提交 Git。登录本身不会采集。
本工具不启动桌面客户端，也不验证网站同步；更换装备后须重新执行采集命令。

数据口径：
- 装备逐槽读取完整链接及实际装等；未加载时留空，不用基础装等冒充。
- 大秘境读取当前赛季可得摘要，不承诺历史赛季记录。
- 团本仅当前锁定/周进度，不等于赛季累计进度，不据此授予成就。
- 家宅保留目录结果中的库存、已摆放和可兑换数量；目录结果未验证完整性，不生成收藏率。
- 家宅等待 10 秒后采样，仍为空记为未核验，不能解释成用户收藏为零。
- 正常重载/登出后的磁盘保存由游戏负责，须逐项真机核实；离线模拟测试不代替验收。
