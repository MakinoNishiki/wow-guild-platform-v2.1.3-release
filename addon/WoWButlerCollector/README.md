# 魔兽管家拾取记录 1.0.4

适用正式服 12.1.5。此候选尚待真实游戏验收。

## 日常使用

1. 安装并启用后默认自动记录。点小地图背包图标打开面板，也可从 ESC → 设置 → 插件 → 魔兽管家拾取记录进入。
2. 面板勾选「开启自动采集」控制新事件；已有记录保留，已接收的物品信息继续加载。开关会记住，不会在下次登录强制重新打开。
3. 团本结束、等待数归零后，点击「导出到网站」，按 Ctrl+C 复制。网站「团队管理 → 装备分配 → 拾取记录」导入，粘贴、核对并确认。关闭导出窗口不会删除记录，也不代表上传成功。
4. 确认网站已成功导入后，必要时再清空本机记录；清空有二次确认。小地图入口可拖动、可隐藏，隐藏后设置页仍可进入。

## 本次修复与旧记录

- 排除装备前战团绑定及账号绑定物品；按完整拾取链接判断，不能仅按同名或物品ID屏蔽。
- 实际装等优先读取链接提示信息，其次使用链接装等接口；不再用基础装等兜底。未取得实际装等或绑定信息时最多等待10秒，仍不全则保留待核对，不纳入导出。
- 新记录保留原始物品链接。1.0.3及以前记录缺少这些信息，会计入待核对，保留原样但不混入新版导出。升级不会将旧219改成305，也不能重新采集已经结束的拾取。请勿继续使用升级前复制的错误文本入库。
- 面板同时显示总记录、可导出与待核对数，导出只包含核验完成的记录。没有可导出记录时按钮禁用，原因在面板常驻显示。

## 记录边界

- 仅采集普通、英雄、史诗团本，逐条记录中文难度和原始难度编号；物品须为史诗品质或以上。随机团不采集、不增加记录/等待/失败计数，无需手动关闭开关。
- 兼容旧团本普通（10/25/40人）和英雄（10/25人）编号；地下城、野外、时光漫游、剧情及其他特殊/未知难度不采集。只处理本客户端收到的拾取消息，不保证看不到的团队拾取也能记录。
- 面板显示当前难度；随机团显示“不采集、不计数”。切换难度前已接收的记录仍保留原难度并继续加载。升级不删除历史数据，旧版已经记录的内容保留原样。
- 不能补回安装前、暂停期间或漏收的事件；物品信息加载失败会在面板显示本次登录失败数及最近错误。
- 拾取人不等于最终获得者；首领为击杀后180秒时间窗候选，最终来源须核对。交易后的最终获得者需在网站确认。
- 没有自动上传程序。导出复制无需 reload；需要代理读取本机保存文件时，先等加载完成，再重载界面或正常退出游戏以保存文件。
- 最多保留2000条，1000条起提醒及时导入，超过上限淘汰最旧条。旧版2秒去重、服务器后缀和数量口径仍待下一轮真实样本核对，未宣称完整解决。

## 兼容命令（无需日常使用）

`/wbc` 打开面板；`/wbc help` 帮助；`/wbc count` 诊断计数；`/wbc export` 导出；`/wbc clear` 二次确认清空。战斗中不打开游戏设置，自动采集保持按开关运行。
