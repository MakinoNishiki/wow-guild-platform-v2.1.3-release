#### 1.2 装备掉落导出增加 icon_name

**改动点**：在原有导出数据结构基础上，增加 `icon_name` 字段。

```lua
-- 在 Parser:ParseItemLink 或独立函数中
function Parser:GetIconName(itemID)
  local name, link, quality, iLevel, reqLevel, class, subclass, maxStack, 
        equipSlot, texture = GetItemInfo(itemID)
  
  if not texture then return nil end
  
  -- texture = "Interface\\ICONS\\inv_helm_plate_raidwarriorprimalist_d_01"
  -- 提取图标名
  local iconName = texture:match("ICONS\\(.+)$")
  return iconName  -- "inv_helm_plate_raidwarriorprimalist_d_01"
end
```

**导出数据结构更新**：

```lua
-- 单条掉落记录
{
  timestamp = 1728864000,
  bossName = "盘魂者内克扎莉",
  difficulty = "mythic",
  
  -- 原有字段
  itemID = 279115,
  itemName = "成簇的海星",
  quality = 4,
  itemLevel = 324,
  looter = "张三",
  
  -- 新增字段
  iconName = "inv_misc_starfish_01",  -- 从 GetItemInfo texture 提取
}
```

**约束**：
- `iconName` 可能为 nil（GetItemInfo 异步加载失败），前端兜底 📦。
- 旧版插件导出的 JSON 不含 `iconName`，网站端解析时忽略即可（前向兼容）。

#### 1.3 套装数据导出（新增功能）

**入口**：小地图图标迷你面板增加「导出套装数据」按钮。

**交互流程**：
```
小地图图标 → 点击「导出套装数据」
  ↓
插件自动遍历：13 个职业 × 全部专精
  ↓
对每个 (classID, specID)：
  1. C_TransmogSets.GetAllSets() 获取全部幻化套装
  2. 筛选当前赛季套装（通过 setInfo.label 或 expansionID 判断）
  3. C_TransmogSets.GetSetSources(setID) 获取套装包含的 itemID 列表
  4. 对每个 itemID：GetItemInfo 获取名称、部位、图标名、装等
  5. 组装为套装记录
  ↓
全部遍历完成后 → 生成 JSON → 复制到剪贴板
```

#### 2.2 新建 tier_set_pieces 表

```sql
CREATE TABLE tier_set_pieces (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    season_id UUID REFERENCES game_seasons(id) NOT NULL,
    tier_set_id UUID REFERENCES tier_sets(id) NOT NULL,
    slot TEXT NOT NULL CHECK (slot IN ('头部', '肩部', '胸部', '手部', '腿部')),
    item_name TEXT NOT NULL,
    official_item_id BIGINT,
    icon_name TEXT,
    ilvl INTEGER,
    armor_type TEXT CHECK (armor_type IN ('布甲', '皮甲', '锁甲', '板甲')),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(season_id, tier_set_id, slot)
);

CREATE INDEX idx_tier_set_pieces_season ON tier_set_pieces(season_id);
CREATE INDEX idx_tier_set_pieces_tier_set ON tier_set_pieces(tier_set_id);

-- 可选：RLS 策略（公示页需要公开读取）
ALTER TABLE tier_set_pieces ENABLE ROW LEVEL SECURITY;
CREATE POLICY "tier_set_pieces_public_select" ON tier_set_pieces
  FOR SELECT USING (true);
```

#### 2.3 网站端「套装数据导入」入口

在管理后台或数据维护页面增加「套装数据导入」入口：

```
[套装数据导入]
粘贴插件导出的套装 JSON：
[                    ]
[                    ]
[解析并预览] [确认导入]
```

**解析逻辑**：
1. `JSON.parse` 外层包装
2. 校验 `version >= 1.1.0` 且 `exportType === "tier_sets"`
3. 遍历 `data` → `pieces`：
   - `season` 匹配 `game_seasons.name`
   - `className` + `specName` 匹配 `tier_sets`（通过 `game_classes.name_zh` + `game_specs.name_zh`）
   - `slot` 直接写入
   - `itemID` → `official_item_id`
   - `iconName` → `icon_name`
   - `ilvl` / `armorType` 直接写入
4. 使用 `INSERT ... ON CONFLICT (season_id, tier_set_id, slot) DO UPDATE` 实现幂等导入

**导入后验证**：
- 显示导入统计：「成功导入 100 件，覆盖 20 个专精」
- 未匹配项标红（如职业/专精在 tier_sets 中找不到）

#### 3.1 picker 装备卡片图标走 Blizzard CDN

**渲染逻辑**：

```js
function getItemIconHtml(item) {
  // 优先 icon_name（新字段，字符串图标名）
  if (item.icon_name) {
    return `<img src="https://render.worldofwarcraft.com/icons/56/${item.icon_name}.jpg" 
                  class="picker-icon" 
                  loading="lazy" 
                  onerror="this.outerHTML='📦'" 
                  alt="${item.item_name}">`;
  }
  
  // 回退：icon_id 暂无 CDN 路径，直接 📦
  return '📦';
}
```

**CDN 规格**：
- 56x56: `https://render.worldofwarcraft.com/icons/56/{icon_name}.jpg`
- 36x36: `https://render.worldofwarcraft.com/icons/36/{icon_name}.jpg`

**约束**：
- 仅 picker 卡片生效。
- `loading="lazy"` 必须保留。
- `onerror` 回退 📦 必须保留。
- 不改动其他页面图标（公示页、装备分配列表可后续逐步接入）。
