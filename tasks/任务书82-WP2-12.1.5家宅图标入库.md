# 任务书 #82-WP2：12.1.5 家宅新增图标入库（REQ-137）

## 背景

任务书 #76 已将 12.1.5 家宅目录新增 251 条记录写入 `decor_catalog`（REQ-165）。任务书 #82-WP1 在当前 WoW CASC build `12.1.5.70575` 验证了 `icon_file_id` 可批量提取：225 个 ID 全部成功、0 失败。项目已有本地图标管线和 `assets/decor-icons/{icon_file_id}.png` 渲染路径（任务书 #50 WP1）。

## 目标

将上述 225 张新图标压缩为项目既定 128×128 PNG 并纳入 `assets/decor-icons/`，使现有图鉴渲染逻辑可显示 12.1.5 新增家具图标。

## 规范与范围

- 必须遵循 `docs/开发规范.md` 与 `docs/问题与需求清单.md`；本任务延续 REQ-137，不新建重复需求编号。
- 只新增 225 个 `{icon_file_id}.png` 素材，并更新 REQ-137 台账、更新日志和本任务修改报告。
- 图标来源为 wow.export 官方 CASC 在线资源管线；源图保留 400×400，入库图按任务书 #50 既定流程使用 Pillow LANCZOS 压至 128×128。
- 不覆盖任何已有资源；不得将临时源图、CASC 缓存、wow.export 源码或导出 manifest 入库。
- 26 条新增目录记录没有 `icon_file_id`，继续使用既有 `_placeholder.png`；不得猜测或伪造映射。
- 不修改数据库、插件、图标渲染代码或服务器配置；不连接服务器、不部署、不提交、不推送。

## 验收口径

1. 本批目标 ID 与 `data/decor-catalog-12.1.5-new-items.json` 中非空 `icon_file_id` 集合一致：225/225。
2. 新增 PNG 均可解码，尺寸为 128×128；目标目录无 ID 同名冲突，素材总体积低于 50 MiB。
3. 抽样图像与对应家具语义相符；旧图鉴占位行为及无 ID 条目保持不变。
4. 保留未提交工作区供运营验收；运营验收通过后由运营自行提交。
