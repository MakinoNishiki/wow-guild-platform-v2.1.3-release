## 一、布局形态

### 1. 右栏悬浮面板（默认态，≥1400px 宽屏）
- 面板固定于视口右侧，**框体完整**——四周边框/底色/间距完整闭合，面板内所有控件（搜索框、重置筛选按钮、chips）**矩形零裁切**（运营 2026-08-11 专项要求：不要预览图那种边框不完整、按钮探出框外）。
- 宽度基准 264px（施工可微调 ±16px，报告说明）；高度 = 视口高 − 顶部偏移；**面板独立纵向滚动**（overflow-y:auto，滚动条深色主题样式）。
- 顶部偏移壳级变量：主应用壳 = topbar 56px + 页头高；公开壳 = 页头高（壳级 class 设定，top:56px 先例）。
- 卡片区让位：内容容器 margin-right = 面板宽 + 间隙，卡片列数自适应重排。

### 2. 面板内容（自上而下，纵向排列）
标题「筛选」→ 搜索框（含清空钮，现有行为保留）→ 重置筛选按钮 + 命中计数（默认「共 N 件」/筛选态「命中 X 件」+「N 项生效」标识）→ 分类组（二级单选+三级多选联动）→ 主属性组 → 副属性组 → 来源组。chips 组内纵向 wrap；组间距一致。

### 3. 窄屏回退态（折叠顶栏）
- 触发：视口 <1400px，**或**主应用壳 1366 实测卡片被挤至 2 列（施工实测判定，两壳各档实测值写进报告；判定口径=卡片区保持 ≥3 列）。
- 回退形态 = 折叠顶栏：**复用既有 #dpFilterToggle + #dpFilterRows 结构**（WP2 所建、现 display:none 闲置），一行装「搜索框 + 重置筛选 + 命中 X 件·N 项生效 + 筛选 ▾」，展开/收起双向，状态 sessionStorage 记忆。
- 宽屏右栏 ↔ 窄屏折叠，**同一套筛选 DOM、同一份渲染 JS**，仅容器形态随断点切换。

### 4. 零改动面（硬约束）
筛选语义零改动：三级联动、置灰规则、搜索置顶、重置筛选、命中计数逻辑、#dpChipToast 独立提示层——全部只换容器位置，不改行为。REQ-090（实例级多选）不实施不变。

### 5. 层级规约（演变登记）
原 sticky 顶栏 z=10 废止，新规：**右栏面板 z=10 ＞ hover 展开卡 z=5 ＞ 普通卡**——hover 长特效卡任何滚动位置不得覆盖面板（断言化）；#dpChipToast z=2000 独立层不动。

### 6. REQ-091 兼容预留
