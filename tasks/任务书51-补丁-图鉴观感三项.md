## 附：Housing Codex 调研纪要（2026-09-18 顾问）

**是什么**：Daeveren 开发的游戏内 addon（CurseForge 分发，v3.2.8 约 551KB；GitHub 开源 Daeveren/HousingCodexLive；178 插件站有镜像）。`/hc` 唤出，装饰图鉴网格+详情面板。

**功能全景**：
- 图鉴：可搜索网格 + 停靠式 3D 预览面板（自动旋转模型、来源、添加补丁、尺寸、染色选项）
- 筛选：已收集/未收集、心愿单、仅促销、隐藏商城件、添加补丁、可追踪、室内/室外、可染色、首获加成、暴雪目录 tags
- 心愿单/隐藏：星标追踪、独立窗口、右键隐藏
- 来源页签：任务（按资料片/地区分组+进度）/成就/商人（地图 waypoint）/掉落（boss/宝箱/世界）/专业（逐专业进度）/PvP/声望（按资料片阵营+声望等级要求+商人位置）/进度总览 dashboard（逐来源逐资料片完成度+最接近完成列表）
- 游戏内融合：商人地图 pin（含促销库存拆分+未收集提示）、当前区域未收集 overlay（悬停 3D 预览）、邻里 Endeavors 面板、商人/背包/银行界面拥有标记（绿勾）、商人 tooltip 收藏进度、装饰寻宝日常自动 waypoint

**对我们的六点启示**：
1. **3D 佐证**：其 3D 为客户端内 ModelFrame 渲染（游戏引擎直接出模型），web 侧不可搬运——web 做 3D 只有 WoWDB 自研 WebGL+CASC 重管线一条路。**我们一期不做 3D 的裁定维持不变**，伪 3D 转盘留二期评估。
2. **分类互证**：其左侧分类栏（家具/点缀/构造/照明/自然/功能/房间/杂项）与我方主类 8 个完全一致——词表正确性外部实证。
3. **来源维度**：其顶部来源页签≈我方来源筛选 chip（已有等价物）；「进度 dashboard」是二期方案单/收集进度的借鉴对象。
4. **「添加于补丁」字段**：per-item 补丁版本号（其详情有「添加于补丁：12.1.0」）。我方 client_version 是采集版本（全量同值），无 per-item 补丁号——二期数据增强线索（可自 wowhead 补采）。
5. **可染色**：其详情有「不可染色」标记，WoWDB 有 dyeable 筛选（约 269 件）——对应我方 can_customize 226 件，语义待闸 c 实证。
6. **拥有状态同步**：游戏内 API 可读拥有状态，web 做不到自动同步；WoWDB 走「Dump Decor 插件导出→上传同步」路线——与我方 #49 导出插件同路径，二期「拥有/方案单」可复用导出插件扩展，不需新数据管线。
