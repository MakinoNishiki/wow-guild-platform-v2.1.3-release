## WP2：首页双入口耦合（纯前端：index.html + js/app.js 渲染处 + main.css）

### 需求

1. **登录态：首页（dashboard）顶部双入口卡片区**（拒绝独立页孤岛的核心落地）：
   - 两张大卡片并排（窄屏纵排）：左「公会团队管理」右「家宅」；
   - 每卡=图标+组名+一句话价值文案+「进入 →」：
     - 公会团队管理：「考勤、装备、心愿单——团长每晚的行政工作，十分钟打完」→ 点击跳考勤页（或 dashboard 既有主入口页，侦察后定）；
     - 家宅：「2062 件家宅装饰全量目录，来源筛选一键到位」→ 点击跳 decor 页签；
   - 样式复用既有卡片体系（main.css 通用类，不新建并行体系）；按下即反馈（:active 缩放）、hover 提一档亮（深色浮层纪律）；
   - 卡片不影响 dashboard 既有统计区块，插于顶部。
2. **未登录态：登录墙底部加公示链接行**（免登录出口，不抢登录主流程）：
   - 一行小字居中：「无需登录：[家宅图鉴公示](decor.html) · [副本掉落公示](data.html)」；
   - 样式降一级（小字、弱色），登录表单视觉优先级不动摇。
3. **无公会遮罩页（authGuildForm）主次调换**（2026-09-18 运营提出非会长注册路径问题，顾问线上查证实锤、运营拍板并入本 WP）：
   - 现状实锤：注册表单仅显示名/邮箱/密码三字段（不填公会）；注册/登录后无公会 → authOverlay 遮罩盖死主界面，仅「创建新公会 / 邀请码加入 / 返回登录」三出口；「创建新公会」三字段大表单居视觉主位，「邀请码加入」缩在两道「或者」分隔线之下——多数注册者应是团员，现布局引导团员误建会（同名山寨会=数据孤岛）。
   - 改动（纯 index.html 该区块结构与文案，零 JS 逻辑变更，handleCreateGuild/handleJoinGuild 不动）：
     a. **邀请码加入提为主路径**：移为表单第一区块，label 上方加引导文案「团员请向会长索取 8 位邀请码」；
     b. **创建新公会降为次级**：置于「或者」分隔线后，引导文案「你是会长？创建新公会」，三字段（公会名/区域/服务器）原样跟随不动；
     c. 顶部提示语「你还没有加入任何公会，请创建或加入一个」微调为「加入公会后即可使用全部功能」（对齐新主次）；
     d. 「返回登录」出口保留原位。
   - 文案纪律：不含 emoji（上传通道破坏在案）。
4. 版本串递增。

### WP2 验收

- 截图：登录态首页双卡（桌面+768 纵排）、未登录登录墙链接行、**无公会遮罩新主次态**（开发者工具强制显示 authOverlay 截图即可；若有测试账号走真注册流程更佳，测试数据验收完自清理并复核为零）；
