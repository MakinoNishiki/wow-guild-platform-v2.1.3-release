### Step 2：卡片模板插入 `<img>` 标签

**操作**：在装备卡片渲染函数中，找到卡片 DOM 模板，在装备名称之前插入 icon。

**自查方法**：F12 → Elements → 点任意装备卡片 → 看 DOM 里有没有 `<img>` 标签指向 render CDN。

**修复代码**（如果缺失则添加，如果已有则核对）：

```javascript
// 在生成装备卡片的函数中，icon_url 计算逻辑
function getItemIconUrl(item) {
  if (!item.icon_id) {
    return '/assets/decor-icons/_placeholder.png';
  }
  return `https://render.worldofwarcraft.com/icons/56/${item.icon_id}.jpg`;
}

// 卡片模板中装备名称之前插入
const iconHtml = item.icon_id 
  ? `<img class="item-icon" src="https://render.worldofwarcraft.com/icons/56/${item.icon_id}.jpg" 
         onerror="this.src='/assets/decor-icons/_placeholder.png'" 
         alt="" loading="lazy" width="36" height="36">`
  : `<img class="item-icon" src="/assets/decor-icons/_placeholder.png" alt="" width="36" height="36">`;

// 最终卡片模板拼接顺序：icon → 名称 → 属性
```

**注意**：CSS 类名 `item-icon` 如果与现有类冲突，可改。但必须是一个独立的 `<img>` 元素，不是 background-image。

### Step 3：CSS 检查

**操作**：F12 → 点装备卡片的 icon `<img>` → Computed 面板检查：

| 属性 | 期望 | 如果异常 |
|------|------|----------|
| `display` | `inline` 或 `inline-block` | 如果 `none`，说明 CSS 隐藏了 |
| `visibility` | `visible` | 如果 `hidden`，取消隐藏 |
| `width` | `36px` | 如果 `0px`，检查是否被压缩 |
| `height` | `36px` | 如果 `0px`，检查是否被压缩 |
| `opacity` | `1` | 如果 `0`，取消透明 |

**修复代码**（如果需要新增/修正 CSS）：
```css
.item-icon {
  display: inline-block;
  width: 36px;
  height: 36px;
  vertical-align: middle;
  margin-right: 8px;
  border-radius: 3px;
  flex-shrink: 0;
}
```

**交付物**：
1. F12 Computed 面板截图（显示 icon 的所有 computed 属性）
