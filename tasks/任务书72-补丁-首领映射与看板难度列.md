## 一、问题

### 1.1 首领名仍为英文

#72 实现了团本名称的中文映射，但看板中的**首领名**（boss name）仍显示英文原文：
- "Nek'zali the Soulcoiler"
- "Ula'tek"

WCL API `reportData.report.fights.name` 返回的是英文首领名，国服用户看不懂。

### 1.2 看板缺少「难度」信息

当前看板表头：「首领」「击杀」「尝试」「最佳进度」
用户反馈希望增加「难度」列，显示：随机 / 普通 / 英雄 / 史诗

## 二、方案

### 2.1 首领中文映射（前端字典，Code 实测产出）

和团本映射同样的方案：前端硬编码字典 `WCL_BOSS_NAMES`，Code 从 WCL API 实测抓取首领名列表。

**抓取方式：**

```graphql
query {
  reportData {
    report(code: "XXXXXX") {
      fights {
        name
        enemyNPCs {
          id
          name
        }
      }
    }
  }
}
```

或从 WCL 网站简体中文页面抓取所有团本的首领列表。

**字典格式：**

```javascript
const WCL_BOSS_NAMES = {
  // Code 实测产出，英文首领名 → 中文官方译名
  // 例：
  // "Nek'zali the Soulcoiler": "缚魂者奈克扎里",
  // "Ula'tek": "乌拉泰克",
  // "Sikran": "希克兰",
  // "Rashanan": "拉夏南",
  // ... 全部首领
};

function getBossName(enName) {
  return WCL_BOSS_NAMES[enName] || enName;
}
```

**注意事项：**
- 首领名比团本名多得多（每个团本 8-12 个首领，全资料片约 200+ 个）
- 但更新频率极低（新团本才加）
- 英文首领名中可能含特殊字符（单引号、空格），字典 key 必须完全匹配
- 建议加一层 normalize：去掉首尾空格、统一大小写（但 WCL 返回的大小写是固定的，建议直接原样匹配）

### 2.2 看板增加「难度」列

**数据来源：**

WCL API `reportData.report` 返回难度信息：

```graphql
query {
  reportData {
    report(code: "XXXXXX") {
      zoneDifficulty  # 1=LFR, 3=Normal, 4=Heroic, 5=Mythic
      fights {
        name
        kill
        fightPercentage
        difficulty  # 单个 fight 的难度（和 report 整体一致）
      }
    }
  }
}
```

**难度映射：**

```javascript
const WCL_DIFFICULTY = {
  1: "随机",
  2: "普通",  // 某些旧本可能用 2
  3: "普通",
  4: "英雄",
  5: "史诗"
};

function getDifficultyText(difficultyId) {
  return WCL_DIFFICULTY[difficultyId] || "未知";
}
```

**看板表头修改：**

```
改前：首领 | 击杀 | 尝试 | 最佳进度
改后：首领 | 难度 | 击杀 | 尝试 | 最佳进度
```

**看板行数据：**

```javascript
// 每行渲染
{
  bossName: getBossName(fight.name),      // 中文映射
  difficulty: getDifficultyText(report.zoneDifficulty), // 难度
  kill: fight.kill ? "✅" : "❌",
  attempts: fight.attempts || 1,
  bestPercent: fight.fightPercentage + "%"
}
```

## 三、集成点（改 app.js）

### 3.1 新增字典

```javascript

}
```

### 3.2 看板渲染修改

```javascript
// 渲染首领行时
row.bossName = getBossName(fight.name);
row.difficulty = getDifficultyText(report.zoneDifficulty || fight.difficulty);

// 表头
const headers = ["首领", "难度", "击杀", "尝试", "最佳进度"];
```

### 3.3 难度信息显示位置

**方案 A（推荐）：** 每行显示难度（同一报告内所有 fight 难度一致，重复显示但信息完整）

**方案 B：** 只在看板标题显示难度（如「📊 团本速览 — 09月05日 烈毒之渊 史诗」）

**建议做 A**（用户明确说要在表头加难度列）。
