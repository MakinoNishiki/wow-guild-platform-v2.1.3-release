# 任务书 #13-补丁：REQ-050 团本清空按钮 + BUG-039/040/041

## 0. 背景

任务书 #13 + 补遗统一验收 17 条，15 条通过，#15（装备分配窄屏）、#16（更新日志四维）未过，另发现展开浮层显示不全。本补丁修复后与 #13、补遗**合并一次提交**。

## 1. REQ-050：团本名称输入框清空按钮

- 创建/编辑活动弹窗的"团本名称"输入框右侧加 **✕ 清空按钮**（暗色小图标，有内容时才显示）；
- 点击后清空文本框并**重新展开下拉面板**让用户重选；
- 不清空"最近使用"记忆；与自定义下拉组件（BUG-027）同一套交互语言。

## 2. BUG-039：REQ-046 手动标记展开浮层显示不全

**现象**（验收截图）：悬浮"19 条已手动标记，将被保留"，展开的浮层只有一个截断小框、勉强露出一行——19 条记录不可见。

**要求**：
1. 浮层宽度适配内容（min-width 与名单匹配），**完整列出全部 N 行**"成员名：状态"；
2. 超过约 10 行时浮层内部滚动（max-height + overflow-y），浮层不超出弹窗可视区；
3. 悬浮触发改为**点击切换展开/收起**更稳（或悬浮+点击均可），移动端思路兼容；
4. 回归：构造 19 条手动标记场景，浮层完整可读。

## 3. BUG-040：装备分配表窄屏内容不可见

**现象**（验收截图）：窗口缩小后，装备分配表（11 列：装备名称/心愿/所属团本/掉落难度/掉落BOSS/装备部位/主属性/副属性/分配给谁/分配状态/分配方式/操作）右侧列被挤出，看不到全部内容。

**要求**：
1. 装备分配表纳入 `.table-container` 横向滚动体系（与导入预览一致）：容器内 min-width 保底，窗口不足时**表内横向滚动**，表头吸顶；
2. 列优先级：窄屏优先保住 装备名称/分配给谁/分配状态/操作 四列，低优先列（副属性/主属性等）允许在横滚中；
3. 1366×768 实测：全部列通过横滚可见、无文字截断错位；
4. 顺带全站排查：还有哪张表列多（考勤记录表/统计排行）同样纳入横滚兜底。

## 4. BUG-041：更新日志四维分类补录不完整

**要求**：
1. 把 **#11 至 #13 补遗**期间全部条目按四维逐条补录：
   - 修复BUG：BUG-014/015/018/019/023~041（已修复的）、SEC-001 等；
   - 功能优化：REQ-037/038/043/045/046/047/049/050 等感知类；
   - 新增功能：WCL 集成、批量操作、筛选、活动状态、软删除等；
   - 模块调整：品牌更换、飞书/本地模式下线、导航重构等；
   - 日期与版本号按实际批次（07-27 #11、07-27 #12+补丁、07-28 #13+补遗）正确标注；
2. 每条文案一句话、用户视角（不写编号堆砌）；
3. 本次起严格执行发布门禁（规范第五章第 5 条）：本次补丁内容也同步补录，作为门禁生效后的第一批；
