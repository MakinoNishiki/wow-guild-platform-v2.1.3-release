# 任务书 #13-补丁2：REQ-046 改方案（折叠区）+ BUG-042/043/044

## 0. 背景

#13 补丁验收：REQ-050/装备表横滚/日志四维已通过；BUG-039 悬浮浮层方案在真实环境仍截断，经产品评估**改方案**；另发现统计报表两处显示缺陷与登录页状态机卡死。

## 1. REQ-046 方案变更：悬浮浮层 → 预览页内嵌折叠区（替代 BUG-039 修法）

**结论**：悬浮浮层在弹窗堆叠中空间不可控（19 条必然截断），废弃。

**新方案**：
1. WCL 同步预览页三分区之下，增加第四区「已手动标记（N）▸」折叠区：默认收起，显示摘要行"已手动标记 N 条，将被保留 ▸"；
2. 点击就地展开：完整列表逐行"成员名：状态"（灰底、只读、左对齐，与三分区同套表格/行样式），再点收起；无悬浮、无截断、无行数上限（区内可滚动）；
3. 展开状态不记住（每次打开预览默认收起）；
4. 删除此前悬浮浮层实现，不留死代码；
5. 回归：构造 19 条手动标记，折叠区展开完整列出 19 行。

## 2. BUG-042：统计报表「缺席榜 Top5」布局违规

**现象**（验收截图）：缺席榜 Top5 被挤成屏幕右边缘的竖条——标题竖排换行、内容半挂屏外、空态"暂无缺席记录"挤压变形。

**要求**：
1. 重新排布：缺席榜 Top5 纳入统计报表标准流式布局（与"出勤率排名"同级，如并排卡片或置于其下方），禁止贴边悬浮条；
2. 标题横排不换行；空态文案规范（居中灰字"暂无缺席记录"）；
3. 1366×768 下不破版。

## 3. BUG-043：统计报表图表 X 轴成员名重叠

**现象**（同截图）：出勤率图表 13 根柱对应 13 个成员名全部重叠糊成一坨，不可读。

**要求**：
1. 成员名超过约 6 个时：标签旋转 45° 或隔 N 抽稀显示；柱宽/间距随数量自适应；
2. 完整名单始终可从下方排名表获得，图表以可读为先；
3. 超长名字（如"一冰封絕戀一"）截断加省略号，悬浮显示全名。

## 4. BUG-044：退出公会后登录页卡"登录中..."

**现象**：退出公会后回到登录页，登录按钮下方显示"登录中..."且不消失；再次点击登录无任何动态感知，一直停留"登录中..."。

**要求**：
1. 诊断登录/退出公会的状态机：退出公会（及退出登录）返回登录页时，登录按钮文案/状态必须复位为"登录"初始态；
2. 点击登录：按钮"登录中..."禁用防重 → 成功跳转 / 失败复位+错误提示——全链路状态闭环，禁止任何路径把按钮卡在"登录中..."；
3. 顺带检查注册按钮同类问题；
4. 根因写入修改报告。
