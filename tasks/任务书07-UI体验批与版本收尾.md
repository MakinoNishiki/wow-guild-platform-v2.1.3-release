## A 组：正确性补漏（优先）

**BUG-018 身份徽章恢复**
- 任务书 #5 权限门改造后，侧边栏公会卡片上的用户角色徽章（会长/编辑/浏览）与设置齿轮入口丢失；
- 恢复角色徽章显示（位置可与原来不同，但必须一眼可见自己身份）；
- 设置齿轮如原来指向公会设置，恢复或并入公会设置页入口。

**BUG-019 活动创建后未即时显示**
- 现象：editor 创建活动后日历/列表不即时出现，需手动刷新；
- 按数据流铁律修复：写入成功后单次 reload + 单次 render，与成员/装备模块行为对齐。

## B 组：UI 体验批（REQ-008~012、REQ-022）

**REQ-009 成员表"职责"列**
- 新增独立"职责"列，位置：职业列右、专精列右、状态列左；
- 按主专精+副专精推导全部职责，显示多个 tag（如主武器/副防护+狂怒 → 输出+坦克 两个 tag）；
- tag 尺寸与职业列职业 tag 完全一致。

**REQ-010 职责图标统一**
- 坦克/输出/治疗三类图标统一视觉风格（要么全彩色要么全扁平，与整体暗色设计一致），消除"治疗彩色、其他扁平"的混搭。

**REQ-011 考勤默认视图**
- 考勤记录默认展示"列表视图"，日历视图改为用户手动切换的可选项（记住用户上次选择更佳，不做强制）。

**REQ-012 活动时长实时显示**
- 创建/编辑活动面板中，选择开始与结束时间后实时显示时长（X 小时 Y 分钟）；结束早于开始时按跨天计算或明确提示。

**REQ-008 心愿标签独立列**
- 装备分配列表中"心愿"标签独立成列，与装备名称、团本、难度等字段同级；非心愿装备显示"—"。

**REQ-022 Roll 点循环**
- Roll 输入框：值为 1 时点 ↓ 变为 100；值为 100 时点 ↑ 变为 1；范围锁定 1–100。

## C 组：WCL 链接（REQ-014）

1. `activities` 表新增两列：`wcl_url`（text，可空）、`wcl_report_code`（text，可空）——产出增量 SQL 交运营执行；
2. 活动编辑区（owner/editor 可见）新增"WCL 日志链接"输入框：粘贴 warcraftlogs.com 链接，前端校验域名格式，保存时自动从 URL 解析报告编号存入 `wcl_report_code`；
3. 已挂链接的活动：列表与详情显示"WCL 复盘"按钮（全体成员可见），新标签页打开；
4. 一个活动一条链接；为空则不显示按钮。

## 纪律

- 修改前输出清单；修改后 node --check + 修改报告（逐编号）；
- WCL 的 SQL 先产出交运营执行，再继续后续验证；
- 不触碰：考勤专项（REQ-001/017/018/020、多角色）、用户中心治理（REQ-016/021/019）、主数据层——均另案。
