# 公示页筛选系统设计规范（PRD）

> 版本 v1.0 ｜ 2026-08-06 ｜ 依据：任务书 #23-补丁 验收反馈（运营实测截图在案）｜ 地位：公示页（data.html）筛选条的唯一设计基准；后续任何筛选相关改动以此为准，禁止即兴样式。

## 1. 设计目标

- 让用户在 3 秒内理解「这里能按什么筛」；
- 所有筛选控件**同一形态、同一尺寸、同一基线**；
- 分组逻辑一眼可读：先大类、后子类，组间有明确分隔。

## 2. 总体结构（唯一合法布局）

筛选条为**一个整体容器**，自上而下四组，每组一行（空间不足时组内折行，不跨组混排）：

```
[部位]   组头 | 全部 | 头部 肩部 胸部 …（chip 序列，组间分隔线）
[类型]   组头 | 全部 | 板甲 锁甲 … 
[主属性] 组头 | 力量 敏捷 智力
[副属性] 组头 | 爆击 急速 精通 全能
[排除杂项] 开关 + 问号帮助            ← 独立行尾
[搜索框]（装备名关键词）              ← 独立行
```

- 每行 = **组头标签（左，固定宽度右对齐）+ chip 序列（左对齐，同一水平基线）**；
- 组头与 chip 必须底对齐在同一行高上；禁止出现组头与 chip 上下错位；
- 组与组之间固定间距（8px 行距），组内 chip 间距 6px。

## 3. Chip 组件规范（唯一尺寸体系）

| 属性 | 值 |
|---|---|
| 高度 | 24px（所有 chip 恒定，禁止被文字撑出第二种高度） |
| 内边距 | 左右 10px，垂直 0（line-height 24px 居中） |
| 圆角 | 12px（全圆角 chip） |
| 字号/字重 | 12px / 500 |
| 默认态 | 深底（--card-bg）+ 1px 描边（--border）+ 次要文字色 |
| 选中态 | 主题色描边 + 主题色文字 + 浅主题色底（rgba 10%） |
| 组头标签 | 12px / 次要文字色 / 固定宽 56px / 右对齐 |
| 分隔 | 大组之间用 1px 竖分隔线（高 16px，居中于 chip 行高） |

- 「全部」chip 恒为每组第一个，选中 = 该组不过滤；
- 同组多选 = OR；跨组 = AND；清空/「全部」还原全集。

## 4. 分组与排序模板

**部位组**：护甲（头/肩/胸/腕/手/腰/腿/脚/背）｜武器（单手/双手/主手/副手/副手物品/远程）｜首饰（颈部/手指）｜饰品｜套装兑换物｜杂项。
**类型组**：护甲（板甲/锁甲/皮甲/布甲/盾牌）｜武器（单手锤/单手斧/单手剑/匕首/拳套/战刃/长柄武器/法杖/弓/枪械/弩/双手锤/双手斧/双手剑/魔杖/副手物品）｜首饰（戒指/项链等）｜饰品｜套装兑换物｜其它·杂项（装饰/坐骑/附魔/制皮/锻造/裁缝/珠宝加工/垃圾/幻化/玩具…动态归入）。

- 分组内用竖分隔线区隔子类（护甲｜武器｜首饰｜饰品…）；
- 选项从数据动态聚合，但必须按本模板排序；模板外新值归「其它·杂项」不丢弃；
- 套装兑换物独立成组，永不与杂项同组。

## 5. 交互与状态

- 所有筛选即时生效（客户端过滤，无延迟无按钮）；
- 赛季切换：全部筛选重置为默认（每组回「全部」、开关关、搜索清空）；
- 「排除杂项物品」开关默认关，问号帮助悬浮/点击显示：「勾选后仅显示装备，屏蔽坐骑、玩具、装饰、配方、幻化及垃圾等杂项物品」；
- 筛选结果数与各组条件严格一致（硬验收：单选/组合/清空还原逐项对数）。

## 6. 响应式

- 1920×1080：四组各一行；
- 1366×768：允许组内折行，但组头与首行 chip 基线对齐、折行 chip 左对齐成第二基线；
- 移动端：筛选条整体可折叠为「筛选 ▾」按钮展开面板。

## 7. 反例（禁止项）

- ❌ 组头与 chip 不在同一水平线；
- ❌ 同一条筛选条里 chip 出现两种以上尺寸；
- ❌ 下拉与 chip 两种形态混用（本规范唯一形态 = chip）；
- ❌ 选项按出现顺序乱排。
