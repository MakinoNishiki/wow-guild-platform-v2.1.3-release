## §1 BUG-109 返回首页入口

**现状（顾问已查证锚点）**：
- `index.html:195` 品牌区 `ia-brand` 为纯 `<div>`，无点击绑定——点 logo 不回首页；
- `index.html:197-198` 一级导航仅 `team`/`house` 两个 tab，无「首页」项；
- `app.js iaSwitchTab()`（约 2730 行）无 `home` 分支；路由默认分支使**有公会用户刷新/重开均落 `#/team/dashboard`，从任何功能页都无法回到 `#/home` 门户**。

**修改要求**：
1. `ia-brand` 整体可点击 → 回 `#/home`（走既有 hash 通道 `iaSetHash`，不破 `iaLastHash` 防环）；加 `cursor:pointer` + hover 态（取 CSS 变量，深色主题）。
2. 一级导航「团队管理」左侧加「首页」tab：`data-ia-tab="home"`；`iaSwitchTab` 加 `'home'` 分支 → `iaSetHash('#/home')`。
3. tab 高亮同步：`iaPaintRoute` 在 `page==='home'` 时首页 tab 高亮（无公会态 tab=null 的现有逻辑不破坏）。

**验收**：① 任意功能页点 logo 回首页；② 任意页点首页 tab 回 `#/home`；③ 有公会/无公会两态均通；④ 埋点只发一次 `tab_click level:1 key:'home'`（不双发）；⑤ **PV 五层链路零改动**——`#/home` 本就在 #60 口径内（看板页筛含首页），derivePage/TRACK_PAGE_RE/analytics_overview 均不动。

## §2 BUG-106 装备分配筛选不显示当前团本

**现状**：装备分配模块（`app.js` 约 6080 起）的副本/首领筛选分类中看不到当前赛季团本。

**修改要求**：
1. **先自查根因**：筛选器数据源是静态写死、旧缓存还是 MasterData 赛季口径（`game_seasons.is_current`，REQ-018 统一读法）？当前团本为何不入列？
2. 根因在前端 → 最小侵入修复，筛选分类随 `is_current` 联动。
3. **根因在数据层（分类挂错赛季等）→ 立即停工申报挂账**，转数据线批处理；禁止前端硬编码补丁。

**验收**：当前赛季团本出现在筛选分类；切换当前赛季后分类跟随刷新；非当前赛季团本仍可选（历史数据可查）。

## §3 BUG-107 已删除成员不计缺席

**现状**：考勤统计（`app.js` 约 4728 活动统计）与缺席排行（约 5638-5656）未排除已删除成员。既有口径（#27-补丁2/BUG-059、台账 3491/3892 行注释）：**考勤记录对删除成员保留并灰显「已删除」，不篡改历史**——本项只改统计口径，不动记录。

**修改要求**：统计与排行剔除已删除成员（判定口径与任务书 #27-补丁2 成员状态解析一致：成员 id 优先、状态回退）；出勤率分母/分子同步口径；明细视图维持灰显不变。

**验收**：① 删除成员后其历史缺席不计入统计数字与排行；② 活动明细仍可见其记录灰显「已删除」；③ 出勤率随口径变化且与明细可人工对账。
