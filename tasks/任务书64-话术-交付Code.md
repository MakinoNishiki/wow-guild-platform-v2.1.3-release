## 补丁 ①：主应用副本掉落页 — 套装区同步「共X件」+ 展开明细

**现状**：data.html（公示壳，免登录）的套装区已实现「共X件」胶囊 + 点击展开五件明细（头/肩/胸/手/腿），但**登录壳的副本掉落页套装区完全没有这套逻辑**。

**你要做的**：
- 把 dataPublic.js 里的套装渲染逻辑同步到主应用副本掉落页的套装一览区
- 每个职业/专精卡头部加「共X件」胶囊按钮，点击就地展开五件明细
- 部位排序沿用公示页（头→肩→胸→手→腿）
- 展开/折叠状态 sessionStorage 记忆（注意命名空间不要和公示页冲突）
- 复用 `CLASS_ARMOR` / `ARMOR_TOKEN_FAMILY` 词表，不另写计数逻辑
- 如果主应用套装区渲染链路和 dataPublic.js 完全独立，把相关函数抽到共享模块（如 lootTaxonomy.js），双壳共用

## 补丁 ②：手动添加装备表单 — 「所属团本」默认当前赛季

**现状**：图3 里手动表单「所属团本」下拉显示全部实例（包括 S1 历史赛季），没有赛季过滤。

**你要做的**：
- 「所属团本」下拉默认只显示当前赛季（`is_current=true`）的团本实例
- 选中团本后，「掉落BOSS」下拉自动过滤为该团本下的 BOSS 列表
- 历史赛季团本折叠/收起，用 optgroup 或底部折叠区都行，默认收起
- 心愿单手动添加表单**同步改**（和装备分配共用组件就一次改完）
- 复用 picker 已有的 `MasterData.getCurrentSeason()` / `raidSeasonOf()`，不另写赛季判断
- `is_current` 异常时回退全量展示

## 补丁 ③：Picker「所属团本」下拉 — 按赛季 optgroup 分组

**现状**：picker 弹窗左侧「所属团本」下拉是平面列表，没有按赛季分组。

**你要做的**：
