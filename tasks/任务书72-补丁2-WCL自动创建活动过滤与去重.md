## 一、问题

用户反馈考勤列表出现大量异常活动：
- 大量 "The Venomous Abyss" 空活动（0人登记，全部缺席）
- "未命名活动" / "未知团本"（WCL 报告无战斗数据）
- 同一个 WCL 报告可能创建了多个活动

**根因：server.js 的 sweep 逻辑缺少以下过滤：**
1. 无战斗数据的报告（zone=Unknown / fights=[]）
2. 已创建过活动的报告（同一 report code 重复创建）
3. 时间过久的报告（如超过 30 天的旧报告不应自动创建）

---

## 二、修复方案

### 2.1 过滤条件（sweep 前加 check）

在 server.js 的 WCL 报告 sweep 逻辑中，创建活动前增加以下过滤：

```javascript
// 伪代码：sweep 创建活动前的过滤
function shouldAutoCreateEvent(report, existingEvents) {
  // ① 过滤无战斗数据的报告
  if (!report.fights || report.fights.length === 0) {
    return { skip: true, reason: "无战斗数据" };
  }
  
  // ② 过滤 Unknown Zone
  if (!report.zone || report.zone.name === "Unknown Zone" || report.zone.id === null) {
    return { skip: true, reason: "未知团本" };
  }
  
  // ③ 按 report code 去重
  const reportCode = report.code;
  const alreadyExists = existingEvents.some(e => e.wcl_report_code === reportCode);
  if (alreadyExists) {
    return { skip: true, reason: "已存在对应活动" };
  }
  
  // ④ 过滤过旧报告（超过 30 天）
  const reportDate = new Date(report.startTime);
  const daysAgo = (Date.now() - reportDate.getTime()) / (1000 * 60 * 60 * 24);
  if (daysAgo > 30) {
    return { skip: true, reason: "报告超过30天" };
  }
  
  return { skip: false };
}
```

### 2.2 去重实现

**方案 A（推荐，零数据库改动）：**

sweep 时先查本公会已有活动，筛选出 `wcl_report_code IS NOT NULL` 的，用 Set 做去重判断。

```javascript
// sweep 前一次性拉取
const existingReportCodes = new Set(
  events
    .filter(e => e.wcl_report_code)
    .map(e => e.wcl_report_code)
);
```

**方案 B（更彻底）：**

给 events 表加唯一索引 `UNIQUE(guild_id, wcl_report_code)`，数据库层保证去重。但需处理已有重复数据（先清理再加索引）。

**建议做方案 A**，零数据库改动，立即生效。

### 2.3 日志记录

每次 sweep 跳过的报告记录日志（方便排查）：

```javascript
console.log(`[WCL sweep] 跳过报告 ${report.code}: ${reason}`);
```

## 三、清理现有垃圾数据

### 3.1 识别垃圾活动

满足以下任一条件即为垃圾活动：
- `wcl_report_code IS NOT NULL` AND `title = '未命名活动'`
- `wcl_report_code IS NOT NULL` AND 团本信息缺失/"未知团本"
- `wcl_report_code IS NOT NULL` AND 0 战斗记录 AND 0 人出席

### 3.2 清理方式

**方式 A（手动，运营执行）：**

运营在管家后台手动删除上述垃圾活动。

**方式 B（脚本，Code 执行）：**

```sql
-- 先查有多少条
SELECT id, title, wcl_report_code, created_at 
FROM events 
WHERE guild_id = '<用户公会id>' 
  AND wcl_report_code IS NOT NULL
  AND (
    title = '未命名活动' 
    OR title LIKE '%未知%'
    OR (attendance_count = 0 AND boss_kills = 0)
  );

-- 确认后删除
DELETE FROM events 
WHERE guild_id = '<用户公会id>' 
  AND wcl_report_code IS NOT NULL
  AND (
    title = '未命名活动' 
    OR title LIKE '%未知%'
    OR (attendance_count = 0 AND boss_kills = 0)
  );
```

**建议先让 Code 出查询脚本，运营确认数量后再删。**
