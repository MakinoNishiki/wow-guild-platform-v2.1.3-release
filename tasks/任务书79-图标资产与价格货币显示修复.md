## 二、修复方案

### 2.1 图标显示（前端）

**方案 A：CDN + 占位图降级**（推荐）

```javascript
// 图标 URL 生成
function getIconUrl(fileId) {
  return `https://render.worldofwarcraft.com/icons/56/${fileId}.jpg`;
}

// 图片加载失败时显示占位图
<img src={getIconUrl(fileId)} 
     onError={(e) => { e.target.src = '/assets/icons/placeholder.png'; }} />
```

**效果**：
- CDN 有的 icon → 正常显示
- CDN 没有的（12.1.5 新 icon）→ 占位图，等 CDN 同步后自动恢复

**方案 B：本地缓存**（未来扩展）
- 将 CDN 下载的 icon 缓存到 `assets/icons/items/`
- 新 icon CDN 可用后批量下载
- 本次不做

### 2.2 价格货币显示（前端）

**解析 source_text 中的货币代码**：

```javascript
// 提取价格信息
function parsePrice(sourceText) {
  // 匹配：价格：|r数字|Hcurrency:ID|h...|h
  const match = sourceText.match(/价格：\|r(\d+)\|Hcurrency:(\d+)\|h/);
  if (match) {
    const amount = parseInt(match[1]);
    const currencyId = match[2];
    return { amount, currencyId, currencyName: getCurrencyName(currencyId) };
  }
  
  // 匹配旧格式：价格：|r数字|T...UI-GOLDICON...
  const goldMatch = sourceText.match(/价格：\|r(\d+).*UI-GOLDICON/);
  if (goldMatch) {
    return { amount: parseInt(goldMatch[1]), currencyId: null, currencyName: '金币' };
  }
  
  // 纯数字兜底
  const numMatch = sourceText.match(/价格：\|r(\d+)/);
  if (numMatch) {
    return { amount: parseInt(numMatch[1]), currencyId: null, currencyName: '金币' };
  }
  
  return null;
}

// 货币 ID 映射表（已确认）

  '1813': { name: '心能',     icon: 'spell_animabastion_orb' },
  '2803': { name: '晦幽铸币', icon: 'inv_misc_elvencoins' },
};
```

**显示格式**：
```

```
