## WP1：密码强度 + 修改密码 + 玩家ID

### 1. 注册密码强度
- 规则：≥8 位；必须同时含字母与数字；拦截常见弱密码（内置 top-20 黑名单：12345678 / password / qq123456 / abc12345 等）。
- 注册表单：输入时实时强度指示（弱/中/强三档色条），不满足规则禁用提交 + 就地中文提示。
- 服务端：gotrue 配置 `GOTRUE_PASSWORD_MIN_LENGTH=8`（SSH 改服务端环境变量，密钥纪律：仅 .env，不进 git/文档）。
- 同一校验组件复用于「修改密码」表单。

### 2. 用户中心「修改密码」
- 入口：用户中心左侧菜单新增「修改密码」（位于修改昵称之下）。
- 表单：当前密码（服务端校验）/ 新密码 / 确认新密码。
- 校验：强度规则同注册；新密码 ≠ 当前密码；两次输入一致。
- 反馈：成功 toast「密码已修改」；失败就地提示（当前密码错误 / 强度不足 / 不一致），不跳转不刷新。
- 改密后当前会话保持登录；不做「登出其他设备」（超范围）。

### 3. 玩家ID（WoW BattleTag 风格）
- 形态：`{当前显示名}#{5位数字}`（例：`战战子#08241`）——魔兽原生 BattleTag 格式，零学习成本。
- 数字段：注册时分配、恒定不变；`user_profiles` 加 `tag_num` 列（**sql/ 目录带版本号增量**，唯一约束）；新注册随机 10000-99999，碰撞重试；存量账号迁移 SQL 批量补发。
- 显示名部分实时跟随昵称（改名不影响数字段）。
- 展示位：①用户中心顶部卡片——玩家ID + 复制按钮（复制完整 `昵称#12345`）；②右上角头像菜单昵称下方小字。
- 纯展示识别用途，**不进入任何鉴权/查重逻辑**。

### WP1 约束红线
- 零依赖、深色 WoW 主题组件规范；js/css/html 改动递增版本串。
- schema 变更仅走 sql/ 增量；迁移纪律（备份 → SSH+docker exec → NOTIFY pgrst → 回滚注释）。
- 不碰公示页与任何现有业务逻辑；测试数据自清理复核为零。

## WP2：邮箱认证 + 忘记密码（前置：SMTP 接通）

### 4. SMTP 接通（运营 + Code 协作）
- 顾问选型结论：**域名 ICP 备案未完成前，国内邮件服务（腾讯 SES / 阿里云邮件推送）无法绑定发信域名——先用海外服务过渡（SendGrid 免费档 100 封/日，足够当前体量）；备案完成后迁移国内服务**。
- Code：gotrue SMTP 环境变量配置（SSH/.env，密钥纪律）；发信联通测试。
- 运营：注册 SendGrid 账号、验证发信域名（DNS 加 SPF/DKIM 记录——顾问给具体记录值操作指引）。

### 5. 注册邮箱验证
- 流程：注册提交 → 提示页「验证邮件已发送至 xxx，请查收并点击确认链接」（可重发，60 秒冷却）→ 邮件内确认链接 → 激活 → 登录。
- 未验证登录：拦截提示「邮箱未验证」+ 重发入口。
- 邮件模板：中文、深色品牌风格（gotrue 模板定制）。

### 6. 忘记密码
- 登录页「忘记密码」入口 → 输入注册邮箱 → 重置邮件 → 链接进重置页 → 设置新密码（强度规则同注册）→ 成功转登录。
- 链接一次性 + 过期中文提示。

### 7. 存量账号兼容
- 一次性 SQL：存量 `auth.users` 全部补标 `email_confirmed_at`（备份后执行），只约束新注册，老用户无感。
