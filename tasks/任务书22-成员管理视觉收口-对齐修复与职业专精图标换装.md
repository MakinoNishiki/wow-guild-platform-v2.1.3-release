## WP1：成员管理列表对齐修复（纯前端 CSS/结构，零逻辑改动）

### 问题定义（以运营截图为验收基准）

成员管理表格同一行内：角色名、职业徽标、专精文字、职责徽标、状态徽标、加入日期、出勤率、操作图标组的**垂直位置不统一**，有的靠上、有的居中；徽标与同行文字**基线不齐**；操作列多个图标之间间距/对齐参差。已离队视图、其他使用同款表格的页面（装备分配、心愿单列表）如存在同款问题一并修。

### 需求

1. 全表统一单元格**垂直居中**（vertical-align: middle 或等效 flex 对齐），行内所有徽标与文字基线对齐；
2. 操作列图标组统一尺寸与间距，与行内容垂直居中；
3. 表格内徽标组件（职业/职责/状态）自身高度、行高、内边距统一，不因文字多少撑出不一致行高；
4. 已离队视图、装备分配、心愿单列表同标准过一遍；
5. 不碰任何逻辑、数据、交互行为（纯样式与结构微调）。

### WP1 验收

- 1366×768 与 1920×1080 两种宽度前后对照截图（成员管理+已离队视图），各行内容垂直居中、基线齐；
- 长角色名/多副专精/多职责的极端行不再撑歪；
- 浏览器控制台零报错。

1. 素材入库：`assets/icons/classes/`、`assets/icons/specs/`、`assets/icons/roles/` 分目录存放（素材包内目录结构与此一致，解包即就位），并建一个集中映射文件 `js/iconMap.js`：中文职业/专精/职责名 → 图标路径，全站只从这一处取。**职业官方色值一并写入 iconMap.js**（英雄榜参数定稿：战士#c69b6d、圣骑士#f48cba、猎人#aad372、潜行者#fff468、牧师#f0ebe0、死亡骑士#c41e3b、萨满#2359ff、法师#68ccef、术士#9382c9、武僧#00ffba、德鲁伊#ff7c0a、恶魔猎手#a330c9、唤魔师#33937f），供第 3 条「职业色作图标底色/描边点缀」使用；

## WP3：#21 验收沉淀附带项（四项小改，单独一个 commit：「任务书#22-WP3：验收附带项四项」）

> 来源：任务书 #21 验收反馈与实战暴露的问题，均已完成定级，照做即可。

### ① 认领方式三档说明分段（纯文案排版）

公会设置「认领方式」下拉下方的说明文字，目前是一整段连排。改为**一行一个模式**：
```
自由认领：成员可自助认领未被认领的角色，先到先得。
认领需审核：成员提交申请，管理者在成员管理顶部批准后生效。
仅管理者分配：成员不可自助认领，由管理者在编辑成员时指定。
切换不影响已存在的认领。
```

### ② 静态资源缓存版本号（根治「部署后用户拿到旧 JS」）

#21 验收实测暴露：index.html 对 js/css 的引用无版本标识，EdgeOne CDN + 浏览器双重缓存会导致用户端跑到旧版脚本（界面是新的、交互是旧的）。要求：index.html 内所有本地 js/css 引用加版本查询串（如 `js/app.js?v=20260805.1`），版本号写在文件顶部一处常量或注释里便于每次发版递增；**写进 docs/开发规范.md：凡改动 js/css 的 commit 必须同步递增版本号**。EO 缓存策略不动，靠查询串破缓存。

### ③ 公会设置保存栏吸附底部（sticky footer）

公会设置弹窗内容已较长，「公会资料」保存按钮在表单顶部，滚动到底部改「认领方式」时看不到保存入口（#21 验收实测踩中）。改为弹窗底部常驻操作栏：左侧「有未保存的修改」状态提示（有改动时显示），右侧「保存」按钮（与原按钮同逻辑，可两处并存或下移至底栏，二选一，以不破坏现有交互为准）。样式贴合现有深色体系。

### ④ 改名同步公会快照（唯一允许动 server.js 的项）

背景：#21 WP1-④ 已确认 `user_metadata.display_name` 为唯一真源，但 `guild_members.display_name`（入会时快照，用于向他人展示名字：审核区块申请人、「认领人：XXX」标签等）不联动，验收实测中会长看到申请人显示旧名。
要求：
- 前端：用户中心改名保存成功后，把本人所有公会的 `guild_members.display_name` 同步为新名（经代理）；
- server.js：补窄例外——`guild_members` 的 PATCH 仅放行「目标行 user_id=本人 且 body 字段 ⊆ {display_name} 且单行」，其余请求照旧落入原有分支（SEC-001 等逻辑一字不动）；
- 验证：改名 → 本人各行快照即时更新 → 他人视角（审核区块/认领人标签）显示新名；代他人改、夹带字段均 403；SEC-001 回归全绿。
