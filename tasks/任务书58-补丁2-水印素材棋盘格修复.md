## WP2：方案单独立页表格列对齐修复（纯前端 CSS）

### 需求

1. **背景（已定案，直接采信）**：用户真机发现独立页表格"字段和表头没对齐"。顾问静态复现实测定案——列边界本身对齐（同一 table），错位感来自两处：
   - **主因**：auto 布局下 `.dh-pp-src { max-width: 260px }` 被 Chrome 忽略（td max-width 不参与列宽算法），长来源文本把来源列撑到 ~44%  table 宽，数量列被连带拉伸，表头文字与数据水平位置错位感强；
   - **次因**：th 统一左对齐，而容量·件/小计数据右对齐、数量步进器中置，窄列下表头与数据分居两端。
2. **修复**：`css/decor-public.css` `.dh-pp-table` 段追加以下规则（原规则保留，新增覆盖）：

```css
/* 任务书 #58-补丁2-WP2：表格列宽受控（fixed 布局），修复表头与数据错位感 */
.dh-pp-table { table-layout: fixed; }
.dh-pp-table th:nth-child(1), .dh-pp-table td:nth-child(1) { width: 36px; }
.dh-pp-table th:nth-child(3), .dh-pp-table td:nth-child(3) { width: 260px; }
.dh-pp-table th:nth-child(4), .dh-pp-table td:nth-child(4) { width: 96px; text-align: center; }
.dh-pp-table th:nth-child(5), .dh-pp-table td:nth-child(5) { width: 72px; }
.dh-pp-table th:nth-child(6), .dh-pp-table td:nth-child(6) { width: 72px; }
.dh-pp-table th:nth-child(7), .dh-pp-table td:nth-child(7) { width: 48px; }
.dh-pp-table th:nth-child(5), .dh-pp-table th:nth-child(6) { text-align: right; }
.dh-pp-src { max-width: none; } /* fixed 布局下 width 已受控，max-width 冗余去除 */
```

   - 家具列（第 2 列）不定义宽度，吃掉剩余空间；
   - 窄视口（<768px）下表格容器 `overflow-x: auto` 已有，fixed 布局超宽时横向滚动兜底。
3. **版本串**：本补丁 WP1/WP2 一次施工，版本串统一 `.77` → `.78`（不再二次递增）。

### WP2 验收

- 长来源文本（≥27 字）在来源列 ellipsis 截断、列宽 260px 不再撑爆；
- 数量/容量·件/小计三列：表头与数据同缘对齐（数量居中、两数字列右对齐）；
- `node --check` 不涉及（纯 CSS）；回归抽屉表格/图鉴卡片不受影响（选择器限 `.dh-pp-table`）。
