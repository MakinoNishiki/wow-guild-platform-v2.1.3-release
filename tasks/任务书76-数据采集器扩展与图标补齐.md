## 二、插件扫描规格

### 2.1 副本掉落扫描 `/wbc scan boss`

**触发**：玩家进入副本后输入 `/wbc scan boss`

**采集逻辑**（EncounterJournal API）：

```lua
-- 遍历当前副本所有首领
local function ScanBossLoot()
    local instanceID = select(8, GetInstanceInfo())
    local results = {}
    
    -- EJ 遍历首领
    local numEncounters = EJ_GetNumEncounters()
    for i = 1, numEncounters do
        local encounterID, encounterName = EJ_GetEncounterInfoByIndex(i, instanceID)
        if encounterID then
            -- 遍历首领掉落
            EJ_SelectEncounter(encounterID)
            local numLoot = EJ_GetNumLoot()
            for j = 1, numLoot do
                local itemID = C_EncounterJournal.GetLootInfoByIndex(j)
                if itemID then
                    local itemName, itemLink, quality, ilvl, _, itemClass, _, _, slot = GetItemInfo(itemID)
                    local iconID = GetItemIcon(itemID)
                    table.insert(results, {
                        scanType = "boss",
                        itemName = itemName,
                        itemID = itemID,
                        iconID = iconID,
                        quality = quality,
                        ilvl = ilvl,
                        slot = slot,
                        itemType = GetItemClassInfo(itemClass),
                        bossName = encounterName,
                        instanceName = select(1, GetInstanceInfo()),
                        difficulty = GetDifficultyInfo(select(3, GetInstanceInfo())) or "未知",
                        timestamp = time()
                    })
                end
            end
        end
    end
    
    -- 存入采集缓冲区（与拾取记录分离）
    WoWButlerCollectorDB.scannedBossLoot = results
    print(string.format("WoWButler: 扫描完成，%d 件装备待导出", #results))
end
```

**关键字段**：
- `scanType = "boss"`（前端导入时分流标识）
- `bossName`：首领名（EJ 获取）
- `instanceName`：副本名
- `difficulty`：难度中文
- `iconID`：图标 ID（关键，用于 icon 补齐）

### 2.2 家宅图鉴扫描 `/wbc scan decor`

**触发**：输入 `/wbc scan decor`

**采集逻辑**（C_Housing API 扫描家宅图鉴，非背包）：

```lua
local function ScanDecorCatalog()
    local results = {}
    
    -- 使用 C_Housing 命名空间扫描家宅图鉴
    -- 遍历所有装饰类别和子类别
    -- TODO: Code 需先查证具体 API 名（如 GetAllDecorations / GetDecorationsByCategory / GetDecorationInfo）
    -- 预期 API 结构（需实证）：
    --   C_Housing.GetDecorationCategories() → 返回类别 ID 列表
    --   C_Housing.GetDecorationsByCategory(categoryID) → 返回装饰 ID 列表  
    --   C_Housing.GetDecorationInfo(decorID) → 返回装饰详情
    
    local categories = C_Housing.GetDecorationCategories and C_Housing.GetDecorationCategories() or {}
    for _, categoryID in ipairs(categories) do
        local decorations = C_Housing.GetDecorationsByCategory and C_Housing.GetDecorationsByCategory(categoryID) or {}
        for _, decorID in ipairs(decorations) do
            local info = C_Housing.GetDecorationInfo and C_Housing.GetDecorationInfo(decorID)
            if info then
                table.insert(results, {
                    scanType = "decor",
                    itemName = info.name,
                    itemID = info.itemID,
                    iconID = info.icon or GetItemIcon(info.itemID),
                    category = info.category or categoryID,
                    subCategory = info.subCategory,
                    source = info.source,  -- 如 API 提供来源信息
                    timestamp = time()
                })
            end
        end
    end
    
    -- Fallback：如果 C_Housing 无遍历 API，使用 Housing 界面钩子
    -- 或从 HousingJournal / HousingCollections 等 UI 框架中提取
    
    WoWButlerCollectorDB.scannedDecor = results
    print(string.format("WoWButler: 家宅图鉴扫描完成，%d 件", #results))
end
```

**重要**：背包/银行扫描只能获取"玩家已拥有"的物品，无法覆盖全图鉴（尤其未收集项）。必须使用 Housing 系统原生 API 或 Housing Journal UI 数据，确保 2062+ 条全量覆盖。

### 2.3 导出命令统一 `/wbc export`

```lua
SLASH_WBC1 = "/wbc"
SlashCmdList["WBC"] = function(msg)
    if msg == "export" then
        -- 合并所有缓冲区数据
        local allData = {}
        if WoWButlerCollectorDB.scannedBossLoot then
            for _, item in ipairs(WoWButlerCollectorDB.scannedBossLoot) do

                table.insert(allData, item)
            end

        local json = JSONEncode(allData)
        -- 弹出编辑框（同 #75）

        ScanBossLoot()
    elseif msg == "scan decor" then
        ScanDecorCatalog()
    elseif msg == "clear" then
        -- 二次确认（同 #75）
        ShowClearConfirm()
    else
        print("WoWButler: /wbc export | /wbc scan boss | /wbc scan decor | /wbc clear")
    end
end
```

## 三、前端导入页扩展

### 3.1 按 scanType 分流

JSON 中每个 item 带 `scanType` 字段，前端解析后分流：

```javascript
function parseImportData(jsonData) {
    const data = JSON.parse(jsonData);
    const grouped = {
        boss: [],      // → boss_loot / dungeon_loot
        decor: [],     // → decor_catalog
        loot: []       // → loot_drops（已有）
    };
    
    data.forEach(item => {
        const type = item.scanType || 'loot';
        if (grouped[type]) grouped[type].push(item);
    });
    
    return grouped;
}
```

### 4.2 补齐方案

**从插件扫描数据回补**：
- `/wbc scan boss` 采集时会获取 `iconID`（`GetItemIcon(itemID)`）
- 导出 JSON 中带 `iconID`，前端入库时直接写入
- 对于存量缺失的 377 条，运营手动补录或从 Wowhead 反查

**sql/43：批量 UPDATE icon_id（从已知数据回补）**

```sql
-- 如果有 icon_id 来源表，批量更新
-- 或运营手动提供 CSV → 批量 UPDATE

-- 示例：从已知映射表更新
UPDATE boss_loot 
SET icon_id = mapping.icon_id
FROM icon_mapping_table mapping
WHERE boss_loot.official_item_id = mapping.official_item_id
  AND boss_loot.icon_id IS NULL;
```

### 4.3 图标资产入管道

补齐 icon_id 后，运营供图入 `scripts/import-item-icons.js` 管道：
1. 收集所有 icon_id（去重）
2. Wowhead CDN 下载：`https://wow.zamimg.com/images/wow/icons/medium/{icon_name}.jpg`
3. 放入 `assets/icons/items/{icon_id}.png`
4. 运行脚本入管道
