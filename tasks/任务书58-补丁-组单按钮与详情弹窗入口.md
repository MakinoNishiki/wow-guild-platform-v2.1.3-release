## 一、需求

1. **卡片加单按钮明确化**
   - 移除卡片图标角标 ＋（`dh-add-plan` 角标形态退役），卡片底部新增通栏按钮：**常态「加入方案单」；该件已在方案单中时显示「已加入 ×N」**。
   - 点击行为不变：加入或 qty+1；点击后按钮文案即时刷新，徽标/抽屉同步。
   - **卡片尺寸允许加大适配**（按钮行约占 32px 高），网格列数不变；动效 150–250ms transform/opacity；双壳（decor.html / 应用内 #page-decor）同渲染层同步改。
2. **详情弹窗补加单按钮**
   - 详情弹窗（只读，不涉 modalDirtyChecks）底部新增主按钮「加入方案单」，行为同卡片按钮（加入/已加入 ×N 双态）；按钮状态与方案单实时一致（抽屉内改数量后回到弹窗，文案应反映最新 qty）。
   - 已加入态点击 = qty+1（与卡片一致），不给用户「只能加不能减」的错觉——减量仍在抽屉步进完成。
3. 视觉规格：按钮沿用主站按钮制式（gold 主按钮 / ghost 次按钮体系），圆角 ≤8px，暗色主题 CSS 变量；按钮不得遮挡卡片名称/来源文本。
4. **不改动**：抽屉结构、导出弹窗、保存链路、埋点挂点（`decor_plan_add` 事件继续在点击时发射，from 属性区分 `card` / `detail`）。

## 二、验收

- 双壳截图（桌面 + 768px 窄屏）：卡片按钮常态/已加入双态、详情弹窗按钮双态。
- 行为链路：卡片加入 ×2 → 详情弹窗同件显示「已加入 ×2」→ 弹窗再点 ×1 → 抽屉 qty=3、徽标同步。
- 窄屏不断行不溢出；`node --check` 全过；零依赖。
