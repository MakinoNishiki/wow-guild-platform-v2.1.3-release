## 1. BUG-020 身份徽章重设计

- owner/editor/viewer 三档徽章：小尺寸盾形/六边形底 + 职业色系分色（owner 金、editor 蓝、viewer 灰），图标+文字；
- 应用位置全站统一：成员管理、考勤详情、顶栏头像菜单旁；
- 与 #13 职业图标同一套视觉语言（24px 体系缩放）。

## 2. BUG-022 按钮体系统一

- 建立按钮层级规范并全站套用（CSS 类统一收口）：
  - 主按钮（保存/确认/导入）：品牌金系实心；
  - 次按钮（取消/返回/忽略）：描边幽灵；
  - 危险按钮（删除/解散）：红系，仅破坏性操作使用；
  - 文字按钮（表格内联操作）：无边框低强调；
- 统一高度/圆角/内边距/字号；禁用态、loading 态样式明确（沿用防重 loading 文案体系）；
- 全站 grep 散落按钮样式，归并到统一类。

## 3. REQ-026 表格列对齐规范 + REQ-030 表格视觉规范（合并实施）

- 列对齐规则：文本列左对齐、数字/出勤率列右对齐、状态/操作列居中；列宽用 table-layout 或 flex 基线约束，不因内容长短跳动；
- 斑马纹（奇偶行低对比底色交替）+ 悬停行高亮（亮一档，参考 ui设计参考 §4 材质层级）；
- 表头：字号小一档、字重加粗、与数据区细分割线；
- 应用范围：成员管理、考勤记录、装备记录、心愿单、智能导入预览——**五张表同一套规范**。

## 4. REQ-027 分辨率/窄窗口适配

- 基准：1366×768 笔记本窗口下全站无横向滚动、无挤压错位、无文字截断；
- 侧边栏在窄窗口可折叠为图标栏（或压缩宽度），主内容区弹性收缩；
- 表格列过多时允许横向滚动但表头吸顶/首列保持可见；
- 弹窗最大宽度与内边距随窗口收缩。

## 5. REQ-031 徽标/标签体系统一

- 全站标签（身份徽章、已取消、已离队、团队标签、冲突提示、职业 tag、状态 tag）收口为**一套标签组件规范**：统一高度/圆角/字号/内边距，语义色板固定（金=管理/红=危险或离队/灰=中性/黄=警告/蓝=信息/绿=成功）；
- BUG-020 的身份徽章按本规范落地（两者合并施工）。
