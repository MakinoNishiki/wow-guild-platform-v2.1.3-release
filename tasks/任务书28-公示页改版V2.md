## WP1：星标数据链（插件 1.0.5 + 转换器 + sql/19 + 回填）

### 需求

1. **插件 1.0.5（addon/WoWButlerExporter）**：掉落导出增加主/副属性**数值**采集——优先 `GetItemStats(itemLink)`（返回属性数值表）；不可用则回退 tooltip 解析。输出字段：`primary_values` / `secondary_values`（属性名→数值，如 `{爆击=300, 急速=100}`）。原有字段格式不变（向后兼容）。
2. **转换器（scripts/wjdc_convert.py）**：透传数值字段进入库 JSON；旧格式文件（无数值）转换不报错、数值列留空。
3. **sql/19**：`boss_loot`、`dungeon_loot` 各加 `secondary_values jsonb null`、`primary_values jsonb null`（回滚注释 + NOTIFY pgrst，幂等）。
4. **回填**：运营游戏内 `/wjdc all` 重跑当前赛季 → 转换器重新转换 → 入库覆盖（数值列写入）。运营配合动作：上号跑宏、把导出文件给执行方。

### WP1 验收

- 插件导出文件含数值字段（样例贴修改报告）；转换器新旧两格式文件均转换通过；

- **转换器输出格式冻结声明**（8.13 S2 翻牌按此格式）；
- 测试数据自清理复核为零；迁移可回滚。

2. **部位+类型 合并为「分类」层级筛选**：
   - 一级 tab：部位 / 武器 / 护甲 / 主属性 / 副属性 / 来源（六个）；
   - 二级值 chips（点一级 tab 展开其值域，组内 OR、跨组 AND 语义不变）：
     - 部位：头部/肩部/胸部/腕部/手部/腰部/腿部/脚部/背部/颈部/手指；
     - 武器：单手/双手/远程/主手/副手；
     - 护甲：板甲/锁甲/皮甲/布甲/盾牌；
     - 主属性：力量/敏捷/智力；副属性：爆击/急速/精通/全能；

4. **「重置」按钮**：筛选区右上角，点击清空全部已选（分类六组 + 关键词）还原 341，样式=次级按钮。
