**类型**：前端补丁
**优先级**：P2

**前置依赖**：无（数据已在线，纯前端）

---

## 一、背景与目标

### 1.1 背景
- 家宅图鉴 `decor_catalog` 表 `tags` 字段（JSONB）已包含 30+ 种族标签（兽人/人类/暗夜精灵等），数据来自暴雪 Housing API 原样入库（BUG-108 勘定）。
- 当前前端筛选维度：分类、来源、主题风格（资料片）、容量、摆放环境、特性。
- "主题风格"文案被用户要求改为"资料片分类"，与新增"种族"筛选形成上下位区分。

### 1.2 目标
1. 家宅图鉴筛选栏「主题风格」改为「资料片分类」（纯文案，零逻辑改动）。
2. 新增「种族」单选筛选维度（30 个种族标签），与资料片分类同级展示。
3. 版本串三壳同步递增。

## 三、详细改动（js/decorData.js）

### 3.1 state 对象（行23-36）

```js
race: 0,             // 种族 tag id（0=全部）
```

### 3.2 过滤逻辑 filteredRows（行74-87）

在 `state.expansion` 过滤行后插入：
```js
if (state.race && !(r.tags && r.tags[String(state.race)])) return false;
```

### 3.3 HTML 筛选栏渲染（行116-121）

在「主题风格」chip 组后插入「种族」chip 组：
```html
<div class="dh-group"><div class="dh-group-head">种族<span class="dh-chip-n">（单选）</span></div>
<div class="dh-group-note">按装饰的种族风格筛选</div>
<div class="dh-chips" id="dhRaceChips"></div></div>
```

### 3.4 chip 渲染与事件绑定（行139-143 附近）

在 EXPANSION_TAGS chip 渲染代码后插入：
```js
// 种族筛选
const raceDefs = [{ id: 0, label: '全部' }, ...D.RACE_TAGS];
$('dhRaceChips').innerHTML = raceDefs.map(e =>
  chip(e.label, state.race === e.id, e.id ? countBy(r => r.tags && r.tags[String(e.id)]) : null)).join('');
[...$('dhRaceChips').children].forEach((btn, i) => btn.onclick = () => {
  state.race = raceDefs[i].id; state.page = 1; refreshChips(); render(true);
});
```

### 3.5 refreshChips paint（行188-195）

在 `paint('dhExpChips', ...)` 行后插入：
```js
paint('dhRaceChips', i => state.race === (i === 0 ? 0 : D.RACE_TAGS[i - 1].id));
```

### 3.6 resetFilters（行203-206）

将 `Object.assign` 行改为：
```js
Object.assign(state, { search: '', category: 0, source: '', expansion: 0, race: 0, costTier: '', env: '', petOnly: false, roomsOnly: false });
```

### 3.7 activeFilterCount（行62-71）

在 `state.expansion` 计数行后插入：
```js
if (state.race) n++;
```

### 3.8 文案改名（3 处）
