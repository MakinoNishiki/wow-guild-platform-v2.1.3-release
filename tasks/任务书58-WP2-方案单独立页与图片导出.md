## WP2-1：多方案数据层改造 + 方案单独立页（应用内，纯前端 + cloud.js）

### 需求

1. **数据层口径改造**（cloud.js / app.js）：
   - `decorPlan` 由「updated_at 最新」改为「**当前选定方案**」：选定 id 存 localStorage `wb_decor_plan_current`；无选定值或选定 id 已不存在 → 回退最新 updated_at 方案；保存/读取/明细差集均指向该 id。
   - 新增操作支持：`create`（INSERT 头 + 空明细，默认名「我的方案 N」）、`rename`、`delete`（删除头，明细级联；**仅剩一个方案时禁止删除并提示**）、`switch`（仅切 localStorage + reload，不写库）。
   - 批量明细写仍走差集批量，禁止逐行 reload（开发规范 1.2）。
2. **方案单独立页**：
   - 侧栏「家宅」组内新增「**方案单**」项（组内增量；**一级导航/分组/首页结构一律不碰，那是 #57 范围**）；页签容器 `#page-decor-plan`，渲染层建议入 `js/decorData.js` 保持家宅域同源（与抽屉共享数据模块，禁止复制第二份数据逻辑）。
   - 页头：标题「我的方案单」+ 方案下拉切换 + 「＋ 新建方案」+ 重命名 + 删除 + 返回图鉴链接。
   - **全宽表格**：列 = 家具（图标+名称，品质色）/ 来源（简述）/ 数量（步进 − ＋）/ 容量·件 / 小计 / 操作（移除）；空态引导「去图鉴挑装饰」。
   - **批量操作条**：全选、批量移除、批量 +1、已选 N 件 · 小计容量。
   - **右侧摘要卡**：总件数、容量合计 `Σ(placement_cost×qty)` 与进度条（参考上限 2000，超仅标红不阻断）、「导出」按钮（跳导出弹窗，预置当前方案）、「分享方案」disabled（灰显 + tooltip「三期社区开放」）、云端同步提示。
   - 侧栏「方案单」项 + 图鉴抽屉入口**徽标同源**（当前方案总件数，实时联动）。
   - 未登录进入本页 → 与抽屉同口径：可看草稿、点保存跳登录；不另造逻辑。
3. 三态齐全（加载/空/失败重试）；768px 窄屏表格横向滚动 + 摘要卡下移；`node --check` 全过。

## WP2-2：导出图片模式 + 三皮肤 + 阵营水印（纯前端 Canvas，零依赖）

### 需求

1. **导出弹窗升级**：补 tab 壳「文字预览 / 生成图片」——文字模式（WP1 已有）迁进 tab 不动逻辑；图片模式为默认聚焦 tab 的次位。
2. **图片模式弹窗**：
   - 左侧 Canvas 实时预览（当前方案数据）；右侧控件：边框皮肤三选一 radio（默认·管家金边 `#C9A869` / 联盟·狮蓝 `#4A7FBF` / 部落·战红 `#B03A2E`）。
   - 「保存图片 PNG」（gold）：`canvas.toBlob` 触发下载，文件名 `{方案名}-魔兽管家.png`。
   - 「复制图片到剪贴板」（ghost）：`navigator.clipboard.write(ClipboardItem)`；**不支持时自动降级为下载 PNG 并 toast 说明**（台账定案口径）。
3. **Canvas 绘制规格**（逐条执行，绘制顺序即图层顺序）：
   - 卡片底圆角矩形（半径 ≤8px），**边框 3px 用当前皮肤色**；深色底（`#0F1115` 系 CSS 变量）。
   - 标题区：方案名（金/肤色系标题色）+ 件数。
   - 清单行：名称 ×qty（容量/件 小字），行高随内容，**卡片高度 = 内容自然高度**（默认最小高，清单变长则变长——水印不撑尺寸）。
   - 合计行 + 页脚固定行：`魔兽管家 · 家宅图鉴免费组单：https://wow.ddctl.com/decor.html`。
   - **水印最后绘制但垫于文字逻辑下**：实现上先绘制水印再绘制文字层，或分层双 canvas 合成——最终效果 = 水印在最底层、文字清晰在上。**锚定右下角：右缘/下缘各 16px；绘制宽度 150px**；**不透明度 18%**；按皮肤选素材：金边→`wm-wb-shield.png`、联盟→`wm-alliance.png`、部落→`wm-horde.png`（路径 `assets/decor-brand/`）。
   - 出图尺寸：导出 PNG 宽度 **≥ 900px**（2 倍屏保真），高度随清单；`devicePixelRatio` 适配预览模糊问题。
4. **素材与版权口径**：素材为暴雪官方美术抠图（过渡使用），代码注释与文档标注「正式上线前评估简化重绘」（台账在案）；素材缺失（404）时优雅降级：无水印出图，console 告警，不阻断导出。
5. 二维码入口：三期再评估，本 WP 不做。

### WP2-2 验收

- 三皮肤 × 有/无清单各一张导出 PNG（报告附原件）：边框色值正确、水印右下 16px 锚定、宽 150px、透明度落在 0.15–0.20、文字层清晰不被压。
- 像素级复核（顾问侧用 PIL 复验）：导出图宽度 ≥900px；右下角 150px 水印区存在且暗度合规。
- 复制图片成功/降级两路径实证；切皮肤预览即时刷新；清单变长卡片变长、水印始终不出框。
- `node --check` 全过；零依赖零构建声明。
