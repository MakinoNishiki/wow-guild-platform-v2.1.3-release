## WP1：侦察定案 + 数据管线 + 应用内图鉴页（纯前端）

### 需求

1. **先侦察再定案（六项，先出侦察节再动手，写进修改报告）**
   - ① `assets/decor-icons/` 命名规则实态（按 icons_manifest.json 核对：文件名=fileID 还是 record_id），确定 `<img>` 拼路径规则；`_placeholder.png` 兜底逻辑（icon_file_id 为空 41 件 + onerror 双保险）。
   - ② `dataPublic.js` 双壳同源机制 + 应用内副本掉落页的数据加载/筛选 UI 复用度清单——**定案倾向：最大复用**，图鉴数据层新建独立文件（建议 `js/decorData.js`），不污染现有掉落页逻辑。
   - ③ **货币/物品中文名映射表**：上述 25 个 currency_id + 11 个 item_id 逐个查中文官方名（wowhead 中文站或游戏内），产出映射草案（标注出处），**先报顾问终审再落常量**；texture 固定渲染为「腐化」系文案（至暗之夜腐化货币贴图）。常量建议落 `js/decorDict.js`。
   - ④ category_ids / subcategory_ids 中文分类名可得性（游戏内 Housing API 分类接口或 wowhead）：可得则出映射草案同审；不可得则一期分类维度用 tags 组代替，在报告如实说明。
   - ⑤ **宠物窝类候选清单**：以 can_customize=true + 名称/tags 关键词（宠物/笼/窝/食水盆）圈候选，清单入报告**报顾问终审**；定后落静态常量，筛选项「可放宠物」。
   - ⑥ 列表性能方案：**定案倾向=分页（每页 60 件）+ `img loading="lazy"`**，不自研虚拟滚动、不引入任何库。
2. **数据管线（只读，DB-first 不涉写入）**
   - REST 拉取列：`record_id,entry_type,name,icon_file_id,quality,size,placement_cost,category_ids,tags,indoors,outdoors,can_customize,source_text,sources`。
   - **防坑：PostgREST 单请求上限 1000 行，必须分页循环拉满 2062 行**（判停：返回批<1000）；拉齐后前端内存索引，筛选全程内存计算不再请求。
   - 加载失败/空结果必须明示（禁止静默失败）；加载中有进行态。
3. **图鉴页（应用内，viewer 及以上可读，纯浏览零操作）**
   - **网格卡片**：128 图标 + 名称（按 quality 着 WoW 品质色：0 灰 1 白 2 绿 3 蓝 4 紫 5 橙）+ 容量徽标（placement_cost）。
   - **筛选栏**：名称搜索（模糊即时，无不必要 debounce）；来源类型（十类中文签：商人/任务/掉落/成就/制造/商城/宝藏/事件/节日/无来源）；资料片（tags 组）；容量档（1-2 / 3-4 / 5+）；摆放环境（室内/室外/均可）；「可放宠物」（窝类清单）；「房间/户型」（entry_type=2）。筛选变更即时刷新 + **结果计数条**（「共 N 件」）。
   - **详情弹窗**（只读弹窗不涉 modalDirtyChecks）：大图标、名称、品质、容量、size、indoors/outdoors、tags chips、**来源渲染**——规格表：
     - shop→「商城购买」；vendor→「商人：{vendor}（{zones 顿号连}）· {price} {reputation?}」；drop→「掉落：{drop}（{zones}）」；quest→「任务：{quest}（{zones}）」；achievement→「成就：{achievement}（{category}）」；profession→「制造：{profession}」；treasure→「宝藏：{treasure}（{zones}）」；event→「事件：{event}」；festival_note→note 原文。
     - price 渲染：`{gold:500}`→「500 金」；`{gold:2,silver:50}`→「2 金 50 银」；`{amount:20,currency_id:3363}`→「20 × {货币名}」；`{amount:1,item_id:...}`→「1 × {物品名}」；`{amount:100,texture}`→「100 × 腐化」。多段 price 用「 + 」连接。
     - **sources=[] 兜底**：渲染 source_text 原文（剥离 `|c........`/`|r`/`|n` 标记与 `|T...|t` 贴图标签）；source_text 亦空（75 件）→「来源未知」。
   - **三态齐全**：加载中骨架/文案、空结果态、失败重试态；动效 150-250ms 仅 transform/opacity；深色 WoW 主题、CSS 变量、≤8px 圆角、768px 断点（窄屏网格降列、筛选栏折叠）。
4. **应用内最小入口**：现有导航加「家宅图鉴」一项（位置报运营确认截图）；**导航分组重构与首页耦合不碰（#52）**。
