## 修正项①（BUG）：特效卡展开后文本重复

现象：折叠态显示截断文本（省略号收尾），展开后**完整文本从头重新渲染**——折叠态已展示的字段与展开态重复一段，视觉上是「重复」而非「衔接」。
定稿逻辑：折叠态只显示截断片段 + 省略号；展开态显示**完整全文**（展开即替换，不是「片段+剩余」拼接，也不是「片段+全文」重复）。实现上建议：同一份文本两处渲染，折叠态 CSS 截断（line-clamp）、展开态完整，由状态类切换——**关键是确认展开态渲染的是全文本身而非拼接**。悬浮（桌面）/点击（移动端）触发与 250ms 过渡维持补丁3 现状不回归。
验收：长文本卡展开前后逐字比对——展开后全文与数据源完全一致、无重复子串；省略号后衔接的正是被截断部分。

## 修正项②：折叠控件加大 + 副本级折叠

1. 现有折叠箭头太小（实测难点多）：折叠/展开控件热区 ≥24×24px，图标加粗（描边 2px 级），常态次要色、悬浮提亮；BOSS 级与区块级同规格；
2. **补副本级折叠**：团本区块内各团本（虚影尖塔/进军奎尔丹纳斯/…）、大秘境区块内各副本（艾杰斯亚学院/魔导师平台/…）均有折叠头（副本名 + 件数徽标 + 折叠控件）；
3. 层级：区块（团本掉落池/大秘境掉落池）→ 副本 → BOSS，三级折叠互不干扰；折叠记忆（sessionStorage）覆盖新增的副本级；
4. 默认全展开；「新本」徽标在折叠头保持可见。
