类型：前端样式调整

## 一、需求

副本掉落公示页（data.html）装备卡片图标从当前约 36px 放大到 **48px**。

用户已确认选择 C 方案（48×48）。

---

## 二、修改范围

仅 data.html 装备卡片图标尺寸，不涉及 Decor。

### CSS 修改（data-public.css 或等效样式文件）

```css
/* 当前 */
.item-icon, .loot-icon {
  width: 36px;
  height: 36px;
}

/* 改后 */
.item-icon, .loot-icon {
  width: 48px;
  height: 48px;
}
```

### 同步调整（如需要）

- 卡片内边距 `padding` 适当微调，避免 icon 贴边
- icon 与右侧文字间距 `margin-right` 保持 8px 或微调至 10px
- 确保 48px icon 在卡片 220px 宽度内不挤坏布局

---

## 三、验证标准

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 图标尺寸 | F12 Computed → width=48px, height=48px |
| 2 | 卡片布局 | 220px 卡片内不溢出、不挤坏文字 |
| 3 | 多行标签 | 属性标签（智力+167 等）不被挤出卡片 |
| 4 | 响应式 | 768px 断点下卡片正常 |
| 5 | 所有装备 | 基希克斯破封 + 8 大米本全部装备卡片正常 |
| 6 | Console | 零红字 |
