# 个人块环节1：进入个人空间

依据开发规范、UI工作方法及2026-11-08分块验收规则。范围仅为入口和访问边界，不推进角色字段、展示主页或多人功能开发。

## 现状核对
- 首页和公开功能页：登录后顶部显示用户中心，仅依赖账号，不依赖公会（iaSyncTopRight）。
- 用户中心：打开个人资料、我的角色；无公会时隐藏公会卡（renderUcGuildCard）。
- 团队管理：无公会时进入加入/创建引导，保留用户中心与首页入口；引导说明公会要求仅适用于团队功能（iaApplyRoute/iaRenderTeamGuide）。
- 家宅方案：个人路由不要求公会；无公会真实保存与刷新恢复已在REQ-187隔离数据库联验通过。
- 游客：显示登录/注册入口；团队加入、创建控件禁用，公开浏览保留。

## 证据与边界
既有证据：docs/evidence/req187-20261107/verification.json（真实Chrome+独立Supabase，含无公会登录、角色保存、方案读写与换号隔离）。本次入口审计见design-plans/personal-entry-audit-20261108.md，以审计实际结果为准；模拟会话入口检查不能作为真实登录认证测试。

## 运营验收
| 编号 | 操作 | 通过标准 |
|---|---|---|
| 1 | 登录后从首页打开右上角用户中心 | 能打开个人资料和我的角色，无需先进入团队管理 |
| 2 | 在家宅图鉴或副本掉落页打开用户中心 | 入口可见、正常打开；关闭后仍在原页面 |
| 3 | 无公会账号进入团队管理，再返回首页 | 团队页提示加入/创建公会；可返回首页，个人入口仍可用 |
| 4 | 无公会账号打开我的角色及家宅方案 | 可进入，不被加入公会弹窗强制阻断 |
| 5 | 退出登录后浏览公开页 | 顶部恢复登录/注册；不显示上个账号的用户中心身份 |

不要求退出正式公会或解除WCL。没有无公会账号时，可先验1/2/5；3/4已有开发联验证据，是否据此接受由运营决定，代理不自行标通过。
