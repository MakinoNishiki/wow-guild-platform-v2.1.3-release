# 任务书 #203 · 家宅作品分享、家具收藏与图鉴预览

2026-11-20。合并 REQ-203、REQ-207 和 REQ-209 的本轮反馈。作者可以只展示装修，也可以自愿附上用量。读者在作品里收藏装修灵感，在图鉴里将要购买的家具收藏到自己的方案单。

## 运营验收清单

| 位置 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 家宅图鉴 → 家具详情 | 点「点击游戏内预览」 | 按钮下方出现绿色的「已复制。在游戏聊天框粘贴并按回车即可预览。」。剪贴板受限时会选中命令并给出金色的手动复制提示。国服游戏内粘贴并回车是本项最后一步。 |
| 家宅图鉴 → 家具卡片 | 点空心爱心、刷新、取消，再打开家具详情 | 爱心会变实心，刷新保留，取消后恢复空心。列表可直接看点赞、收藏、浏览。浏览只在打开详情时记录，同一访客对同一家具 30 分钟内计一次。 |
| 家宅图鉴 → 方案单 | 收藏家具，点「查看方案单」，再从图鉴选另一个方案或新建方案 | 收藏直接写入方案。侧栏红点随新收藏递增，进入方案页清零。已收藏按钮直接打开方案页，页内可调数量、保存、导出。同一账号把同件家具放进两份方案，公开收藏人数仍为 1。 |
| 家宅分享 → 创建或编辑作品 | 分别留空、选满 6 个预设、填满 3 个自定义标签，保存草稿后重开，再发布 | 81 个预设按风格、种族、资料片、节庆和配色分组。两类标签独立计数，超额有提示。作品卡片和详情均可看到发布时选用的标签。 |
| 作者工作区 → 家具用量 | 搜索图鉴家具并填数量，或粘贴已有清单，核对预览后保存 | 只纳入图鉴能识别的装饰，可修正数量、移除或清空。批量清单会标出跳过的类型与未收录的编号。同编号的房型或外设不会认作家具。作者也可留空后直接发布。 |
| 公开作品 → 家具清单 | 悬停或用键盘聚焦家具，进入图鉴，返回后填写自己的可用量 | 来源、地点和参考价格沿用同一份图鉴资料。填 0 表示没有，留空表示未知；有可用量时才算缺件。刷新后可以读回，其他读者看不到自己的数量。 |
| 公开作品 → 社区互动 | 登录后点赞、收藏、留言，切到「我的收藏」查看；再试一次取消点赞 | 点赞和收藏可撤销。个人收藏能找到仍然公开的作品；作者撤回后从公开列表、热门和收藏列表消失。基本词库会拦截不合规留言并提示原因。 |
| 作品或留言 → 举报 → 用户中心 | 提交原因和说明，以管理员身份处理，再回到举报账号查看通知 | 管理员可驳回、隐藏留言、下架作品，以及复查恢复。举报人收到受理和处理结果；重复提交待处理举报会合并。已下架作品的图集、蓝图与互动同步收回。 |
| 公开作品 → 近七日热门 / 标签筛选 | 查看有互动的作品，按一个预设或作者自定义标签筛选，点进详情再返回 | 作品按近七日有效点赞、收藏和公开留言合计排序。过期互动退出，返回后保留筛选。 |

## 验证与发布

整包 29 项检查通过。本地 Chrome 在 1366 和 1920 像素两档宽度留存截图，隔离 PostgreSQL 与 PostgREST 用于保存、刷新回读、权限与重复迁移验证。网页已实测至命令写入剪贴板。实际国服游戏内执行由运营验收。网页拖拽 3D 目前覆盖已转换并核对的 26 件家具，图鉴的「可看 3D」筛选可直接找到这些家具。

作者手头已有的家具数据可批量附单。国服原生蓝图短码可按作者设置提供复制，网页仅凭短码自动取全套家具的接口仍待证实。

本包待提交、部署及运营验收。生产 SQL 52 已随上一版上线。本包随新版依次执行 SQL 53（标签）、54（家具用量及个人数量）、55（互动、举报与回执）、56（热门与筛选）、57（方案单收藏统计）。发布后回读公开作品与原有方案，再验证作者保存、访客浏览和举报回执。
