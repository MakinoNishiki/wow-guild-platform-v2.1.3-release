## 二、修法文本（逐函数最小手术清单）

总原则：**只动 exportInstances / collectTiers / doExport 三个函数 + whenItemReady 一处包装 + 枚举入口两处钉档**；getLootItemID/getItemBasics/parseItemDetail/scanLink/parseStatLines/statValuesFromApi 等 1.0.9 时代稳定解析路径一律不碰。

### A 组｜BUG-086 跨跑态污染根治（最高优先，run2 病灶）

- **A1 难度档保存/还原改必经路径**：`origDiff` 捕获从 `if tierAlive`（:376-379）移到段首无条件执行（大米段也捕获）；还原从 nextInstance 终局（:388）移到 `done(out)` 调用前的统一 finalize（正常/异常殊途同归）；**origDiff=nil 时显式还原到 normal(14) 并黄字注明「手册难度原未设置，已归位普通档」**——消除 mythic 残留跨跑污染。
- **A2 枚举前钉难度+回读校验（与 REQ-119①合并实施）**：阶段一实例枚举循环内、`EJ_SelectInstance` 之后加 `EJ_SetDifficulty(锚定档)+EJ_GetDifficulty 读回`，读回不符黄字并记该实例「钉档失败」；团本段锚定 normal(14)（枚举基准档，四档重扫自行逐档切换不受影响），大米段锚定史诗(23)（M+ 掉落表基准，REQ-118 档位枚举的基准点）。
- **A3 异步回调链 pcall 包裹**：`whenItemReady` 内两处 `fn()` 调用点（ContinueOnItemLoad 回调 :315-319、C_Timer.After 回退 :323）包 pcall；捕获后 err 红字（实例/BOSS/物品 ID 具名）并强制 `stepItem()` 推进——链不死、锁不卡。
- **A4 段 abort 标记防双推进**：`pcall(seg.run)` 捕获跳段时（:571-575）置 `seg.aborted=true`；段内链的每个推进点（nextBoss/nextInstance/stepItem 入口）首行检查 `seg.aborted` 即退出。
- **A5 EJ 选中态 pcall**：:406-407 `EJ_SelectInstance/EJ_SelectEncounter` 补 pcall，失败红字跳该 BOSS（不炸链）。
- **A6 run 标记+时间戳（REQ-119③）**：buildMeta 加 `run_id`（`date("%Y%m%d-%H%M%S")`）；导出开始/结束黄字打印 run_id+时间戳，导出文件 meta 同值——日志与文件可互查。

### B 组｜BUG-083 熔断撤除（顾问约束：熔断若保留仅单件粒度、永不跨 BOSS 蔓延——方案=整删熔断器）

- **B1 删熔断**：移除 `tierAlive=false` 全局熔断（:434-437）与 `softFail` 喂入；每个 BOSS 独立尝试切档（切档读回校验 :236-239 本身就是天然逐 BOSS 闸）。`softFail` 改纯计数，段尾黄字汇总「N 个 BOSS 未出档值」。
- **B2 撤 BOSS 级回退**：软失败（全件静默跳过）不再 `stripTiers`——已采到的部分档值保留，按 C 组新文案报告；硬失败（pcall 炸）保留 strip 但先黄字报告已带档件数再抹（留证据）。
- **B3 collectTiers 返回值改造**：:273-275 整 BOSS 判死删除，改返回逐件逐路径计数表（见 C 组），永不 return false。

### C 组｜BUG-084 分开报错（含五条闭环②的段级红字做实）

- **C1 逐件逐路径计数**：:243-244 守卫处起计 `noLink`（info 非表/无 link 键）、`idMismatch`（itemID 对不上）、`scanFail`（SetHyperlink pcall 失败）、`noValue`（扫到 tooltip 无静态值）、`notReady`（未就绪件，见 D 组）。
- **C2 分案文案**：`noLink>0 且 scanned==0` →「稀疏表缺 link 字段（数据源缺，物品 ID 列顾问评估）」；`idMismatch>0 且 scanned==0` →「跨难度掉落列表错位（守卫拦截）」；`scanned>0 且 tiered==0` →「0 件出档值（疑全为无静态属性品类/冷缓存空 tooltip）」。
- **C3 带档黄字扩充**：「四档重扫完成（X/Y 件带档）」（:432）扩为「X/Y 带档（缺档：noLink=a 错位=b 未就绪=c 无静态值=d）」——一次导出即定位，免逐件 probe。
- **C4 段级中断红字做实**：:573 文案扩为「实例名+中断原因+恢复建议」（如「团本段导出中断（原因：…），其余段落不受影响；请 /reload 后重跑，仍现请截图反馈顾问侧」）。
