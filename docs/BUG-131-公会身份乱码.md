# 任务书 #191 补丁 · 成员权限中的中文身份

正式页面打开「公会 → 公会资料 → 成员权限」。有分配权限的会长可以点击一位团员右侧的「分配角色」，核对当前选中的名称，再关闭窗口。

## 定位与修复

- 运营截图里，两名使用兵卒徽记的成员显示「团���」。只读核对该公会的角色目录，系统团员名称的 UTF-8 字节为 `e5 9b a2 e5 91 98`，使用默认名称，修订号为 0。
- 用相同的游戏站点程序和隔离数据库，将角色响应切在「员」字的第一个字节后。修复前浏览器实际读到「团���」。数据库代理逐段把字节转换成文本，分段处的汉字被替换。
- 改用连续 UTF-8 解码。默认角色和会长自定的名称均使用原数据，数据库无需迁移。
- 交互审计发现，「分配角色」与「移除」同用弱化的文字，两者悬停均变红。分配现在使用主文字色，悬停为金色；移除使用次文字色，悬停为红色。键盘聚焦带描边。角色权限与操作确认沿用原有规则。

## 验证

- Chrome 中分别用会长与普通成员账号进入公会资料。会长看到完整的「团员」，点击行内「分配角色」可读到同名的当前选择；点击「移除」弹出具名确认，取消后成员保留。普通成员仅查看身份。
- 在持续对角色响应分包的条件下，会长创建「考勤官」、选择王后徽记、保存和分配；刷新后会长与团员两端可见。并发改名和未登录访问也已回归。
- 共 7 项角色浏览器检查、33 项自动化测试通过。静态版本为 `20261125.171`。正式库核对仅做读取，创建和分配在隔离环境验证。
