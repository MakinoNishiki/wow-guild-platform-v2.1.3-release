# 固定团双向招募 · 未来设想

2026-11-23 运营记录。关联历史需求 REQ-082，待以后评估，优先级未定。此次只保存产品设想。

## 档案、公开招募卡与私下联系

2026-11-25 运营确认三种阅读场景。公会档案和内部招募卡仅现任成员可看，含已填写的招募负责人联系方式。会长保存内部资料不会触发站外展示。

等招募平台排期后，只有会长主动关联招募板并发布，访客才可免登录浏览选择发布的招募信息。公开页默认隐藏联系方式；发布人可明确选择在公开卡上展示哪些联系渠道。未选择公开时，双方可在一次沟通中主动发送联系方式，或同意该对方查看。一次授权仅适用于当事双方与本次沟通，其他访客不能据此查看。发布前预览应清楚区分「所有访客可见」与「双方联系后可交换」。公开发布及点对点交流属于后续招募平台。

## 从一个真实缺口出发

国服正式服固定团正在开荒史诗乌拉特克，目标是「千钧一发」。团长要找能长期出勤的团员，优先武僧、猎人和鸟德，最好有 M8 经验。一次搜索要回答三件事：对方现在还找团吗？双方每周能长期重合几个晚上？对方在这个首领上的经历到了哪一步？

| 设计点 | 将来设计时保留的约定 |
| --- | --- |
| 谁在找谁 | 分设「团队招人」和「玩家找团」。团长能搜到的候选人须本人确认有求组意愿。公会招募官的微信、WCL 名单里的角色都不能据此生成玩家求组卡。 |
| 硬条件、偏好、未知 | 发布者分别指定必须满足的条件和影响排序的偏好。这个案例要求找长期团，三个职业和 M8 属于偏好。只填武僧时，专精显示「待确认」。出勤时间缺失时标注未知，避免误算重合天数。 |
| 经历与承诺 | M8 需对应赛季、副本、难度、首领，分别记录到场、打到某阶段、击杀。WCL 佐证对应角色的战斗经历。愿用的专精、每周可参加的晚上、能否跨零点由玩家本人确认。历史出勤供参考，未来约定另行记录。 |
| 履历与当前意向 | 角色、专精和已核实的经历可复用。求组意向与团队空缺各有最近确认日期，到期退出活跃搜索。已入团、已招满可一键关闭，重开时仅更新变化项。有效期留待试点确定。 |
| 从现有渠道迁入 | 玩家或团长可将自己的 NGA 帖、群公告文字或截图提取成草稿。链接无法读取时支持粘贴原文，保留来源，只追问缺失的关键项，由本人确认后发布。联系方式按本人选择的范围展示，群聊截图里的第三方微信不自动公开。 |
| 从搜索到试打 | 候选卡回答「为什么值得聊、什么待确认、怎么联系」。例如「鸟德｜本人确认找长期团｜三晚中两晚重合，周日待确认｜WCL 有本赛季乌拉特克 P2 记录」。双方可更新「已联系、已约试打、已入团、未匹配」，同团负责人能看到跟进状态，避免重复打扰。 |

## 首次验证

等运营排期后，用一个真实的长期鸟德空缺试跑。候选人可来自 NGA、微信群或集合石，请本人确认一张简短资料卡；记录玩家愿意填哪些字段、在哪一步放弃，以及团长还需追问什么。一个角色进过战斗名单不足以发起联系。

| 指标 | 试点记录方式 |
| --- | --- |
| 约成一次合适试打需联系几人 | 按不同候选人计数，多位负责人联系同一个人只计一人。 |
| 距首次合适试打几天 | 记录空缺发布日期、首次合适试打日期；尚未约成的缺口保留状态。 |
| 入团四周出勤 | 对照双方约定，列出实际出勤场数／约定场数。 |

后续观察团长再次缺人时是否主动重开职位、玩家是否愿意更新旧履历。这两个行为用来判断资料能否复用。历史 REQ-082 中的完整度排序、公开页和投递范围，留待重启时逐项核对。
