## “有特效”的准确含义

这份正例集只说明：**该家具对应的原始 M2 模型确实含有已通过结构校验的粒子或拖尾发射器定义**。不通过名称里的“火”“发光”“魔法”、主题标签、图片颜色或材质混合模式猜测。

不能把没进入正例集的家具标成“无特效”。贴图动画、灯光、透明发光材质、事件附加效果或外部附属模型未由这两个数组穷尽；即使存在发射器，实际可见性也可能受动画状态、显示设置等条件影响。本次没有在游戏内摆放这 513 件逐一观察，也没有让网页渲染粒子。

例如既有 3D 样例“玛卓克萨斯心能水晶”两个数组都为空，仍不能据此否定其材质效果。建议筛选值注明“模型含粒子／拖尾”；若界面沿用“视觉特效”，说明应明确“依据原始模型发射器字段，部分游戏效果暂未覆盖”。

## 生成方法和结构依据

复用 TASK-084 固定版本 wow.export 的只读 CASC 解包链路及本机已有的公共 TACTKeys 文件。远端回退显式禁用，原始读取要求完整 BLTE 解码。每个模型记录字节数、SHA-256、构建号和资产编号；同一资产只读取一次，再映射至使用它的家具。

扫描器逐块校验 MD21 容器边界，要求唯一 MD21 内含合法 MD20，限定已经确认布局的 v272/v273/v274。数组指针相对 **MD20 负载起点**，不是外层文件起点。读取 `ribbon_emitters` 与 `particle_emitters` 的数量和偏移，同时检查数组实际范围、现代记录步长、发射器坐标的有限值、粒子类型及拖尾材质／纹理索引。非零数量却指向零地址、越界、格式不支持等情况均记未知，不计正例。

第一手解析器与格式作者资料：

- [wow.export 固定源码 M2Loader](https://github.com/Marlamin/wow.export/blob/caf2bb0006930e151cd3810fba0f7d55e2e4b562/src/js/3D/loaders/M2Loader.js)：核对 MD21 包装与内层 MD20、头部字段顺序。旧导出器没有实际导出粒子／拖尾，因此此次直接核对原始数据，不从 GLB 倒推。
- [WoWFormatLib M2Reader](https://github.com/Marlamin/WoWFormatLib/blob/master/WoWFormatLib/FileReaders/M2Reader.cs)：独立核对模型头部两类发射器的 count/offset 字段。
- [WhiteoutLib 格式说明](https://github.com/sc2-arcade-watcher/WhiteoutLib/blob/libmodkit/docs/M2_FILE_FORMAT_SPECIFICATION.md)：核对 MD20 相对偏移 0x120 / 0x128，现代粒子 492 字节及拖尾成员布局；拖尾按该布局合计 176 字节。这里只实现所需的独立字段检查，不把另一解析库加入网站。

## 交付接口与文件

`js/decorEffectIds.js` 为普通浏览器脚本，需在能力筛选消费方前加载并由主任务统一 `?v=`：

- `window.DecorEffectIds`：数字 `record_id` 的 Set，仅含上述 513 个正例。
- `window.DecorEffectCheckedIds`：2,274 个已成功检查的家具编号。未命中仍可能是缺编号、后续新家具或其他未知项；不可据此推断没有任何游戏视觉效果。
- `window.DecorEffectScan`：构建号、目录 SHA-256、覆盖数量和含义来源说明。

采集脚本：`scripts/decor/scan_model_effects.cjs`。只读游戏；输出原始文件至 Git 忽略的 `scripts/decor/out/req209-effect-models/`（本轮合计 347,785,660 字节）。这些 bin 没有复制到公开 assets，没有新增网页可访问的游戏模型。

公开核对证据：`docs/evidence/req209-effects-20261119/scan.json`，逐家具保留映射、状态、文件哈希、数组地址和发射器字段；不含游戏账号、角色、作品或蓝图数据。
