## 一、调研依据节（调研前置硬约束）

**铁证（运营回传，1.0.23 冒烟转义 dump）**：八件 mythic 档疑似 dump 单元=「史诗\n毒咒」**单串、纯 `\n`、零杂码**——1.0.23 报告中的「夹中码/杂字符」假设证伪。

**悖论留档**：顾问侧 LuaJIT 实证——干净单串下 1.0.23 显式 `\n` 模式（乃至 1.0.18 旧跨行拼接模式）**理论必中**；真机未中 ⇒ **吃进匹配的串 ≠ dump 出来的串**。本侧复核佐证：fengari（真 Lua VM）对铁证串跑 1.0.23 旧模式同样必中（实测输出见自检节）。

**悖论剩余解释**（如实申报，本版不赌其中任何一个）：转义 dump 只显形 `\r`/`\n`/`|` 三符——**`\t`、U+00A0（不换行空格）、零宽字符（U+200B 等）不在显形范围内**，肉眼与转义均不可见；或加载层差异（真机跑的串经了某条未审计的加工路径）。`%s+` 定向能覆盖「分隔符是任何 ASCII 空白（含 \t）」一支；若真凶是 U+00A0/零宽这类**非 %s 字节**，`%s+` 同样不中——该分支的取证兜底（转义 dump）仍在，且已在遗留申报给出下一版定向（全字节 hex 显形）。

## 二、定位三答回执（逐行申报）

**①匹配点与 dump 点字符串来源——是否同一变量、剥码是否先于匹配？**
同一数组、同一元素、同一剥码函数。collectTiers 单档扫描体内 `lines = scanLink(info.link)`（WoWButlerExporter.lua:674）只扫一次；匹配侧 `parseStatLines(lines, d)`（:681）内 `plain = stripLineCodes(t)`（:289）**先剥码后匹配**；dump 侧（:710-714）遍历**同一个 `lines`**，`p = stripLineCodes(raw)` 判定、raw 转义打印。**头号嫌疑（匹配跑在剥码前原始串）证伪**——匹配输入=剥码后串；且 dump 铁证 raw 纯净 ⇒ plain==raw（stripLineCodes 对无码串恒等，逐 gsub 走查在案）。

**②行数组遍历是否把「内含 \n 的单行」整体进匹配、跨行拼接只跑行间？**
成立。`readTipLines()`（:229-237）按 FontString 整行取 `GetText()`，**内含 `\n` 的单行作为一个数组元素整体进匹配**；跨行拼接 `(prevPlain..plain)` 只跑相邻元素之间，够不到元素内部——这正是 1.0.23 加单串形态级的原因。次号嫌疑形态成立，但 1.0.23 已按此形态书写仍不中，故形态不是病根、字节才是。

**③1.0.23 新级 `\n` 的写法是普通字符串 `"\n"` 还是 `"\\n"`/`[[]]`？**
**普通双引号字符串内 `\n` 转义**（正确写法）。od 实证（1.0.23 存档文件）：模式段文件字节为 `5C 6E`（反斜杠+n 两字符），Lua 加载后=真实换行字节；非 `\\n`（双反斜杠）、非长括号串。顾问实证「后两者不中」与写法核验结论一致——写法无错。

## 三、修法（顾问定向，最小手术）

单串形态级模式：`^史诗%s*\n%s*毒咒%s*$` → **`^史诗%s+毒咒%s*$`**——不指名换行符，`%s+` 通吃 `\n`/空格/`\t`/混合空白形态。免疫锚不变：`^史诗` 起锚 + `毒咒%s*$` 收尾，名行以字续不命中、flavor 以「。」收尾不命中、兑换物名行不命中（一级 `^毒咒%s*$` 精确等值不放宽）。

改动两处（一致性强制）：
1. 匹配级 `WoWButlerExporter.lua:316`（elseif 一支，表达式级替换）；
2. 疑似 dump 豁免条件 `:712`（同步为同一模式——命中新形态的行不误报 dump）。

跨行拼接级 `史诗%s*毒咒%s*$`（1.0.18）与一级 `^毒咒%s*$`（1.0.9）**零改动**。导出字段格式零改动。

## 三之二、预授权并入：字节级 hex dump（2026-08-15 运营预授权，不升版本号）

**背景**：1.0.24 送审后，顾问与本侧残余风险判断一致并升级为主嫌疑——三答闭合后唯一自洽解释=**不可见非 %s 字节**（U+00A0 不换行空格 / U+200B 零宽空格 / U+FEFF BOM / U+3000 表意空格），转义 dump 只对 `\r`/`\n`/`|` 三符显形、对该类字节**失明**，故 `%s+` 存在不中概率。运营预授权：hex dump 直接并入 1.0.24，%s+ 不中当轮即出字节。

**落地（仅打印路径，最小手术）**：
- `WoWButlerExporter.lua:267` 新增常量 `VENOM_HEX_IDS`（八件 ID 集合，2026-08-14 运营终裁名单）；
- `:731-734` 疑似 dump 分支内追加：命中疑似行且 `it.id ∈ VENOM_HEX_IDS` 时，多打一行「毒咒疑似行 hex（物品 N，mythic 档）：XX XX XX…」——`raw:gsub(".", function(c) return string.format("%02X ", c:byte()) end)` 逐字节十六进制，对 raw 原文取字节（不经剥码，零信息损失）。
- 限定八件 ID=打印量封顶（每件每档至多一行），非八件疑似行行为完全不变。

**终修方向预置（运营已批方向，待 hex 证据再动，本版不实施）**：stripLineCodes 剥码后追加字节归一化（C2A0→空格或剔除 / E2808B 剔除 / EFBBBF 剔除 / E38080→空格），模式回归 `^史诗%s*毒咒%s*$`。
