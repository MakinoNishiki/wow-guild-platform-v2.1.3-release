# REQ-194 分配信息修复与验收

## 原因与改动

运营图1中优等生的晚拾取仍为“待核对”，因此旧界面不显示转分配；缺少首领并不是禁止分配的条件。现明确提示“先核对，再分配”，核对面板新增“确认并填写分配”。只有核对成功才打开分配表单；取消、失败、公会变化不继续。首领空显示“未采集”，可在分配表单补充，原始拾取证据不修改。

最终获得者下拉复用IconMap.classColor与原职业类。选项保留名字、服务器、职业，保存仍以成员ID区分跨服同名；待分配时清空获得者及颜色。原生下拉当前选中/高亮项保留既有金色或系统高亮底色，未选中选项与收起的已选值采用职业色。

分配表新增独立装等列，保留难度列；INVTYPE部位统一用现有词表显示中文，分配方式覆盖掷骰/按规则掷骰/团队议会/团长/团本积分/贡献装备积分/金币竞拍/自定义。规则掷骰显示已保存点数。旧数据不需要重导，也不批量改写库内代码。表内横向滚动保留，装备名称设最小宽度防止竖排。

## 运营验收（本块独立）

1. 拾取记录打开优等生晚拾取：显示“未采集”和“先核对，再分配”。点核对→确认并填写分配，能够进入分配表单；缺首领可补“盘卷祭坛”，无考勤活动也能保存。
2. 选择最终获得者，展开下拉检查职业色；跨服同名可分辨。保存后刷新仍为正确获得者。
3. 分配表装等344、史诗、腰部/胸部/腿部和中文分配方式清晰；重新编辑修改仍保留。
4. 原记录已转过分配时显示“查看分配”，重复保存不多一件。未核对/失败不会自动产生分配。
