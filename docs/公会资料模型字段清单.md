# 公会资料模型字段清单

> 版本 V1.0（2026-07-26）。依据：NGA 招募帖分层抽样（名人堂进度团完整帖 1、休闲/萌新团完整帖 2、求职串 1、全版招募标题语料库数千条）。
> 用途：REQ-025（公会介绍字段）、REQ-013（公会公开页）、V3.0（招募求职）三处的统一设计依据。

---

## 一、公会资料（长期身份档案）

| 字段 | 类型 | 必填 | 说明 / 枚举 | 覆盖依据 |
|---|---|---|---|---|
| 公会名称 | text | 必填 | 已有 | 全类型 |
| 服务器/大区 | text | 必填 | 已有 | 全类型 |
| 阵营 | enum | 选填 | 联盟 / 部落 / 双阵营混编 | 高频；现版本跨阵营跨服普及 |
| **分配制度** | enum + text | **必填** | ROLL / 一需多贪 / CL（团长分配）/ 其他自定义 + 自定义规则说明 | 种子-003 核心诉求（REQ-025） |
| 公会简介 | text | 选填 | 公会史、理念、氛围描述 | 全类型高频 |
| 团队类型 | 多选 enum | 选填 | 进度名人堂团 / 千钧一发团 / 休闲进度团 / 休闲社交团 / 大秘境团 / 萌新团 | 分层抽样全覆盖 |
| 活动日 | 多选 | 选填 | 周一~周日（如"412"=周四一二） | 全类型必填级高频 |
| 活动时段 | time range | 选填 | 如 20:00–23:00 | 全类型必填级高频 |
| 活动强度说明 | text | 选填 | "不加班""9点档""中年早睡团"等高频表述 | 标题语料高频 |
| 当前版本进度 | text | 选填 | 如 M4/8；远期由活动数据自动生成 | 进度团必填 |
| 历史荣誉 | text | 选填 | 名人堂、服务器首杀等 | 进度团核心卖点 |
| 氛围标签 | 多选 enum | 选填 | 上班族 / 中年团 / 午夜团 / 白天团 / 萌新友好 / 跨服跨阵营 | 标题语料高频词 |

## 二、招募信息（V3.0 状态层，可随时开关）

| 字段 | 类型 | 说明 / 枚举 | 覆盖依据 |
|---|---|---|---|
| 招募状态 | boolean | 与 REQ-013 公开/隐身联动 | — |
| 招募对象表 | 结构化 | 职业 × 专精 × 需求度（高/中/低） | NGA 招募帖标准格式 |
| 招募要求 | 多选 + 自定义 | WCL 分数 / 出勤率要求 / 多修优先 / 不接受打包求职 / 竞争上岗 / 无黑历史 | 进度团高频 |
| 公会福利 | 多选 + 自定义 | 公修 / 合剂大餐 / 爆发药 / 凡图斯 / 包机票（转服报销） | 标题语料高频卖点 |
| 公会 WCL 主页 | url | NGA 招募版规强制附 WCL | 版规 + 高频 |
| 联系方式 | text | 微信 / 战网 ID；可附"不强制加群"说明 | 全类型 |
| 寄语/补充说明 | text | 自由发挥区 | 全类型 |

## 三、玩家简历（V3.0 求职侧设计输入）

| 字段 | 类型 | 说明 |
|---|---|---|
| 主角色 | 结构化 | 职业 / 专精 / 装等 / 服务器 |
| 团本经验 | text | 版本 + 进度（如 11.1 M8/8） |
| WCL 链接/分数 | url / text | 求职帖高频 |
| 可出勤时间 | text | 每周天数 + 时段 |
| 意向团型 | enum | 进度 / 休闲 / 大米 / 均可 |
| 平台履历附件 | 系统生成 | **出勤率、装备获取史、诚信记录（REQ-019）——我们的差异化资产，玩家授权后展示** |

## 四、设计原则

1. **资料与招募分离**：资料是身份（长期稳定），招募是状态（随时开关、随版本更新）；
2. **枚举 + 自定义兜底**：枚举保证可筛选可统计，自定义文本保留魔兽圈千奇百怪的表达空间；
3. **公开边界**：REQ-013 公开页只渲染资料与招募字段；考勤、装备、心愿单等内部数据永不公开；
4. **一次填写多处生效**：分配制度自动带出到装备分配弹窗（REQ-025）、资料自动渲染到公开页（REQ-013）、招募字段直接生成招募帖（V3.0）。
