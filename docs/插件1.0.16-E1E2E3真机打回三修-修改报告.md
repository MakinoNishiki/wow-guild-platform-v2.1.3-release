## 二、E2（P1，REQ-088 残差）：venomcurse 全场零命中

**代码面事实申报**（出入必报纪律）：毒咒读取点自 1.0.12 起**已在史诗档通道内**（collectTiers 按档链接 parseStatLines 提取），并非仍停锚档平面 tooltip——但真机零命中，说明命中面被两处击穿：
1. **精确等值过脆**：`plain == "毒咒"` 不容许行尾空白/残留码，一行尾随差异即全场漏；
2. **只锚史诗档单点**：史诗档被跳档/陈旧拦截时无其他档兜底（虽终案「毒咒行=史诗独有」，但档链接 tooltip 是否严格如此未经逐档实证）。

**修法**：
- 匹配改 `plain:match("^毒咒%s*$")`（容许行尾空白）；
- **任一档 tooltip 出现毒咒行即采**（安全超集：其他档天然无此行则不触发；effect 仍只存史诗档文本不动）；
- **疑似行取证**：史诗档扫描后 d.venomcurse 仍空时，对含「毒咒」字样但非精确命中的原行黄字 dump（| 转义 ||，带物品 ID+档 key）——若下轮真机仍零命中，该取证一锤定音区分「行不存在（EJ 预览态数据缺）」与「行形态不符（检测再修）」。

**判据不变**：271876 `venomcurse=毒咒`。

## 三、E3 = BUG-092（P2）：258045 黎明之刃的战刃 primary 空

**代码面嫌疑位**：parseStatLines 数值属性行 `^%+([%d,]+)%s*(.+)$` 锚定在**原始行**上匹配——1.0.9 的行首码剥离只罩特效/毒咒分支，未罩属性行；该件属性行若带行首码/行尾收色码即失配（千分位/数值本身无恙）。
**修法**：属性行解析先 `stripLineCodes` 再匹配（纯文本行零影响，特效/毒咒复用同一 plain）。
**如实申报**：若修后该件仍空 = EJ 预览态 tooltip 数据侧缺行（代码面无更多嫌疑位），需 `/wjdc probe hover 258045` 取证后另议。
