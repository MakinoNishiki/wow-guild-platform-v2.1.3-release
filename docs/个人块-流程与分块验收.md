## 每块固定记录模板
- 范围与不包含内容
- 已有能力及证据
- 本块缺口和实际改动
- 验收操作及通过标准（含保存、刷新、失败反馈、权限/隔离等适用项）
- 自测结果与限制
- 运营验收结论、日期及反馈依据
- 遗留项及去向
- 状态：待盘点 / 待实现 / 自测中 / 待运营验收 / 验收通过
