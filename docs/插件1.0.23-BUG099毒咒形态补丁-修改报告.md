## 一、调研依据节（调研前置硬约束）

**真机取证（运营回传，run 20260815-005810）**：毒咒八件 mythic 档疑似 dump 单元均呈「史诗↵毒咒」**合在一格**——与 1.0.17 时代取证的「史诗↵毒咒」分两行形态不同。

**主嫌疑**：12.1 以**单串内嵌 `\n`** 形态交付毒咒行——1.0.18 的「上一行剥码以史诗收尾 + 本行拼接」跨行匹配够不到（格力只有一行，没有「上一行」可拼）。

**必须如实申报的疑点**：旧跨行拼接 `(prevPlain..plain):match("史诗%s*毒咒%s*$")` 无 `^` 锚、且 Lua 的 `%s` 类本身含 `\n`——**理论上单串「史诗\n毒咒」合一格时旧码就能匹配上**，但真机 0/8 未中。这说明真实字节形态大概率**不是**干净的「史诗\n毒咒」（可能夹 `|r`/`|cff` 中段色码或其他杂字符——stripLineCodes 只剥行首行尾码，串中码不剥）。**若如此，运营给的新 pattern ①也可能仍不中**——这正是补丁②转义 dump 兜底的设计意图：下一跑字节显形，一锤定音，零猜测定向下一版。

**结论**：①按运营处方原样落地，**不声称必中**；②为①失败分支的取证兜底，两条互不依赖。

## 二、补丁三条回执

**①匹配加第三级——单串内嵌换行形态**（`WoWButlerExporter.lua` parseStatLines :313-321）：

```lua
if plain:match("^毒咒%s*$") then                    -- 第一级：纯毒咒行（1.0.9 起，不动）
  d.venomcurse = "毒咒"
elseif plain:match("^史诗%s*\n%s*毒咒%s*$") then    -- 第三级（本版新增）：单串内嵌换行
  d.venomcurse = "毒咒"
elseif prevPlain and (prevPlain .. plain):match("史诗%s*毒咒%s*$") then  -- 跨两行（1.0.18，不动）
  d.venomcurse = "毒咒"
end
```

免疫锚不变：装备名行以字续不命中（`^史诗…毒咒$` 全串锚定，名行后缀不贴边）、flavor 句以「。」收尾不命中（`$` 锚挡）。免疫侧（兑换物五件+270165）1.0.22 真机正确未误标，本版零改动。

**②疑似 dump 转义可见化**（collectTiers :709-712）：dump 内容 `(raw:gsub("\r","\\r"):gsub("\n","\\n"):gsub("|","||"))`——`\n` 显形为字面两字符（防聊天框真换行吃掉形态）、`|` 显形为 `||`（WoW 聊天转义，色码管道符逐字节可见）。同时 dump 触发条件加豁免 `not p:match("^史诗%s*\n%s*毒咒%s*$")`——命中新形态的行不再误报疑似 dump。

**③毒咒八件全中列入冒烟硬项**：八件（268215/268202/268207/271874/271875/268265/271876/271878）均在冒烟范围烈毒之渊内——`validate-export.js` 冒烟分支 SMOKE_GATES 后新增 V3 硬闸：逐件缺席或未中标都 ❌（det 提示对聊天框转义 dump 定字节形态）；免疫侧在场件误标 ❌、缺席不判。步骤卡 Q4/V3/V16/V17 口径同步。

## 六、转义后 dump 样例行（运营点名交付）

若第三级仍未命中，聊天框「毒咒疑似行」将呈如下形态（示例，字节显形后）：

```
毒咒疑似行未精确命中（物品 271876，mythic 档）：|cff1eff00史诗\n毒咒|r
```

- `\n` = 字面反斜杠+n 两字符（原串内嵌换行的显形）；
- `|` 显形为 `||`（上例若为色码包裹会呈 `||cff1eff00史诗\n毒咒||r`）；
- 据此可逐字节读出真实形态：是否夹中码、色码位置、换行符是 `\n` 还是 `\r\n`——下一版 pattern 定向零猜测。
