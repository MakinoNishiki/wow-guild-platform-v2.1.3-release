## 二、真实病灶与修复

**病灶**：家宅装饰详情弹窗中，`sources=[]` 的商品（含全部 251 件 12.1.5 新增）走 `stripRawText` 裸文本路径，`|Hcurrency:ID|h` 与 `UI-GOLDICON` 图标码被一并剥离，价格只剩裸数字「价格：350」——币种信息丢失。

**修复**（`js/decorData.js`，仅 `renderSourceBlock` 裸文本路径）：
- 新增 `rawPriceLabel(s)`：按原文三形态还原——货币链接（`价格：|rN|Hcurrency:ID|h` → `N × 货币名`）、金币图标（`N|T...UI-GOLDICON...|t` → `N 金`）、双价并存（`N × 货币 + N 金`，以 ` + ` 连接）
- 货币名取 `D.CURRENCY_NAMES`（单一真源），未收录回退「货币 ID」不编名
- 价格行替换用 `/价格：[\d\s]+/g` 全局替换（多商人块同治）
- 结构化 `sources` 的 `priceText()` 既有链路零改动
