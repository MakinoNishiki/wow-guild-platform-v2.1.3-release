## 页面核对

正式站首页返回 200，标题只写「魔兽管家」。家宅与榜单主要通过页内路由打开；网站地图及两个拟提交的新网址在本轮开发前均返回 404。现有顶部导航用按钮，家宅入口卡使用片段地址。复用现有页面及导航样式，把公开入口改为可抓取链接，给每个地址提供对应的标题、简介和无需运行脚本也能阅读的正文。保留原来分享出去的链接及公会成员默认落地页。

## 运营提交

1. 首先验证网址前缀 `https://wow.ddctl.com/`。Google 可选择 HTML 标签或 DNS 验证。百度在站点管理中按账号显示的验证方式操作。选择 HTML 标签时提供平台分配的完整验证标签即可；选择 DNS 时由域名管理员添加平台指定的记录。
2. 首页当前可以提交。新页面和网站地图上线后，打开四个提交地址核对，再向 Google 的「站点地图」提交 `https://wow.ddctl.com/sitemap.xml`，从「网址检查」请求编入索引。百度在「普通收录」中按账号可用方式提交上表四个页面网址。
3. 分开登记站点验证、提交回执和实际收录。Google 用「网址检查」查看索引状态，在「效果」中查看查询词、展示和点击。百度查看「索引量」「流量与关键词」。提交成功与收录结果以平台反馈为准。

11 月 27 日实查：在百度单条提交页填写正式站首页并点击提交后跳到登录页。Google Search Console 同样要求登录。尚未取得站长平台回执。正式站当时仍返回 11 月 26 日的前端资源，字体工具和网站地图均为 404。

## 本机验收

- 最短路径：打开首页，点击顶部「字体管理器」，再从工具右上角进入「更新日志」。页头显示当前版本与最新公告日期，原有公告保留当时的版本。
- Chrome 禁用 JavaScript 后，四个公开地址仍分别返回正确的标题、简介、规范网址和可见主标题。启用脚本后，旧图鉴链接、PvP 切换、浏览器前进和后退均能返回对应页面。字体页上报一次页面浏览。
- Chrome 隔离目录完成字体应用、刷新回读、删除和原文件恢复。排行榜在 1366 与 1920 像素宽度下通过实榜筛选、翻页、错误重试与浏览器返回验证。
- 可复跑 `scripts/verify-req217-public.cjs`、`scripts/verify-font-review-install.js`。首页资源标识 `20261127.177` 共 52 处，旧标识残留 0 处。本次无新增 SQL。待运营点验、部署及站长平台回执。

原版 REQ-217 已于 11 月 27 日在正式站验证。本补丁在本机完成，尚待推送、上线与运营点验。

| 运营截图中的问题 | 修改与验证 |
| --- | --- |
| 页首仅以「魔兽管家」文字链接返回 | 在左上角显示「返回魔兽管家首页」及箭头。Chrome 在 1366 和 1920 像素下均可看到，点击后进入首页。 |

| 授权后「刷新当前字体」与次要操作颜色相近，多版本共存时只看到正式服路径 | 待授权时突出「继续使用此目录」，读取成功后突出「刷新当前字体」。选游戏总目录会显示当前正式服目标及识别到的其他版本。只选 Fonts 时显示版本待确认。 |

在 Chrome 隔离目录回归中保留目录记录，关闭页面再重新打开，分别模拟拒绝、允许和再次失效，核对两种继续路径均未打开目录选择器。已有授权的刷新、应用、删除及原文件恢复也通过。浏览器原生授权弹窗由浏览器控制。

本机游戏总目录实际包含 `_retail_`、`_forever_`、`_classic_`、`_classic_era_`、`_classic_titan_`。Chrome 隔离目录按相同结构验证显示，单选无限服或怀旧服时提示支持范围，原来的正式服目标保持不变。此次未向实际游戏目录写入文件。
