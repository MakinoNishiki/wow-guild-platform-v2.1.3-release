## F1 「分类」过滤组（三级结构）

PRD 原文口径：合并「部位」与「类型」为统一「分类」，分类下设二级 tab，二级 tab 下设三级 tab。

### 结构
- 一级：组名「分类」，与现有 主属性/副属性/来源 三组并列（位置：主属性组之前，为第一组——装备认知顺序：先分类后属性）
- 二级 tab（单选切换）：部位 / 武器 / 护甲
- 三级 chips（当前二级类目下展示，**多选**，同类目内取并集 OR，与其他过滤组取交集 AND）：
  - 部位（11）：头部/肩部/胸部/腕部/手部/腰部/腿部/脚部/背部/颈部/手指
  - 武器（5）：单手/双手/远程/主手/副手
  - 护甲（5）：板甲/锁甲/皮甲/布甲/盾牌

### 映射执行表（PRD 补充口径，不在过滤器 UI 展示）
- 远程武器 = 弓、弩、枪；**双手不含远程**
- 单手武器 = 单手剑/单手锤/单手斧/匕首/拳套/战刃
- 双手武器 = 双手剑/双手锤/双手斧/长柄武器/**法杖**
- 护甲 = 板/锁/皮/布 + 盾牌

### 前置审计（先取证后施工，证据三标）
- 全量跑 `slot` 与 `item_type` 值域分布（308 件现役数据），产出「三级 chip → slot/item_type 映射表」随设计方案送审，顾问线上复核后方可施工
- 重点确认：「主手」在数据中的落法（slot=主手 是否存在；单手与主手的区分）；「副手」= 副手物品 or 副手武器的判别；盾牌归护甲而非武器
- 饰品/其它（item_type=其它，如饰品、项链戒指）在分类组的归属：部位类目可命中（颈部/手指），饰品无部位三级项——**允许分类组存在"无归属"装备**，不做强行归类；UI 上选择分类后饰品类自然不命中，此为预期行为，报告注明

### 交互细则
- 二级 tab 切换不清空三级已选？——**清空**：二级类目互斥（一件装备不可能既是部位又是武器类目下的选中态），切换二级 tab 时清空上一类目的三级选择，避免隐性条件残留
- 三级 chips 样式沿用 .dp-chip 体系；选中态、计数、与搜索/属性/来源的组合逻辑与现有一致
- 重置按钮清空含分类组在内的全部条件

## F2 来源实例级过滤

PRD 原文口径：来源下分 团本（梦境裂隙/虚影尖塔/进军奎尔丹纳斯/孢陨幽境）、秘境（艾杰斯亚学院/魔导师平台/迈萨拉洞窟/节点希纳斯/风行者之塔/萨隆矿坑/执政团之座/通天峰）。

### 结构
- 来源组扩展为两级：一级 chips 维持 全部/团本/大秘境（单选）；选中 团本 或 大秘境 时展开对应实例 chips（团本 4 个、秘境 8 个，单选）
- 实例选择行为（浏览态）：选中某实例 → 另一池整池折叠（沿用 R6 机制）+ 本池仅保留该实例分组；再点该实例 chip 取消选中恢复池全量；选「全部」→ 双池全展开
- 实例名称与计数随数据驱动（当前 S1：团本 4、秘境 8），实例 chip 可带计数角标（沿用组标题计数样式）
- 赛季翻牌（S2）时实例列表随 is_current 数据自动更新，不写死

- 清空全部内容类条件自动回浏览态；重置按钮语义不变
- 排序保持数据自然序（团本→秘境→BOSS 内序），不发明新排序
- 状态切换走现有 0.2s 渐显动画；prefers-reduced-motion 降级不变
- 套装兑换物（鸣响虚空珍玩）在平铺态正常命中展示（无属性筛选时不冲突；属性筛选时因无主副属性自然不命中，预期行为）
