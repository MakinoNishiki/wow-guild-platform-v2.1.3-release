## 二、第一节 每页件数动态化（页件铺满）

### 实现要点（js/decorData.js）

1. **列数实测**：`measureColumns()` 探针同步三连——`<div class="dh-grid">` 挂 `#dhMain` → `getComputedStyle(probe).gridTemplateColumns` 强制排版取轨道数 → 同 JS 任务内 remove（无绘制无闪烁）。不写死断点、不复制媒体查询逻辑。隐藏态（登录壳切去他页 display:none）auto-fill 不可解析（返回 `repeat(...)` 原串或 `none`）→ 判不可测返回 0，调用方跳过不动。
2. **每页件数**：`state.pageSize = 实测列数 × ROWS_PER_PAGE(8)`；`currentPageSize()` 惰性首算（首挂载在 `render()` 前先算再渲染首页），隐藏态极端降级 = `D.PAGE_SIZE`（60）兜底。`render()` 三处 `D.PAGE_SIZE` 引用全部切换动态值，分页器「第 X/Y 页 · 共 Z 件」文案随动态值自然更新（Y/Z 语义不变）。
3. **resize 锚点**：`window resize` 防抖 300ms → 重测列数；件数变化时记当前页首件 `record_id` 锚点，`rows.findIndex` 重定位 `state.page = floor(idx/新件数)+1`，不粗暴回第 1 页；件数不变零重渲染；隐藏态（列数测不出）直接跳过。
4. 筛选/搜索/排序变化回第 1 页现逻辑零改动（各 chip/搜索回调原样 `state.page = 1`）。
5. 双壳同源渲染层一次改动两壳同效（登录壳 `#page-decor` / 公示壳 `decor.html` 同一 `window.DecorCatalog`）。

## 三、第二节 卡片版式重排（容量角标 + 来源两行）

### 实现要点

1. **容量角标**：`cardHtml()` 容量徽标自底部 `.dh-badges` 行移入 `.dh-icon-wrap` 内 `<span class="dh-badge dh-cost-badge">容量 N</span>`——`.dh-icon-wrap` 加 `position: relative`，角标 `position:absolute; top:2px; right:2px`，底色/描边/圆角全沿袭 `.dh-badge` 既有类（只加定位与紧凑 padding），字号 10px（≤11px）；768 档 9px/padding 3px/top-right 1px 同比例缩小。仅覆图标右上角缘，图标主体与容器描边无遮挡（04 特写帧可见）。**原底部容量行删除**；无房间/宠物徽标的卡整行 `.dh-badges` 省略（净空高，抵来源一行变两行，净增高 ≤ 一行达成——实测卡片增高仅来源单行→双行的约 15px）。
2. **名称行/分类路径行不动**（分类行维持单行省略）；**来源摘要两行截断**：`.dh-src` 改 `display:-webkit-box; -webkit-line-clamp:2; line-clamp:2（标准回退）; -webkit-box-orient:vertical`，居中、`word-break:break-all`；「来源未知」`.dh-src-unknown` 灰字斜体 `white-space:nowrap` 单行维持（B11b 断言 nowrap 在场）。
3. 图标 96px / 768 档 72px、网格 minmax 190/132 均零改动；详情弹窗零改动；收藏/3D 不做。
