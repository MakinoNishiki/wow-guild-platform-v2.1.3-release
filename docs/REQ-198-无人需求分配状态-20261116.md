# REQ-198 无人需求分配状态

## 范围与语义
引用《开发规范》《问题与需求清单》《UI工作方法-证据规范实现验收》。依据运营截图新增本期小块，前期REQ193/194/195主线运营验收结论另行登记。

- 待分配：尚未决定最终处理结果。
- 已分配：已明确最终获得者。
- 无人需求：已确认没有成员需要，不强制分配给谁；仍保留原拾取人，之后可重新分配。
- 无人需求不等于已经分解或销毁；不伪造游戏交易结果。

## 实际改动
- index.html：拾取转分配、手动装备表单和状态筛选增加选项，版本串143。
- js/app.js：无人需求清空并禁用获得者，解释文案、灰色状态徽标；保存继续走cloudCrud，心愿沿用仅已分配才计已获取的既有规则。
- lib/lootAllocation.cjs：允许无人需求；服务器拒绝无人需求同时带获得者。保留同来源单条、原拾取快照、活动后补和owner/editor权限。
- 不增加SQL，不修改历史数据；前端与服务端需一起发布并重启服务。未提交、推送或部署生产。
