## 共用规则

| 层级 | 验收标准 |
|---|---|
| 全站导航 | 顶栏负责模块切换。模块页头负责当前页面的任务说明，正式接入时复用原页面标题位置，避免标题重复。 |
| 视觉 | 深色底、分层面板、统一 8px 圆角和细边。主题渐变集中在页头。金色用于主动作、选中态和焦点。物品品质色、属性色及状态色保留业务含义。 |
| 浏览页 | 先交代当前页面能查什么，再呈现筛选、当前结果及详情入口。筛选保留搜索、清除和结果数量。掉落按副本、首领组织，家宅按分类和来源检索并保留卡片网格。 |
| 操作页 | 后续沿用同一视觉层级。表格、行操作、批量操作及保存反馈另用一组真实操作页验证。 |
| 交互 | 选择状态可见，焦点有轮廓。真实结果更新后再显示成功，加载、无结果、失败各有独立反馈。当前桌面优先。 |

- 截图是方向对照，临时页头与现有顶栏标题重复，掉落右侧筛选栏占据页头右边缘。正式合入时共用页头应替换原模块标题，并为桌面右侧筛选栏预留宽度。
- 暂缓发布现有掉落改版。方向验收后，先统一两页页头和视觉组件，再验现有筛选、键盘、空态和失败态。操作型页面另选样板。

## 整站设计延展 · 职业测试、招募与可分享图鉴

- 职业测试与主站共享品牌、导航、字体、配色和结果卡片。MBTI 可作为选填的趣味标签与分享表达。推荐理由仍来自玩家选择的职责、操作和玩法偏好，结果页展示可核对的理由。
- 区分玩家自填性别与游戏角色形象。社交资料可以预留选填字段及可见范围，测试可跳过。答题结果、公开名片及对外分享分别由用户决定展示内容。设计阶段先预留位置，数据采集和存储待单独确认。
- 招募参考 [任务书 #25](../tasks/任务书25-公会招募板一期v3.1.md) 的公会招募与玩家求职双端模板。优先复用职业／专精、职责、活动时间等既有匹配维度。测试结果可由用户主动附到名片，公开图鉴和社区链接沿用各自的权限边界。
- 人物、事件、物品、职业与专精使用稳定的对象链接。关系节点和详情引用均可跳转，支持浏览器返回；分享预览优先展示对象名称、主图和一句摘要。公开图鉴可直接分享，公会与个人内容沿用原有访问权限。
- 整站方向稿继续覆盖首页、家宅、公会工作区，同时展示职业测试结果、人物关系与装备档案的关键状态。职业测试、社交和图鉴扩展仍作为方向参考。
