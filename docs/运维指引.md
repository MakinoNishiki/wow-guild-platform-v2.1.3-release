## 旧域名 ddctl.com 301 跳转（EdgeOne，朋友侧 5 分钟）

背景：美国站已退役（CI 已停部署），站点全量运行在 EdgeOne（国内）。旧域名 `ddctl.com` 裸域仍有历史访问，需要在 EO 控制台加一条 301 规则，把 `ddctl.com/*` 全部 301 到 `https://wow.ddctl.com`（保留路径）。**不做静态跳转页——EO 301 是正解**（搜索引擎权重转移、无中间页闪烁）。

### 操作步骤（EdgeOne 控制台）

1. 登录 EdgeOne 控制台 → 进入站点 `ddctl.com`。
2. 左侧菜单「规则引擎」（Rule Engine）→「添加规则」。
3. 规则配置：
   - 匹配条件：主机名（Host）等于 `ddctl.com`（即裸域，不含 `wow.ddctl.com` 等其他子域）；
   - 操作：选择「重定向」（Redirect）；
   - 目标 URL：`https://wow.ddctl.com${request_uri}`（保留原路径与查询串；若控制台不支持变量插值，选「保留路径」选项即可）；
   - 状态码：**301（永久重定向）**。
4. 保存并发布规则（EO 规则需点「发布/生效」）。
5. 验证（任选其一）：
   - `curl -sI http://ddctl.com/some/path` → 应返回 `HTTP/301`，`Location: https://wow.ddctl.com/some/path`；
   - 浏览器无痕窗口访问 `http://ddctl.com/任意路径` → 地址栏应跳到 `https://wow.ddctl.com/任意路径`。
