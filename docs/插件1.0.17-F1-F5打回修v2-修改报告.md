- `EJ_SetLootFilter(0,0)` 的「清」语义无直接文档锚定——仅作 `EJ_ResetLootFilter` 缺位时的回退路径（getter 往返口径），主路径不依赖它。

## 二、F1-F5 逐条修复回执

### F1（P0）槽位清零置毒 → 根治

`captureLootFilter` / `resetLootFilter` / `restoreLootFilter` 三件套重写（WoWButlerExporter.lua:297-341）：

- 清零：`EJ_ResetLootFilter()` 优先（职业/专精全系，wiki 12.0.0 在册 "Clear all filters"），缺位回退 `EJ_SetLootFilter(0,0)`；槽位 `C_EncounterJournal.ResetSlotFilter()` 优先，`SetSlotFilter(Enum.ItemSlotFilterType.NoFilter)` 枚举常量兜底——**禁传字面 0**（0=Head 实证置毒）。
- 捕获：`EJ_GetLootFilter()` 拿 class/spec + `C_EncounterJournal.GetSlotFilter()` 拿真实枚举值，还原时按捕获值回设，无捕获值时 `ResetSlotFilter()`。
- 快照黄字格式不变（`过滤器[class=/spec=/slot=]`），真机反馈时 slot 应见 15 而非 0。

### F2（P0）重建窗 → 官方钩子+阶段一全量异步化

- 新增 `whenLootListFresh(fn, attempt)`（:366-385）：`EJ_IsLootListOutOfDate()` 轮询 false 放行，每帧一次、60 帧封顶超时红字后放行；函数缺位回退 `C_Timer.After(0, fn)`。**就绪后同样下一帧执行**（D1 浅栈纪律：枚举链全程零同步递归——否则「恒新鲜」路径会把逐 BOSS 回调链压成同步长链，重踩 BUG-089 爆栈隐患，属本包自增防护，申报在案）。
- 阶段一由同步 while 重构为异步链（:662-770 区间）：`enumInstance` / `nextEnumBoss` / `enumBossItems` 三级闭包，选本/钉档/清过滤器后、选 BOSS 后、0 件重试前均过 `whenLootListFresh`；跑完自动续推阶段二（`startPhase2 = nextInstance` 前向声明接线）。
- `collectTiers` 切档后 `C_Timer.After(0, …scanTier)` 同改挂 `whenLootListFresh`（:519），1.0.16 已加的逐档 `resetLootFilter()` 保留。

### F3（P1）0 件静默判空 → 重试+红字

- BOSS 级：枚举 0 件且重试未满 3 次 → 过重建钩子重扫；仍 0 → **红字**「BOSS『%s』枚举重试 3 次仍 0 件掉落——记空掉落占位（非正常默认，请截图反馈顾问侧）」。
- 实例级：全 BOSS 重试后仍 0 件的空实例判定由黄字改**红字**（禁静默）；伪实例名表过滤维持黄字不变。

### F4（P1）LastCounts 质量门

doExport 终局（:1045-1056 区间）：逐实例计数归集后收集 0 件实例清单 `zeroNames`（排序保证输出稳定）；非空 → 红字「计数质量门：以下实例本次 0 件（…）——本跑标记 abnormal，不覆写上次计数基线」并**拒覆写** `WJDCLastCounts`；空 → 照常覆写。计数对比黄字逻辑不动。

### F5（P2）250459×4 重复 → itemID 去重（新立 BUG-093）

`enumBossItems` 枚举循环内 `seen[itemID]` 去重，同 BOSS 首次出现才入列；500 封顶防呆不变。

### 冒烟模式 /wjdc smoke（顾问增补②，同批落）

- `exportInstances` 加可选第 7 参 `smokeLimit={name, maxBosses}`：阶段一非目标实例零触碰跳过、目标收齐即收尾；BOSS 数达上限即走既有双判收尾——**采集/解析/档扫/黄字全要素与全量同一条链**（过滤器快照/档值/effect/毒咒疑似行 dump 全在），零平行实现。
- `doExport` 加 smoke 双段：「冒烟·团本」至暗之夜第 1 BOSS +「冒烟·大秘境」毒牙祭坛第 1 BOSS，档通道探测两段全开。
- 终局：冒烟跑 `meta.smoke=true` 标记，**跳过计数对比/质量门/LastCounts 基线覆写**（样本仅 2 实例，防污染全量基线）；冒烟目标实例枚举不到时红字具名提示。
- slash 放行 `smoke` + 用法文案；段提交/看门狗/断链标记语义不变。
- 范围纪律③：本批只 F1-F5+冒烟，其他一概未捎。
