# BUG-133 成员角色分配权限预览

归属任务书 #191。入口为「公会 → 成员权限 → 成员行的分配角色」。

## 界面核对

运营截图中的左栏已经选中「团员」，右侧仅显示成员及角色下拉框。点击同一角色后才出现权限开关，底部动作也从「保存分配」变成「保存修改」。代码核对发现，成员分配首次渲染漏掉了权限明细，左栏点击又打开了编辑全公会角色的流程。

## 交互

打开即显示目标成员、当前角色和五组共 17 项权限。会长用下拉框或左栏切换候选角色时，两处选择与预览同步。权限勾选状态取自公会保存的角色配置。选择有变化时启用「保存分配」，保存只更新该成员的身份。要调整整个角色的权限，使用成员页的「管理角色与权限」。

## 自测与点验

- 在本机 Chrome 和隔离数据库中，从测试团员的「分配角色」进入。验证首屏已经载入全部权限，重复点击「团员」仍停留在同一成员的分配窗口。
- 在「团员」与「公会编辑」之间切换，核对招募卡和 WCL 权限。放弃修改后保留原身份；保存后重新打开，显示新身份及其权限。核对后恢复测试团员原身份，角色定义和修订号一致。
- 已分配自定义角色的成员首次打开也显示对应棋子及实际权限。原有角色创建、编辑、普通成员只读及并发修改检查通过。
