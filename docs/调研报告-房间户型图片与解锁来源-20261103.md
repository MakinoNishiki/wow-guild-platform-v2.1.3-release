## 结论与可落地路径

当前扫描40条Room记录，item_id、icon_file_id、asset_id、model_scene_id均为空，source_text全部空。不能由这些空值推导“没有图片／没有解锁条件”：插件白名单未保存iconAtlas，而客户端目录结构明确允许iconTexture和iconAtlas二选一。下表完整覆盖40条，成本均来自本机12.1.5/build70688扫描。

WoWDB已找到35个对应ID页面，其中33个页面明确链接room-icons图片。400/401谷仓没有房间icon链接，页面里的玩家作品图不能代作它们的官方图；其余5个本库条目未在该站当前36条目录中找到（该站还有本库没有的Entry）。**可以先按明确ID映射补33张，再处理7个缺图条目，不能拿相近房间图硬套。**图片链接来自页面自身，本轮未下载/核验像素，不声称其与70688本机贴图字节一致。

优先图形管道：本机HouseRoom.db2按ID核对名称/WeightCost → UiTextureAtlasElementID → UiTextureAtlasElement/UiTextureAtlasMember/UiTextureAtlas关联图集 → 从本机CASC取贴图并按矩形裁切。具体表连接键及Atlas尺寸须实际解析后定，不能只按文件名猜裁图。HouseRoom还带RoomWmoDataID和ItemID，可用于继续追踪模型/对应解锁物品；RoomWmoData仅有BoundingBox/Height，不等于模型FDID。若本机表能取得准确轮廓，也可自绘SVG平面示意并标注“户型示意”，不伪装实景截图。

[WoWDB房间目录](https://housing.wowdb.com/rooms/)是图片与自有规格一手来源，但没有钉死build70688。示例[小八边形房间](https://housing.wowdb.com/rooms/14/octagon-room-small-14/)的Specifications列Min.Level=1，Cost=4、24.3×24.3、4连接点；Min.Level暂只作站点参数，不直接写入真实解锁来源。同页玩家户型卡片中的Level 3/Level 9是整套方案等级，更不能当该房间解锁等级。该站Closet正文称单连接，规格却列2连接，说明外站描述也需要核对。
