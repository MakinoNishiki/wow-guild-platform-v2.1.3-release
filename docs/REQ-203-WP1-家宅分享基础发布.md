# 任务书#203-WP1：家宅分享基础发布

## 交付

在“家宅房屋 → 家宅分享”发布装修作品。访客能浏览公开列表和作品详情。网站账号即为作者身份，无公会账号也可使用。“我的作品”只显示本账号的已发布作品和草稿，公开作品沿用同一条记录和固定链接。个人方案单继续提供家具采购、组单与导出。

| 作者操作 | 作者看到 | 新打开页面的访客看到 |
|---|---|---|
| 保存草稿 | 私有草稿，可继续编辑 | 公开列表与作品链接均无此作品 |
| 发布，保留默认代码设置 | 已发布，仍可编辑代码 | 标题、署名与说明，提示“作者仅展示作品” |
| 勾选允许复制并保存 | 作品更新 | 可复制原生蓝图码 |
| 取消允许复制并保存 | 作品仍已发布 | 原链接可看介绍，公开接口收回代码 |
| 撤回为草稿 | 原作品与代码保留 | 原链接提示“作品不存在或已撤回” |

## 运营验收

1. 用无公会账号从家宅分享创建作品，填写作品名与原生蓝图码，保存草稿。刷新“我的作品”后重开，核对输入。
2. 发布作品并保留默认代码设置。把作品网址在未登录窗口打开，核对署名、作品说明和“作者仅展示作品”。
3. 勾选“允许访客复制蓝图码”并保存。刷新访客页，复制并对照游戏里的原码。再次关掉开关，刷新确认介绍仍可以看、复制入口已收回。
4. 撤回为草稿，刷新访客的原链接和公开列表。作者应能重新编辑同一份草稿。
5. 进入图鉴，将家具加入个人方案单并导出采购清单，核对数量与获取来源。

## 补丁1：装修截图与蓝图授权

作者可从「家宅分享 → 创建作品」选取最多四张 JPG、PNG 或 WebP，每个原文件最多 16 MB。网页自动缩图，第一张为封面，可重新指定或移除。截图、原码设置与作品说明一起保存。装修图和原码都可用于已有作品。

| 作者设置 | 访客打开已发布作品时 |
| --- | --- |
| 关闭「公开蓝图码」 | 浏览作品和截图，公开接口隐藏原码。作者可以将蓝图码留空。 |
| 公开原码，关闭「允许访客一键复制」 | 可看到原码、手动选中复制。 |
| 同时勾选两个选项 | 可看到原码，并可点击「复制蓝图码」。 |

**运营验收**

1. 从空白作品上传两张横竖不同的截图，留空原码，选第二张为封面，保存草稿后重开。确认同一封面排序，发布后用访客窗口查看列表封面、打开作品、切换两张图。
2. 编辑同一作品，填入原码。依次试表格的三个选项，每次保存后刷新访客页面。最后在勾选两个选项时实际复制并核对剪贴板。
3. 移除一张图并保存，随后撤回作品。在访客窗口刷新作品链接，作者仍能重开草稿。

**验证和发布**　本机 PostgreSQL、PostgREST 和真实 Chrome 已验证上述流程及失败重试、旧作设置迁移、草稿图片权限、撤回后的旧图链接。登录资料由测试程序提供，使用合成横竖图片和测试码。截图和核对结果见[编辑器](evidence/req203-photos-20261119/web-editor-1920.png)、[访客列表](evidence/req203-photos-20261119/web-gallery-1366.png)、[访客详情](evidence/req203-photos-20261119/visible-detail-1366.png)、[检查记录](evidence/req203-photos-20261119/web-verification.json)。

## 补丁2：作品图集与蓝图复制

作者最多选 8 张 JPG、PNG 或 WebP，每张原图可达 20 MB。编辑时点任一缩略图即可原位更换，即使已满 8 张也可操作。图上显示待保存，状态行说明更换位置；取消或失败保留原图。作品卡片初始为作者封面，可点击左右半幅或横拖翻图；标题进入详情。“返回公开作品”位于详情顶部。公开列表和详情只返回展示字段。作者同时启用分享和允许复制后，访客在详情点按钮才取得代码并写入剪贴板。

**本地验证**　Chrome、一次性 PostgreSQL 和 PostgREST，使用两个模拟登录账号。16 项验证通过，覆盖实际上传 20 MB 原图、拒绝超出 1 字节、8 张保存、原位更换及持久化、卡片翻图、剪贴板复制与撤销授权、方案单采购导出回归。8 图样例的实际保存请求为 1,566,271 字节。[核对结果](evidence/req203-gallery-20261119/web-verification.json) · [编辑器原位更换](evidence/req203-gallery-20261119/replace-eight-1366.png)

## 补丁3：封面翻图

公开作品与「我的作品」的多图卡片使用相同翻图控件。打开列表先看作者封面，四张图显示四枚白点，八张图显示八枚。点其中一枚直接看对应截图，当前点较大。封面两侧用带阴影的白色箭头，点击可从末张回到首张。公开作品点主图直接进入详情，草稿留在作者区。

**运营验收**　打开「家宅房屋 → 家宅分享」，找一个多图作品。点末枚圆点，再点右箭头，应回到作者封面。按住主图横拖应留在列表，轻点主图应打开这件作品。返回列表后检查首张封面，单图作品只展示图片。
