# 任务书#203-WP1：家宅分享基础发布

## 交付

在“家宅房屋 → 家宅分享”发布装修作品。访客能浏览公开列表和作品详情。网站账号即为作者身份，无公会账号也可使用。“我的作品”只显示本账号的已发布作品和草稿，公开作品沿用同一条记录和固定链接。个人方案单继续提供家具采购、组单与导出。

| 作者操作 | 作者看到 | 新打开页面的访客看到 |
|---|---|---|
| 保存草稿 | 私有草稿，可继续编辑 | 公开列表与作品链接均无此作品 |
| 发布，保留默认代码设置 | 已发布，仍可编辑代码 | 标题、署名与说明，提示“作者仅展示作品” |
| 勾选允许复制并保存 | 作品更新 | 可复制原生蓝图码 |
| 取消允许复制并保存 | 作品仍已发布 | 原链接可看介绍，公开接口收回代码 |
| 撤回为草稿 | 原作品与代码保留 | 原链接提示“作品不存在或已撤回” |

## 运营验收

1. 用无公会账号从家宅分享创建作品，填写作品名与原生蓝图码，保存草稿。刷新“我的作品”后重开，核对输入。
2. 发布作品并保留默认代码设置。把作品网址在未登录窗口打开，核对署名、作品说明和“作者仅展示作品”。
3. 勾选“允许访客复制蓝图码”并保存。刷新访客页，复制并对照游戏里的原码。再次关掉开关，刷新确认介绍仍可以看、复制入口已收回。
4. 撤回为草稿，刷新访客的原链接和公开列表。作者应能重新编辑同一份草稿。
5. 进入图鉴，将家具加入个人方案单并导出采购清单，核对数量与获取来源。

## 补丁1：装修截图与蓝图授权

作者可从「家宅分享 → 创建作品」选取最多四张 JPG、PNG 或 WebP，每个原文件最多 16 MB。网页自动缩图，第一张为封面，可重新指定或移除。截图、原码设置与作品说明一起保存。装修图和原码都可用于已有作品。

| 作者设置 | 访客打开已发布作品时 |
| --- | --- |
| 关闭「公开蓝图码」 | 浏览作品和截图，公开接口隐藏原码。作者可以将蓝图码留空。 |
| 公开原码，关闭「允许访客一键复制」 | 可看到原码、手动选中复制。 |
| 同时勾选两个选项 | 可看到原码，并可点击「复制蓝图码」。 |

**运营验收**

1. 从空白作品上传两张横竖不同的截图，留空原码，选第二张为封面，保存草稿后重开。确认同一封面排序，发布后用访客窗口查看列表封面、打开作品、切换两张图。
2. 编辑同一作品，填入原码。依次试表格的三个选项，每次保存后刷新访客页面。最后在勾选两个选项时实际复制并核对剪贴板。
3. 移除一张图并保存，随后撤回作品。在访客窗口刷新作品链接，作者仍能重开草稿。
