## 一、R12 返修：展开层 = 特效全文可见（隐藏前缀占位废止）

**运营口径（WP3-v5）**：hover 展开态必须是一段完整连续可见文本——①截断前的前文保持可见（v4 把前缀做成不可见占位、hover 后特效前两行消失，判定为错误）；②省略号移除；③续文紧接断点继续排列；④无任何不可见占位区、无空白行。视觉 = 特效行从截断态生长为完整态；absolute 不推挤布局不变；未溢出卡依旧无 hover。

**实现（采用运营建议 b 的等价形态）**：

- `js/dataPublic.js` `measureEffectOverlays()`：展开层内容由「`.dp-fx-hidden` 隐藏前缀 + 可见续文文本节点」改为 **`overlay.textContent = full`（特效全文，同一文本流全程可见）**。展开层 top:0 实底原位覆盖预览，同宽同字体同行高——全文前两行与预览逐字重合，第三行起自断点自然生长，恰好呈现「从截断态生长为完整态」。预览截断逻辑（镜像二分实测「连…恰好装满 2 行」的最长前缀）不变，省略号只存在于折叠态预览。
- `css/data-public.css`：`.dp-fx-hidden` 规则整条删除（全仓引用已清零，仅剩注释中的废止说明）；展开层定位/实底/动画（200ms ease-out 只动 transform/opacity，reduced-motion 瞬时）不变。
- 未溢出卡路径（R7）不变：无 …、无 hover、无展开层。
