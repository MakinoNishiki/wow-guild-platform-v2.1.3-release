## 补丁 3 · 公会内部招募卡

入口为「公会档案 → 公会资料 → 公会招募卡」。会长首次填写后点「保存招募卡」，团员从同一位置阅读。保存不触发公开发布。

| 界面核对发现 | 实现与验收口径 |
| --- | --- |
| 原评审稿展示示例公会和排班，刷新会清空填写。 | 当前公会没有卡时显示「本公会尚未填写招募卡」。会长可填写并保存，其他成员看只读卡。无须重复填写公会介绍或分配制度。 |
| 评审稿逐项勾选联系方式，容易把档案保存理解成对外发布。 | 标题下写明仅本公会成员可见。成员可以看到会长填写的全部招募联络方式；切换公会或登出会清除原卡。 |
| 招募资料与账号、会籍相关，直接打开链接也要遵守阅读范围。 | 游客先登录，已登录未入会用户可创建或加入。离会或更换账号后再读须重新核实会籍。既有公开战报仍按已发布内容展示。 |
| 两个窗口可以同时编辑排班。 | 保存后回读，失败可保留输入重试。已有更新时提示冲突，只有会长确认重新读取才替换当前输入。 |

## 现有公会的使用路径

成员点顶栏「公会档案」进入资料页。会长点「编辑资料」即可修改介绍、装备制度、分配说明及认领政策。保存成功后返回阅读视图。编辑战报的权限继续归会长和公会编辑，公开战报旧地址仍有效。WCL 绑定区沿用原权限，已绑定时提供该公会的主页链接。

## WCL 进度核查

WCL 官方报告接口支持按难度、首领及击杀结果查询战斗。现有服务器已能按绑定的 WCL 公会 ID 查最近 20 份报告，并读取单份报告的首领、难度及击杀标志。公会排行榜字段提供排名位置。要得到赛季的普通、英雄、史诗进度，需要覆盖赛季的可读报告，以副本、难度和首领去重，并与该赛季的首领表核对分母。[WCL 报告字段](https://www.warcraftlogs.com/v2-api-docs/warcraft/report.doc.html) · [公会副本排名](https://www.warcraftlogs.com/v2-api-docs/warcraft/guildzonerankings.doc.html)

匿名浏览器访问反馈中的国服示例公会，收到 HTTP 403 的访问校验页。本次核实了接口能力与本站现有取数逻辑；该公会全赛季的实际覆盖率、私人日志缺口和配额成本仍需用合法可读的代表性报告核实。当前产品的战报进度继续来自已发布战报，页面不展示未经核实的全赛季数字。
