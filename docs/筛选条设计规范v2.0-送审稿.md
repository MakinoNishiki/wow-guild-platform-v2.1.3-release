## 4. 改造设计

### 4.1 布局（自上而下，唯一合法结构）

```
┌────────────────────────────────────────────────────────────┐
│ [搜索装备名…（加宽 flex:1，清除钮保留）        ] [重置筛选] │ ← 首行，无 chip
│ 主属性  多选                                                │ ← 区头标题
│ [力量] [敏捷] [智力]                                        │
│ 副属性  多选                                                │
│ [爆击] [急速] [精通] [全能]                                  │
│ 来源  单选 · 值域随赛季数据驱动                              │
│ [全部] │ [团本] [大秘境] [副本任务] [专业制造]               │ ← 单选五枚
└────────────────────────────────────────────────────────────┘
```

「排除杂项物品」开关+问号帮助**整块删除**（DOM 不残留）；部位/类型两行删除。

### 4.2 交互语义

- 主/副属性：**多选不变**（组内多标签 AND 语义不变），样式不变；
- 来源：**单选**（点选互斥，「全部」= 不限制）；与主/副属性/搜索词跨组 AND；
- 重置筛选：清空来源+主/副属性+搜索词，还原当季全集（复用 `resetFilters()`）；
- 赛季切换：全部重置语义不变；搜索清除钮（REQ-084）不回归。

### 4.3 来源归组映射（数据匹配映射表，进代码注释，不上界面）

| 来源 chip | 数据匹配 | 备注 |
|---|---|---|
| 团本 | `boss_loot` 全量（经 game_raids→赛季归属过滤当前赛季） | 四本随赛季数据驱动，不写死 |
| 大秘境 | `dungeon_loot` 全量（game_dungeons→赛季链路） | 八本同上 |
| 副本任务 | 当前数据模型无此来源 | **预留值**：当季无数据时 chip 不渲染（不写死、不置灰占位），待确认 |
| 专业制造 | 同上 | 同上 |

值域赛季驱动：某来源当季无数据 → 该 chip 不出现（与任务书「值域按赛季数据驱动，不得写死」一致）。

### 4.4 杂项与套装兑换物展示口径（任务书 §WP2 + v1.0 §4 延续）

- **杂项**：数据层排除 `slot='杂项'` 全部 68 行（装饰/垃圾/坐骑/配方类等），页面零渲染、筛选零入口、开关整块删除；删后基线 **343**（实测）；
- **套装兑换物**：**非杂项，保留展示**（现网仅 1 行），沿用「独立归类、永不与杂项同组」口径；部位/类型行取消后无 chip 入口，仅卡片展示，来源归入其掉落本（团本）。

### 4.5 动画规格（UI v2 §6 注册内）

- **筛选器展开收起**（移动端「筛选 ▾」面板 + 筛选条高度变化）：150–250ms ease-out，只动 transform/opacity（禁 height 直改——用 transform: scaleY/translateY + opacity 组合），`prefers-reduced-motion` 下禁用；
- **卡片入场 fade+轻微上浮**（任务书 §WP2-5 已定）：筛选/搜索触发重渲染时 150–250ms ease-out，只动 transform/opacity，出场不做，reduced-motion 禁用；
- 桌面恒展开形态下筛选条本身无折叠，动画主要作用于卡片入场。

### 4.6 筛选与结果严格一致（硬验收口径）

单选/多选/组合/搜索/重置逐项对数，基线 = 施工时当季实测（现锚 343：爆击 166/力量 101/组合 45 对数不变——删杂项不影响属性对数，任务书侦察结论）。
