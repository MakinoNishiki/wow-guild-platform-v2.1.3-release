## 一、根因定案（hex 解码结果，运营回传）

八件逐字相同，代表件 268215：

```
raw 串 = |cFF 0FF 0史诗|r\n|cFF 0BF D毒咒|r
```

- 色码 hex 段**内嵌空格**（0x20）：`|cFF 0FF 0` / `|cFF 0BF D`（挤掉空格=6 位色值 FF0FF0/FF0BFD）；
- 严格剥码模式（`|c`+连续 hex）**遇空格断裂剥不掉** → 匹配串以「|」开头 → 所有 `^史诗` 锚模式（含 1.0.25 的 `.-` 版）**首字节即败**；
- 旧无 `^` 跨行版也因两段中文间夹 `|r\n|cFF 0BF D`（非空白）而败——**四版全灭同一根因**；
- 聊天显示干净=渲染器对畸形色码宽容所致；
- 1.0.24/1.0.25 的「非 %s 不可见字节」主嫌疑随之证伪——hex 直读显示夹的是**色码段**（`|`/`c`/hex/空格全是普通可见 ASCII），不是 U+00A0/零宽字节。转义 dump 时代 `|` 被显形为 `||` 反而把色码痕迹呈现为「无杂码」表象，教训在案。

## 二、修法回执（两条，最小手术）

**①venomcurse 判定路径剥码加固**（`WoWButlerExporter.lua:326`，parseStatLines 内局部变量）：

```lua
local vplain = t:gsub("|c[%x ]+", ""):gsub("|r", ""):gsub("^%s+", ""):gsub("%s+$", "")
```

- `|c[%x ]+` 兼容标准 8 位连续 hex 与内嵌空格畸形码；中文 UTF-8 首字节（≥0x80）非 %x 非空格，**天然止跑，不会误吃正文**（fengari 正文保护专项实证：`|cFF0FF000装备：毒咒特效。|r` 加固后正文逐字保留）；
- 顺序=先剥 `|c` 后剥 `|r`，再 trim（`^%s+`/`%s+$`）；
- 未采用 `|c[^|]-|r` 形态（会吃掉色码与 `|r` 之间的正文）——按定向执行。
- **影响面申报（定向点名项）**：加固剥码为 **venomcurse 判定路径专用局部变量 vplain**，**全局共享函数 stripLineCodes 零改动**（effect/属性行解析路径完全不受影响）——影响面=本功能。冒烟主体件数回归判据（烈毒 112±/毒牙 12+）照例适用，但本改动物理上不触主体采集链。

**②匹配模式回归严格版 `^史诗%s*毒咒%s*$`**（:364）：1.0.25 的 `.-` 版**退役**——剥码修好后两段之间只剩 `\n`，`%s*` 足够且误伤面最小。三级判定统一走加固串 vplain（一级 `^毒咒%s*$` / 二级严格版 / 跨行 `史诗%s*毒咒%s*$`，跨行前驱变量更名 prevVplain）。免疫锚不变（名行字续/flavor 句「。」收尾/兑换物五件/单边全不误伤）。

**dump/hex 豁免条件同步**（:766）：豁免模式同步回归严格版；加固剥码命中后 `venomcurse` 置值 → dump 分支不进入，**疑似 dump/hex 行当轮自动消失（豁免生效=修复生效的现场证据）**；仍未中则 dump/hex 照旧出。

**退役代价如实申报**：1.0.25 断言中「非 %s 不可见字节夹中（U+00A0/U+3000/任意字节，无色码）必中」三案随 `.-` 版退役而**不再命中**——根因已定=畸形色码而非夹字节，真机铁证串不含此类字节；保留严格版是「误伤面最小」裁定（运营定向②原话）。若后续真机出现无色码纯不可见字节夹中形态，hex 兜底仍在版，一跑可再定向。
