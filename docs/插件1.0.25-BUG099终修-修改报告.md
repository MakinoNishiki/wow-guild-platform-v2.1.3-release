- 性质：1.0.24 冒烟主体三连绿、毒咒 0/8 仍红——悖论闭合，非 %s 不可见字节实锤。按运营/顾问定向：①模式改字节无关版 `^史诗.-毒咒%s*$`；②hex dump 兜底随版带上。一跑定案：中→销案连跑全量 A/B；不中→hex 截图发顾问。

## 一、调研依据节（调研前置硬约束）

**悖论闭合链（三版迭代全记录在案）**：
1. 1.0.23 转义 dump 铁证：单串「史诗\n毒咒」纯 `\n` 零杂码（夹码假设证伪）；
2. 1.0.23 显式 `\n` 模式 od 实证写法正确（文件字节 5C 6E 标准转义）、顾问 LuaJIT+本侧 fengari 双实证对铁证串**理论必中**——真机未中 ⇒ 匹配输入串≠dump 串；
3. 1.0.24 `%s+`（通吃全部 ASCII 空白含 Tab，fengari 实证）真机仍 0/8 ⇒ 夹在中间的**不是任何 ASCII 空白**——三答闭合后唯一自洽解释=**非 %s 不可见字节**（U+00A0 不换行空格 / U+200B 零宽 / U+3000 表意空格等），转义 dump 只显形 `\r`/`\n`/`|` 三符对其失明，`%s` 类对其同样失明。

**终极可能性穷举（顾问口径，本版全覆盖）**：
- 夹中字节=任意非 %s 字节 → `.-` 字节无关版**必中**（不管夹什么）；
- 连 `.-` 版都不中 → 唯一剩余解释=「史诗」「毒咒」**字面本身的字码**就不是预期字码（如全角/异体字/私有区）——hex dump（1.0.24 已并入，本版随带）逐字节直读，一跑定死。此为最后一种可能。

## 二、处方两条回执

**①模式改字节无关版 `^史诗.-毒咒%s*$`**（`WoWButlerExporter.lua:344` elseif 一支，表达式级替换）：`.` 在 Lua 模式里匹配**任意字节**（含 `\n`，含一切非 %s 字节），`-` 非贪婪——`史诗` 与 `毒咒` 之间夹任何东西都判有。免疫锚不变：`^史诗` 起锚 + `毒咒%s*$` 收尾——名行以字续（「史诗\n毒咒残片」）不命中、flavor 句（以「。」收尾）不命中、兑换物名行（「毒咒宝珠」不起于史诗）不命中、单边（「史诗」）不命中——**fengari 断言覆盖合成不可见字节串**（见自检节 13 断言，含运营点名串「史诗+U+200B+\n+毒咒」必中）。

**②hex dump 兜底同版带上**：1.0.24 预授权并入的 hex dump（`VENOM_HEX_IDS` 八件限定、仅打印路径，:267 常量+:746-749 打印分支）**原样随版**，零改动。dump 豁免条件与匹配级同步为 `^史诗.-毒咒%s*$`（:743——命中字节无关版的串不再误报疑似 dump）。
