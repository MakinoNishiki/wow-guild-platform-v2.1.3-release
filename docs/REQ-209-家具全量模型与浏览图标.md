# 任务书 #209 补丁 · 家具全量 3D 与浏览量图标

## 范围与界面审计

运营在「华丽的石制壁炉」详情看到灰色 3D 按钮，并指出图鉴的浏览量眼形倾斜。旧版只为 26 件家具打包了网页模型。卡片与详情共用的眼形使用不对称圆角，整个图标又被旋转 35 度。此补丁覆盖当前图鉴内全部家具及两处浏览统计。40 条房间户型沿用平面图。

## 模型交付

| 目录 | 家具条目 | 网页使用的模型文件 |
| --- | ---: | ---: |
| 已发布的静态模型 | 26 | 26 |
| 本次新增的普通家具 | 2,248 | 2,245 |
| 本次新增的墙体、立柱、门廊 | 21 | 21 |

模型从本机国服正式服 12.1.5.70961 导出。用游戏的家具编号关联记录，三条共享模型的记录直接复用对应文件。21 条结构件原目录缺少普通家具模型编号，按游戏数据库 HouseDecor 的 ID、中文名和 ItemID 逐项核对，从 ModelType=2 的记录读出独立的建筑模型文件编号，再加载各组网格与贴图。[HouseDecor 字段定义](https://github.com/wowdev/WoWDBDefs/blob/master/definitions/HouseDecor.dbd)

模型与贴图随站点自托管。新增 2,266 个文件，共 413,282,032 字节。访客点击「3D 预览」时按需加载所选一件。模型显示静态外观，粒子和游戏动画仍须进游戏查看。华丽的石制壁炉的家具编号为 80，模型编号为 6033663。奥格瑞玛室内门廊的家具编号为 523，建筑模型编号为 6426638。

浏览量采用共用的水平眼形矢量图。眼角等高、瞳孔居中，与右侧计数在同一行，颜色跟随原统计栏。

## 验证与验收

- 本机 Chrome 使用站点实际查看器和图鉴快照，逐条加载 2,295 件模型并读回画面。逐件结果记录家具编号及 128 × 128 视口中的非透明像素数。[渲染记录](evidence/req209-full-models/renders.json)
- 本机实际网页 `#/house/decor` 使用只读目录回放。在 1366 和 1920 两种宽度下，搜索壁炉和门廊，打开详情、切换 3D、拖动、复位、切回图片、关闭。校验拖动后画面改变、复位后还原，以及卡片眼形与计数的对齐。[操作记录](evidence/req209-full-models/interaction.json) · [壁炉](evidence/req209-full-models/80-1366.png) · [门廊](evidence/req209-full-models/523-1920.png) · [卡片图标](evidence/req209-full-models/card-1366.png)
- 本次无 SQL。本地交付，生产发布与运营验收待进行。

## 复核入口

导出工具 `scripts/decor/export_catalog_models.cjs` 复用既有本地游戏读取器并调用 FFmpeg 编码网页贴图。`scripts/decor/structural-models.json` 保存 21 条建筑映射。生成并检查全目录索引使用 `node scripts/decor/index_catalog_models.cjs`。运行 `node scripts/verify-req209-full-models.cjs` 可重复浏览器全量检查与页面交互验证。
