# REQ-209 / REQ-205 家具 3D 预览实现与验证

日期：2026-11-19。实现与本地组件浏览器验证完成；未提交、未部署，待主任务整站联验及运营验收。遵循《开发规范》与《UI工作方法-证据规范实现验收》。开工审计和组件规格见 `design-plans/req209-decor-model-preview.md`。

## 本次变化

- **新增功能**：现有家具详情内嵌「图片 / 3D 预览」，26 件已映射家具支持鼠标旋转、滚轮缩放、左右按钮、放大缩小、复位和键盘视角调整。
- **功能优化**：仅点击 3D 才加载运行库和当前家具；失败保留图片，提供重新加载；关闭、切图片、页面路由变化释放模型及上下文。
- **修复 BUG**：本包实现中已处理“网络失败的模块 import 被浏览器缓存导致不能重试”和“模型未加载完就关闭后旧请求返回”的边界；不另立既有产品故障编号。
- **模块调整**：静态模型及 MIT three.js r180 运行库自托管；不引入构建工具、不请求第三方 CDN、不改游戏插件与图鉴数据库。

## 接口与接入文件

入口依次引用 `js/decorModelManifest.js`、`js/decorModelPreview.js`，在 `decorData.js` 之前；增加 `css/decor-model.css`。这些入口和统一缓存版本由主任务接入。

`window.DecorModelPreview.mount({host,row,poster})` 返回 `{destroy()}`。`decorData.js` 的 `openDetail` 挂载，`closeDetail` 销毁。`js/decorModelViewer.js` 由壳动态导入，不直接增加到 HTML script 列表。

运行库在 `js/vendor/three-r180/`，实际模型在 `assets/decor-models/task084/`；服务只补 GLB/glTF MIME。脚本、数据、权限和目录边界没有额外开放。无需 SQL。

## 资产与材质核对

26 个发布 GLB 与 TASK-084 原文件逐字节一致；映射中的 `record_id → asset_id` 全部与已有 2335 行目录快照相符；字节数和 SHA256 全部相符。共 11,469,972 字节。原始导出与来源见该目录 README。

材质沿用已有静态缩略图处理：隐藏无贴图网格、部分特效小面片，28559 特定混合模式的效果网格不呈现；贴图双面裁切。真实浏览器中的正/反面接触图已逐格查看，26 件均有可辨认的家具实体，未出现整件空白或整块缺贴图白板。两个细枝条模型在深色背景下偏暗，与原静态材质特征一致。

此结论不是游戏内实时逐件外观对照，也不是所有方向、粒子、动画或染色完整性验证。页面明确显示“静态外观，不含动态特效”。其余目录仍显示图片和暂无 3D 提示，不宣称全库覆盖。

## 本地真实浏览器验证

执行：`node scripts/verify-req209-models.cjs`。真实 Chrome、headless、SwiftShader；组件页载入实际 `decorData.js`、目录快照和实际 GLB，接口仅由回放服务提供只读数据，没有生产或测试库写入。这不是普通显卡性能测试。

| 页面与动作 | 实际结果 |
|---|---|
| 家具图鉴 → 堕罪堡餐桌详情 → 图片默认态 | 未请求 three.js、模型查看器模块或 GLB |
| 详情 → 3D → 鼠标拖动 → 滚轮 → 复位 | 拖动/缩放后的模型像素变化，复位回到原视角截图；键盘旋转和 Home 同样通过 |
| 详情 → 图片 → 3D → 关闭 | 图片保留，切回图片和关闭后 canvas 均为 0，可重新打开 |
| 26 件家具依次打开 3D、旋转至背面、关闭 | 26/26 装载成功，前后视角不同并留证，每件关闭后无残留 canvas |
| 缺模型、缺图和长名称测试项 | 3D 不可用说明，图片占位、文字来源与加单入口仍在 |
| 阻断 GLB 请求 → 错误态 → 恢复网络 → 重试 | 原图片可见，重新加载模型成功 |
| 浏览器 WebGL 上下文主动丢失 → 重试 | 清理后回退图片，重试恢复模型 |
| 模型加载中关闭 → 打开另一件 | 旧请求不回填，当前只出现一个正确模型区域 |
| 阻断运行库模块请求 → 恢复 → 重试 | 使用重试模块地址恢复，不被浏览器失败缓存锁死 |

1366×768 与 1920×1080 已截图，模型在原详情面板中，来源/加单沿原详情纵向滚动。状态覆盖：图片默认、悬浮/焦点/按下、图片及 3D 选中、缺模型禁用、加载中、错误、缺图片、3D 展开。该子组件没有业务保存，不以本报告替代主任务的方案单保存联验。
