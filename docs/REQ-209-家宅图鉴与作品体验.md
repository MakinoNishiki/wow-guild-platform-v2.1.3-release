## 页面审计与处理

| 原页面遇到的问题 | 本次操作 |
| --- | --- |
| 找同种族的两种颜色须分别搜索，资料片主题容易被理解为加入游戏的时间 | 筛选组支持多选，同组取并集、跨组取交集。排序可选中文名称、加入版本、站内点赞或浏览。已有来源和价格继续在详情展示。 |
| 家具图只能看一个角度 | 通过「更多筛选 → 特性 → 可看 3D」找到有模型的家具。在同一个详情区域切换图片与三维外观，拖动、滚轮、键盘和按钮均可操作。 |
| 快捷加入无法指定方案 | 卡片和详情均可快捷加一件。登录用户点相邻的「选方案」可选现有方案或新建，原方案中的编辑会暂存。在方案抽屉可调数量、保存到账号。 |
| 作者需先存图再选择文件上传 | 创建、编辑作品时均可用 Ctrl+V 或拖入文件追加图片。共用已有的 8 张、每张 20 MB 校验，仍可更换单图或调整封面。 |
| 列表上的主图与翻图容易混淆 | 上一版已经支持点公开主图进详情、点圆点或横拖翻图。本次回归这些既有操作。 |

## 数据口径与覆盖

- 图鉴目录含 2,295 件家具和 40 个房间/户型。按目录编号匹配到 2,261 件家具的加入版本。34 件家具与 40 个房间的加入版本留待核实。按版本新旧排序时，未知项都排在末尾。版本反映资料源标注的补丁号，国服上线日期尚未逐件核对。[加入版本数据源](https://github.com/Daeveren/HousingCodexLive/blob/22791e6bcbacf242608efa4072d09dd5f7b7dc32/Core/DecorPatchData.lua)
- 详情只在有逐件记录时显示具体构建号。本次核对的 3 件均为 11.2.7.64632。[银月城大型平台](https://housing.wowdb.com/decor/2105/silvermoon-large-platform-2105/) · [烈风烹饪烤架](https://housing.wowdb.com/decor/8236/razorwind-cooking-grill-8236/) · [燃煤炉灶](https://housing.wowdb.com/decor/9472/coal-fired-stovetop-9472/)
- 逐件核对玩家的烹饪或操作记录，目前可按「可烹饪」找到两件炉具，按「可互动」找到两件有明确操作的家具。国服本机模型中有 513 件家具带粒子或拖尾定义，纳入「有特效」。游戏内实际播放、开关条件及其他类型特效未逐件核对。[能力依据](evidence/req209-20261119/decor-use-sources.json) · [国服模型核对](REQ-209-家具模型特效数据与溯源-20261119.md)
- 3D 预览覆盖 26 件已转换并核对正、背面的家具，静态外观不播放游戏粒子动画。选择 3D 后才请求模型。模型缺失、加载失败或浏览器无法渲染时，图片和原图鉴功能仍可用。[模型验证与材质说明](REQ-209-家具3D预览实现与验证-20261119.md)
- 浏览统计从该功能启用时起计算。账号或同一浏览器的匿名标识按家具单独计数，距离上次有效浏览满 30 分钟才能再计一次。登录用户每件可点一个赞、可撤销。访客能看到总数。SQL 52 已在一次性 PostgreSQL / PostgREST 环境核对权限、时间窗口、并发重复写入和回读，正式站迁移及核对见上方发布记录。[数据库迁移](../sql/52_req209_decor_engagement.sql)

## 运营统一验收单

| 入口 | 操作及预期 |
| --- | --- |
| 家宅图鉴 → 更多筛选 | 同时选两种颜色，再选一种风格。结果包含任一所选颜色，同时满足所选风格。取消单项、清空筛选、切换名称或版本排序后，命中数与列表一致。 |
| 家宅图鉴 → 家具详情 | 搜「银月城大型平台」，看加入版本 11.2.7、构建号 64632。切换到一件尚无版本的家具，显示「尚待核实」。 |
| 家宅图鉴 → 功能 | 分别点「可烹饪」「可互动」「有特效」。可烹饪能找到「燃煤炉灶」，可互动能找到「神秘的书柜墙壁」。 |
| 家宅图鉴 → 特性 → 可看 3D | 打开「堕罪堡餐桌」，选择 3D，拖动看背面，滚轮放大，再点「复位」。换回图片，检查仍能查看来源、加入方案。建议用日常游戏电脑感受操作流畅度。 |
| 家宅图鉴 → 游戏内预览 | 打开「银月城大型平台」，点「点击游戏内预览」。在国服正式服聊天框粘贴、回车，核对游戏显示的家具。网页剪贴板与编号已验证；运营已于 2026-11-20 确认国服客户端粘贴后可预览。[游戏界面函数](https://raw.githubusercontent.com/Gethe/wow-ui-source/live/Interface/AddOns/Blizzard_HousingEventHandler/Blizzard_HousingEventHandler.lua) |
| 家具详情 → 点赞和浏览 | 登录后点赞，刷新应保留，再点可撤销。同一浏览器连续打开同一件，浏览只增加一次。返回列表可选「站内点赞最多」「站内浏览最多」。 |
| 家具卡片或详情 → 选方案 | 选已有方案加一件，再给另一份新方案添加同一家具两件。在抽屉保存后刷新，确认各自的名称和数量。游客可继续使用临时方案。 |
| 家宅分享 → 创建或编辑作品 | Ctrl+V 粘贴一张截图，拖入两张，粘贴说明文字。保存并重开应见三张图、顺序与文字一致。公开卡片点主图进详情，横拖只翻图。 |

本地验证覆盖 Chrome 的 1366、1920 两档桌面宽度、一次性数据库及测试账号、26 个真实模型的装载与失败恢复。运营验收待记录。[图鉴交互](evidence/req209-20261119/catalog-verification.json) · [全目录与热度联验](evidence/req209-20261119/engagement-check.json) · [方案与截图保存](evidence/req209-20261119/entry-check.json) · [模型交互](evidence/req209-models-20261119/verification.json)
