# 个人档案 v3.3.0

2026-11-28，REQ-186、REQ-187。交互稿整批通过，正式页面待运营点验。进入顶栏「个人档案」即可切换以下页面。

| 页面 | 操作与验收结果 |
| --- | --- |
| 展示与隐私 | 在 Chrome 选定角色后刷新，访客名片从对外接口读回名称、区服、地区、职业。本人看得到其他角色与专精，本会团员只看到本会名册认领记录。撤下后访客预览为空。 |
| 我的资产 | 打开指定家宅方案，将家具从 2 件改为 3 件、保存、返回，数量已更新。当前公会显示已认领角色的心愿和最终获配装备，待分配物品未计入。 |
| 公会与认领 | 核对无效邀请码提示、加入第二个公会、审核制申请与撤回、切回原会、解除与重新认领、退出最后一个公会。角色和个人方案保留。 |
| 账号隔离 | 同一浏览器登出后换账号，看到新账号自己的方案。访客打开三个私有地址均获登录引导。 |

验证使用正式应用代码、Chrome、一次性 PostgreSQL 和 PostgREST。身份与登录会话使用测试数据。本次沿用既有表、权限与方案编辑器，无生产 SQL。个人名片目前提供可见范围预览。缺少明确获配角色编号的历史装备记录不会归入个人资产。
