# REQ-207 作品互动、举报与站内回执

状态：本地实现及隔离真浏览器验证完成；未代运营验收，未提交、推送或部署。生产需 SQL55 随本批迁移执行。开工审计见 `design-plans/req207-community-interactions.md`。

## 已实现

- 新增功能：公开装修作品点赞、收藏、纯文字留言、删除本人留言；作品/留言举报，选择原因并补充说明。
- 新增功能：平台管理员举报队列，可驳回、隐藏留言、下架作品，并可纠正隐藏/下架结果；处理历史保留。
- 功能优化：举报提交、处理结果自动进入用户中心通知；举报人收到受理/处理回执，受到隐藏/下架处理的作者也收到原因。支持单条和全部已读。登录后可见标签页每 60 秒回读未读数、提交动作后刷新红点；这属于站内通知，不是浏览器/系统推送。
- 修复与边界：失败保留输入，写后回读失败重试不重复留言；同一用户同目标只留一条待处理举报；下架同时撤回公开详情、图片、蓝图复制、互动与热度；旧版/新版保存都不能绕过下架限制。解除限制后仍为草稿，由作者自行重新发布。
- 模块调整：作品收藏独立于个人家具采购方案单；社区后台权限来自平台 `superadmin`，公会 owner/editor/viewer 均不自动获得此权限。

## 数据与接口

SQL：`sql/55_req207_housing_community.sql`。新增：

| 表/视图 | 用途 |
| --- | --- |
| `housing_build_reactions` | work_id/user_id/kind 唯一，like 与 favorite |
| `housing_build_comments` | 留言正文、作者与 visible/removed/hidden 状态 |
| `housing_community_reports` | 原因、说明、目标文本快照、处理状态与历史 |
| `housing_community_notifications` | 用户级受理和处理回执、已读状态 |
| `housing_build_community_totals` | 公开作品 work_id/likes/favorites/comments/recent7d |
| `housing_community_comment_list` | 供专属接口查询留言显示名，不对匿名或普通角色开放 |

`housing_builds` 增加 `moderation_hidden` 与约束 `NOT moderation_hidden OR NOT published`。与旧/新保存 RPC 共享约束，不能只靠前端按钮防绕过。

专属 `/api/housing-community/`：

| 方法 | 动作 | 权限 |
| --- | --- | --- |
| GET | summary、thread | 公开作品；thread 可带本人状态，留言仅显示名/文本/时间/本人标记 |
| GET | favorites | 仅当前登录用户、仅仍公开作品 ID |
| POST | react、comment、remove-comment、report | 登录用户；删除仅本人 |
| GET | my-report、notifications | 仅本人 |
| POST | read | 仅本人回执 |
| GET/POST | admin-reports / moderate | 平台管理员 |

公共汇总仅计算仍公开且未下架的作品；留言只算 visible。recent7d 是过去 7 天产生、目前仍有效的点赞/收藏/可见留言数量之和，不是访问量或未去重点击次数。取消点赞/收藏、隐藏留言后不再计入。

四张表和专属视图启用/配合 RLS，拒绝 anon/authenticated 直接读写；专属 RPC 只允许 service_role 执行。RPC 使用 SECURITY DEFINER、空 search_path、限定表名，并在处理举报时再次核对 auth.users 中平台角色；服务端 JWT 校验与字段白名单先行。所有前端写入经过 cloudCrud 与云端回读，不进入公会缓存。

## 基础规则及明确限制

- 留言 1—1000 字、举报说明最多 1000 字、处理说明 1—500 字；纯文本显示，通知标题和内容转义，不执行 HTML 或链接脚本。
- `lib/housingCommunityRules.cjs` 提供可审阅的小型禁用短语清单与危险协议检查；不是完整审核词库，不具备图片识别或 AI 自动审核，不宣称能识别全部违规内容。
- 留言每账号每分钟最多 5 条，举报每账号每小时最多 10 条；重复同一幂等请求不新增行。
- 后台保存举报当时的作品标题、说明或留言文本。可通过“查看公开作品”核对当前公开截图；本期没有独立的历史图片证据归档，作品撤回后该公开入口按权限关闭。
- 用户中心本次聚合最近 100 条社区回执。未开发邮件通知、系统推送、账号封禁/禁言期限或多级审核。这些不在本次最小社区链路内。

## 实际验证

2026-11-20，运行 `node scripts/verify-req203-web.cjs --suite=community`。
真实本机一次性 PostgreSQL + PostgREST + 项目 `server.js` + Chrome 157.0.8103.79；认证身份使用三个隔离测试账号（作者、另一用户、平台管理员），没有生产数据写入。

结果：11 项通过，其中公共迁移/ACL 2 项、社区 9 组。

1. `#/house/community/:id` 游客点击点赞打开登录入口，未登录 API 拒绝写入；普通用户后台入口拒绝。
2. 实际点击点赞、取消点赞、收藏，刷新后结果与数据库一致；重复点赞保持一条，本人收藏不跨账号。
3. 实际发布留言；禁用短语被服务端阻止；HTML 测试文本不执行；人为制造写后回读失败，输入保留，再提交只留一行；他人不能删除。
4. 实际点击举报留言、填写原因说明、提交；重复待处理举报去重；用户中心可看到受理回执。
5. 平台管理员实际隐藏留言，游客不可见且计数减少；举报人与留言作者收到结果；别人不能把这条回执标记已读；用户中心“全部已读”写回数据库。
6. 后台恢复留言保留历史；作者实际删除留言后不再计入热度。
7. 后台下架作品后，详情、公开图片、复制蓝图、互动、收藏与汇总全部收回；重新发布被阻止，作者仍能保存草稿；直接数据库 UPDATE 也受约束。
8. 后台解除下架后仍为草稿，作者可重新发布；驳回举报不下架作品，保留处理回执。
9. anon/authenticated 表和 RPC 权限检查；数据库再次拒绝非平台管理员处理操作。
