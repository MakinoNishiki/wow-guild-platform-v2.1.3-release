## 当前采用文字的导航

顶部五项为「首页、团队管理、家宅房屋、副本掉落、更新日志」。这五项文字起点、选中线和间距一致。建议第一版保留文字导航。若运营希望顶部也配图，五项可分别用盾形站徽、军旗、屋顶、掉落宝箱、带书签的编年册，其中宝箱和军旗可供首页与团队入口复用。

高密度的页内切换目前也使用文字。考勤有「日历视图 / 列表视图」，装备有「分配记录 / 拾取记录」，家宅有「公开作品 / 我的作品」，方案单导出有「文字预览 / 生成图片」，成员导入有「从 WCL 导入 / 手动名单（备用）」。数据中心含版本、赛季、团本、BOSS、掉落池、大秘境掉落、套装、大秘境、职业、专精、访问统计 11 项。副本掉落的「全部 / 部位 / 武器 / 护甲」切换筛选条件。建议这些控件保留文字，留出空间给项目名。

编辑、删除、导入等操作按钮，状态提示、身份徽章和插图属于其他用途。游戏内物品、职业、专精、职责、货币已有对应资源，保留游戏识别方式。品牌盾徽与页签 favicon 已有专用文件。

## 建议出样规格

| 项目 | 建议值 |
| --- | --- |
| 尺寸 | 所有导航图标显示 **20 × 20 像素**，统一 24 × 24 设计网格；图与文字间距 8 像素。行高与整行可点击面积沿用现有样式 |
| 轮廓 | 单一主形，少量内部刻线。先看单色剪影，再看原寸深底效果 |
| 状态 | 默认灰铜；悬浮提亮；选中沿用站内金色与现有文字、外框。焦点落在整个导航按钮上 |
| 首张选稿板 | 同画「家宅图鉴、方案单、家宅分享、装备分配」四枚。A 为哑光雕刻铜章，B 为暗铁底配少量暖金边。并排给出原寸左栏、放大细节与选中态 |

此前研究的站点是 ForeverChanges。这里借鉴的是主题美术集中在入口、数据区留干净背景的层次安排。两套出样均用魔兽管家原创轮廓。运营先审位置与尺寸，再看样张、选定画法、扩展整套。[站内参考笔记](ui设计参考.md#外站参考--foreverchanges2026-11-03) · [ForeverChanges](https://foreverchanges.pro/zh-cn)

**核对方式**　正式站 Chrome 桌面 1920 × 1080 打开家宅图鉴，确认左侧三项的实际文字与图形，点击「家宅分享」进入公开作品，回首页核对三张快捷入口及顶部五项。团队和用户中心按当前页面定义清点，数据中心受超管权限控制。旧侧栏和移动底栏在该桌面宽度均隐藏。本次为盘点，图标设计与上线日期由运营审定。
