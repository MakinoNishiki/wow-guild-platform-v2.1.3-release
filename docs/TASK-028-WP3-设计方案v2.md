## 一、新口径（运营定，五条）

1. **卡片默认展示完整信息组**：名称 / 主属性+数值 / 副属性+数值（数值大者⭐星标）/ 特效 / 掉落来源（实例+BOSS）/ 套装归属（有则显），配新排版承载；
2. **只有超出卡片容量的文本（长特效）用 hover 悬浮展示全文**，复用补丁4 已验收 overlay 模式（150–250ms ease-out、只动 transform/opacity、reduced-motion 降级）；
3. **卡片零点击交互**：现有点击详情层（单开互斥/Esc/点外）全部移除，下线方式见 §四；
4. 难度行继续不显（tiers 无数据）；
5. sql/21 RPC 保留不动（卡片面数据全部来自 RPC 行，无需变更）。

## 二、卡片排版规格（新排版承载）

六结构行，自上而下：

| 行 | 内容 | 规格 |
|---|---|---|
| 1 名称 | 物品名（金） | 高 18px，单行截断 |
| 2 meta | 部位/类型 tag（灰，现状延续） | 高 20px，单行 nowrap 溢出隐藏 |
| 3 主属性 | tag+数值（力量 +61 式） | 高 20px 单行；**启用 §4.11 属性色板**（力量 #ff6b6b/敏捷 #40c057/智力 #4dabf7，确认点 A）；缺数值只显属性名（确认点 E） |
| 4 副属性 | tag+数值，灰系 | 高 20px 单行；**数值大者金星变体**（§4.2 已注册：右上角金五角星 SVG 自绘+金色描边）；相等/单值/缺数值不加星（三态规则延续旧 WP3 文案） |
| 5 特效 | 特效绿 #1eff00 | **恒 2 行**（line-clamp:2，无特效空行占位）；超 2 行为超长 → hover 展示全文 |
| 6 来源 | 实例 · BOSS（· 套装归属） | 高 16px 单行截断，11px --text-muted；套装归属并入同行末尾（确认点 C）；BOSS 空=「整体池」 |

**等高策略**：六行恒占恒高（缺省=空行占位），卡片总高恒定、兄弟卡天然等高，零 JS 依赖；统一尺寸铁律（§4.4）由结构保证而非覆盖层补丁。**特效截断行数 = 2**（确认点 B）。

**星标规则**（按①，仅副属性行）：同卡副属性数值两两比较，严格大者加星；并列第一不加；单副属性不加；缺数值不加不报错。主属性行不加星（规格文本「数值大者⭐星标」挂在副属性后；三主属性同值实例见 mockup 孢子大王的菌丝徽记）。

## 三、hover 特效覆盖层（补丁4 模式回归 §6 白名单）

- 触发：仅桌面 `:hover`（快读路径），无点击路径（③）；
- 形态：补丁4 下展覆盖层（卡片下缘拉出、z-index 抬升不挤压网格、全文替换语义——展开时预览行隐藏）；覆盖层上缘对齐特效预览行位；
- **动画回归白名单**：200ms ease-out 只动 transform/opacity（translateY(-4px)+fade），reduced-motion 瞬时——v1 施工时注册的 F1 例外（max-height/padding 过渡）随之**废止**（确认点 D），§6 例外条款同批撤除；
- 无特效卡无 overlay、无 has-effect 引导边框？——**保留**金色微光描边作为「有特效可 hover」引导（现状延续，已验收）。
