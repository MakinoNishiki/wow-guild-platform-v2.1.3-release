# WCL 账号授权只读验证：接口核查

日期：2026-11-05。仅官方文档研究；未读取凭据、未执行用户授权、未写业务数据。

## 已确认

- 官方 Character schema 的 `claimed` 表示角色是否由当前用户认领；字段仅在用户 API 且具备 `view-user-profile` scope 时可访问。这是 WCL 认领关系，不能扩大解释为战网实名所有权证明。[官方 Character schema](https://de.warcraftlogs.com/v2-api-docs/warcraft/character.doc.html)
- 官方 Query schema 提供 `userData` 获取授权用户的 ID 和用户名；角色查询则由 `characterData` 承担。不能仅凭这两个入口推断已支持完整账号角色列表。[官方 Query schema](https://www.warcraftlogs.com/v2-api-docs/warcraft/query.doc.html)
- 官方中国站 schema 同样列出 Character 与 User；User 注释说明多数用户字段需要以本人身份授权并具备上述 scope。中文域名存在不代表国服角色归属已实测可用。[官方中国站 schema](https://cn.warcraftlogs.com/v2-api-docs/warcraft/character.doc.html)
