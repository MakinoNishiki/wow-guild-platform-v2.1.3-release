# 公示页筛选系统设计规范

> **版本 v3.1（2026-08-09）取代 v3.0**｜依据：任务书 #28-WP6 补丁（P1–P4，运营 2026-08-09 体验终审）｜地位：公示页（data.html）筛选条的唯一设计基准；后续任何筛选相关改动以此为准，禁止即兴样式。
> v3.0（2026-08-09，WP6 主体 F1/F2/F3）自本文生效起**废止**；v2.0（2026-08-08）、v1.0（2026-08-06）早已废止。WP6 补丁增量：P2 分类二级增设「全部」默认 tab / P3 部位增设「饰品」（12 项）/ P4 筛选联动置灰（§3、§6）；P1 装备卡 hover 整卡生长（见 UI 设计规范 v2 §4.4/§6）。

## 1. 设计目标

- 让用户在 3 秒内理解「这里能按什么筛」；
- 所有筛选控件**同一形态、同一尺寸**；
- 层级分类一眼可读：首行工具（搜索+重置），小类别自第二行起，每组 = 区头标题 + chips。

## 2. 总体结构（唯一合法布局）

筛选条为**一个整体容器**，自上而下：

```
[搜索框（置顶加宽，清除钮保留）              ] [重置筛选]   ← 首行：不放任何 chip
[分类] 区头标题（右随「二级单选 · 三级多选」注释）        ← WP6 F1：第一组（先分类后属性）
  全部 部位 武器 护甲                          ← 二级 tab（P2：「全部」默认选中=未启用分类过滤；单选，切换/收起清空三级；加粗区别于 chips）
  （三级 chips 行：当前二级类目下的 chips，多选）       ← 「全部」态整行不渲染
[主属性] 区头标题（右随「多选」注释）
  力量 敏捷 智力                              ← chips 自第二行起
[副属性] 区头标题（右随「多选」注释）
  爆击 急速 精通 全能
[来源] 区头标题（右随「单选 · 值域随赛季数据驱动」注释）
  全部 │ 团本 大秘境 副本任务 专业制造          ← 单选五枚（值域赛季驱动，无数据 chip 不出现）
  （实例 chips 行：选中团本/大秘境时展开，带计数角标）    ← WP6 F2：未选来源时整行隐藏
```

- 首行 = 搜索框（flex:1 加宽）+「重置筛选」按钮（右端），**不放任何 chip**；
- 每组 = **区头标题独占一行** + chips 行（组内折行允许，不跨组混排）；
- 组与组间距 10px，区头标题与 chips 行垂直间距 6px，组内 chip 间距 6px；
- **「排除杂项物品」开关与问号帮助整块删除**（DOM 不残留）；部位/类型两行删除（细粒度筛选由来源维度取代；WP6 起部位/武器/护甲细粒度经「分类」组三级结构回归，§4-2）。

## 3. Chip 规格表（唯一事实源）

| 属性 | 值 |
|---|---|
| 高度 | 24px 恒定（禁第二高度） |
| 内边距 | 左右 10px，垂直 0 |
| 圆角 | 12px（全圆角例外，已注册） |
| 字号/字重 | 12px / 500 |
| 行内居中 | line-height:1（BUG-054 中文光学居中定稿） |
| 默认态 | --bg-card 底 + 1px --border-color 描边 + --text-secondary 文字 |
| 选中态 | --gold 描边+文字 + rgba(240,192,96,.1) 底（**多选/单选同一样式**） |
| 置灰态（P4，WP6 补丁 2026-08-09） | opacity .4 + 虚线描边 + cursor:not-allowed + 悬浮原因提示（「当前筛选组合下『X』无命中装备」）+ aria-disabled；**仅未选 chip 可置灰，已选 chip 恒不置灰；禁止自动清除已选**；条件变化实时刷新；来源一级 chips 不做置灰（单选+全部锚点语义） |
| 组内间距 | 6px；来源行「全部」与四值之间 1px 竖分隔线（16px 高）；**来源组值 chip 同包 .dp-chip-sub，间距与主/副属性组同一 6px**（R5，WP3-v3，2026-08-08） |
| 区头标题 | 独占一行：12px / 600 / --text-secondary / 字距 0.02em；右随 11px --text-muted 注释（多选 / 单选·值域随赛季数据驱动） |
| 重置筛选按钮 | 次级按钮（btn-secondary 描边，UI 规范 v2 §4.1），与搜索框同排右端；点击清空全部筛选状态+搜索词，还原当季全集 |

- 主/副属性：**多选**（组内多标签 AND 语义不变）；未选中即不过滤，无「全部」chip；
- 分类（WP6 F1，2026-08-09；P2 补丁同日）：**二级 tab 单选**（**全部（默认选中，= 未启用分类过滤，三级区不渲染 chips）**/部位/武器/护甲；再点已选 tab 收起回「全部」；**切换/收起清空三级已选**——类目互斥，防隐性条件残留）+ **三级 chips 多选**（同类目内并集 OR，与其他过滤组交集 AND）；三级 chips 沿用 .dp-chip 体系（24px/12px 圆角/选中态同款），二级 tab 同体系加粗（600）区分；**三级 chips 数据驱动——当季 0 命中的 chip 不渲染**（主手全库 0 命中：定义保留不渲染，有数据赛季自动出现）；仅打开二级 tab 未选 chip = 无过滤条件；
- 来源：**单选**互斥，「全部」= 不限制；与主/副属性/搜索词跨组 AND；**联动折叠**（R6，WP3-v3，2026-08-08）：选「团本」→ 大秘境掉落池整段（含分组标题）不渲染，选「大秘境」→ 团本掉落池整段不渲染，「全部」均展开；
- 来源实例级（WP6 F2，2026-08-09）：选中团本/大秘境时展开**实例 chips 第二行**（当季有数据实例、sort_order 序、**带计数角标**沿用 .dp-count 组标题计数样式）；实例**单选、再点取消**；浏览态选中实例 = 另一池整池折叠（R6）+ 本池只剩该实例分组；平铺态退化为纯过滤（§10）；
- 所有筛选即时生效（客户端过滤，无延迟无按钮）。

## 5. 杂项与套装兑换物口径

- **杂项**：数据层排除 `slot='杂项'` 全部行（装饰/垃圾/坐骑/配方类等），页面零渲染、筛选零入口；
- **装饰品/幻化**：R9（WP3-v3，2026-08-08）起服务端增排 `item_type IN ('装饰品','幻化')`（sql/22，公开 RPC `get_public_loot_detail` 口径；注意 item_type「装饰」住宅物件≠「装饰品」，不在排除口径）；
- **世界BOSS**：R13（WP3-v4 / BUG-062，2026-08-08）起 `game_raids.type='world'`（至暗之夜，32 件）服务端黑名单剔除（`is distinct from 'world'`，sql/24——不用白名单写法，避免误杀 lair）；**巢穴 lair（孢陨幽境/潮缚石窟）归团本口径保留展示**；剔除后基线 **S1 全集 308 = 团本 104（虚影尖塔60+进军奎尔丹纳斯25+梦境裂隙8+孢陨幽境11）+ 大秘境 204**（340 口径 2026-08-08 起作废）；
- **套装兑换物**：非杂项，**保留展示**（R9 明确不排除），沿用「独立归类、永不与杂项同组」口径；无 chip 入口，仅卡片展示，来源归入其掉落本。

## 6. 交互与状态

- 赛季切换：全部筛选重置为默认（来源回「全部」+实例行收起、分类二级收起+三级清空、主/副属性清空、搜索清空）；
- 「重置筛选」按钮：一键清空全部筛选状态+搜索词，还原当季全集（复用赛季重置同一函数）；
- 搜索框清除钮（REQ-084）保留：有内容才显示、点击/Esc 清空、焦点留输入框；
- 筛选结果数与各组条件严格一致（硬验收：单选/组合/清空还原逐项对数，基线随 §5 口径——当前 S1 全集 308）；
- **筛选联动置灰**（P4，WP6 补丁 2026-08-09）：任何筛选条件下实时计算每个**未选** chip 在「其他组条件+搜索」下的命中数（纯前端内存计算当季 308 行，不新增接口），0 命中即置灰不可点（§3 置灰态规格）；已选 chip 恒不置灰、**禁止自动清除用户已选**；0 命中空态+重置引导保留；覆盖组 = 主属性/副属性/分类三级/来源实例级（来源一级 chips 不做，单选+全部锚点语义）。

## 6-2. 双态规则（WP6 F3，2026-08-09 运营定）

| 状态 | 触发条件 | 形态 |
|---|---|---|
| 浏览态 | 无任何筛选，或仅选来源（含实例级） | 双池堆叠 + 实例/BOSS 分组 + R6 折叠（现状） |
| 筛选态（平铺） | 搜索词、分类三级、主属性、副属性**任一激活** | 全局平铺：无池标题无分组，命中卡片直接铺满网格 |

- 分类仅打开二级 tab 未选 chip **不算激活**（无过滤条件）；
- 平铺态顶部「命中 N 件」计数；0 命中空态「无符合条件装备」+ 内联「重置筛选」引导按钮；
- 平铺态下来源 chips（含实例级）**退化为纯过滤器**：缩小命中集合，不再触发折叠/分组；
- 清空全部内容类条件自动回浏览态；排序保持数据自然序（团本→秘境→BOSS 内序），不发明新排序；
- 状态切换走既有 0.2s 卡片入场渐显动画；prefers-reduced-motion 降级不变；
- 套装兑换物（鸣响虚空珍玩）平铺态正常命中（属性筛选时因无主副属性自然不命中，预期行为）；套装一览区块双态常驻。

## 7. 动画规格（UI 规范 v2 §6 注册内，运营裁定④两者并存）

- **筛选器展开收起**（移动端「筛选 ▾」面板）：150–250ms ease-out，只动 transform/opacity；展开走 keyframes 入场（fade+轻微下移），收起反向过渡后隐藏；`prefers-reduced-motion` 下禁用；
- **卡片入场 fade+轻微上浮**：筛选/搜索触发卡片重渲染时，150–250ms ease-out，只动 transform/opacity；出场不做（直接重渲染）；reduced-motion 禁用；
- 桌面恒展开形态下筛选条无折叠，动画主要作用于卡片入场。

## 8. 响应式

- 1920×1080 / 1366×768 两档必测：首行 + 四组各一行（WP6 起含分类组；分类三级行/来源实例行未激活时隐藏，激活后组内折行允许，chips 左对齐成第二基线）；
- 移动端（≤768px）：筛选条整体折叠为「筛选 ▾」按钮展开面板（已知取舍-封存，仅保持可用）。

## 9. 反例（禁止项）

- ❌ 首行出现任何 chip；
- ❌ 区头标题与 chips 同行混排；
- ❌ chip 出现两种以上尺寸；下拉与 chip 混用（本规范唯一形态 = chip）；
- ❌ 「排除杂项」类开关复活（杂项已无入口）；
- ❌ 来源值域写死实例名（必须赛季数据驱动）；
- ❌ 分类三级 chips 写死渲染（必须当季数据驱动，0 命中不渲染）；
- ❌ 筛选态（平铺）出现池标题/实例/BOSS 分组，或平铺态来源触发折叠（来源退化为纯过滤）；
- ❌ 动画动 height/width/layout 属性（只动 transform/opacity）。
