# prd-review — PRD 评审 Skill

## 功能

按照 `docs/prd/prd-review.md` 中的标准化规则，对指定 PRD 文件或目录执行完备性评审，输出结构化评审报告。

## 使用方式

在 Claude Code 对话中输入：

```
/prd-review
```

或直接带上路径：

```
/prd-review docs/prd/需求文档.pdf
/prd-review docs/prd/
```

## 输入

| 参数 | 说明 | 示例 |
|------|------|------|
| 文件路径 | 单个 PRD 文件（.pdf / .md / .txt） | `docs/prd/仓库主数据改造需求.pdf` |
| 目录路径 | 目录下所有 PRD 文件批量评审 | `docs/prd/` |

未提供参数时，Skill 会交互询问路径。

## 输出

- **对话摘要**：结论、综合分、各风险缺口数量、报告路径
- **评审报告文件**：`docs/prd/cr-report-{需求名称简写}.md`（目录不存在时自动创建）

## 评审维度

| 维度 | 权重 |
|------|:---:|
| 业务背景 | 10% |
| 页面/模块说明 | 15% |
| 核心流程 | 20% |
| 关键字段说明 | 20% |
| 校验规则 | 15% |
| 异常场景 | 10% |
| 状态流转规则 | 10% |

## 评审结论

| 综合分 | 高风险缺口 | 结论 |
|:-----:|:--------:|------|
| ≥ 7 | 0 | **通过** — 直接排期 |
| 5-7 | ≤ 任意 | **有条件通过** — 补充后可开始 |
| < 5 或任意分 | > 0 | **不通过** — 补充后重新评审 |

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 评审执行逻辑（工作流） |
| `review-criteria.md` | 评审规则主体（7 个维度的检查项、评分标准、缺口定级）。**需要调整评审标准时只改此文件** |
| `README.md` | 使用说明 |

报告输出目录：`docs/prd/`（不存在时自动创建）
